# 急诊子集的数据分布差异与时序基础模型的反应：描述分析方案（2026-11-08 锁定）

> 研究者 11-07 的问题：分诊等级、到达方式等子集在数据上有什么物理差异（例如 ESI High / Moderate / Low 三组的分布差异），这些差异会对基础模型产生什么影响。
> 本方案只做描述分析，不改任何已有结论，不新增 A 档决定。结论标为探索性（D111）。结果见 `result/时序基础模型/急诊子集数据分布与基础模型机制_结果_20261108.md`。

## 3. 描述量（看结果之前定好）

每个“就诊 × 变量”算一次，再按组汇总（中位数与四分位距，或比例）。每一项后面写它对应的模型机制。

### 3.1 测量过程（决定模型输入的形状）

| 描述量 | 定义 | 对应机制 |
|---|---|---|
| 有上下文比例 | 上下文内至少有一次观测 | 没有上下文的就诊不进预测 |
| 首次测量时间 | 第一个非空格的起点（分钟） | 有效长度 = 总格数 − 开头空格；③ 发现嵌入增益来自它 |
| 观测格数 | 上下文内有观测的格数 | 越少，前向填充越多 |
| 真实观测占比 | 观测格数 / 有效长度 | 其余是填充值 |
| 只有一次观测的比例 | 观测格数 = 1 | 必然是常数序列 |
| 常数上下文比例 | 有效段最大值 = 最小值 | 实例标准化后只剩长度，模型输出接近水平线（M2） |

### 3.2 数值水平（被实例标准化抹去的部分）

| 描述量 | 定义 | 对应机制 |
|---|---|---|
| 末值 | 上下文最后一个值 | 水平；标准化后不进入形状，只在还原时回来（M1） |
| 上下文内已越阈比例 | 任一上下文值越过 HR>110、MAP<65、SpO₂<90 | 越阈风险分和 Context-max 的直接来源 |
| 末值到阈值的相对距离 | `(末值 − 阈值)/阈值`，越阈为正（与 S 分数同号） | 同上 |

### 3.3 上下文内的波动

| 描述量 | 定义 | 对应机制 |
|---|---|---|
| 标准差 | 填充后序列的标准差（模型看到的尺度） | 标准化的分母；越小，噪声被放大越多 |
| 变异系数 | 标准差 / 均值 | 去掉水平后的相对波动 |
| 极差 | 最大值 − 最小值 | — |

### 3.4 预测段（真实未来）

| 描述量 | 定义 | 对应机制 |
|---|---|---|
| 未来观测数 | 预测段内的观测数 | 观测越多，该组在合并 MAE 中权重越大 |
| LOCF 平均绝对误差 | 未来观测与末值之差的绝对值，按观测合并 | 所有模型共有的“难度”（M3） |
| LOCF 平均有符号误差 | `末值 − 未来值` 的均值 | 正值表示未来回落（回归均值） |
| 未来标准差 | 预测段内观测的标准差（≥2 个观测） | 未来波动 |
| 新越阈比例 | 上下文未越阈、预测段内出现越阈 | 越阈型风险的来源 |

### 3.5 结局

- MIMIC-IV-ED：D103 标签（2 h 时点后 12 h 内进 ICU 或死亡）在三项都有上下文的就诊中的比例。
- MC-MED：`decomp_60` 在 A 半共同风险队列中的比例。
- 为解释 ③：每组内，首次测量在第 0 格与晚于第 0 格的就诊的结局比例（按变量分开）。

## 4. 模型的反应

在“八个模型和 LOCF 都有有限预测”的共同未来观测上计算：

1. 各模型与 LOCF 的合并 MAE；八模型平均 MAE / LOCF MAE 的比值 R（R>1 表示模型比 LOCF 差）。
2. 偏离 LOCF 的幅度：每个就诊预测段内 `|预测 − 末值|` 的均值，各组取中位数；“近似水平线”比例：预测段内 `max|预测 − 末值| < 1`（bpm、mmHg 或 %）。
3. 按上下文形状（常数 / 非常数）分层的 R。
4. **构成分解**：标准化比值 `R_std = Σ_s π_s·MAE_模型,g,s / Σ_s π_s·MAE_LOCF,g,s`，其中 s 为上下文形状，π_s 为该变量全体中各形状的未来观测占比。它回答“如果这一组的常数/非常数构成与全体相同，R 还会不同吗”。
5. 不确定性：患者聚类 bootstrap，B = 1000，seed 2026；报告 R、R_std 以及“组 − 补集”之差的 95% 区间。不做多重校正（描述分析，不作判定）。

## 5. 判读规则（看结果之前写定）

- 对每个组与它的补集：
  - ΔR 区间含 0：该组相对 LOCF 的表现与补集无可分辨差异。
  - ΔR 区间不含 0，ΔR_std 区间含 0：差异由上下文形状的构成解释（该组非常数上下文更多或更少）。
  - ΔR_std 区间也不含 0：同一形状内也有差异，写成“构成之外还有组内差异”，不再进一步归因。
- 描述量不做检验。MIMIC-IV-ED 样本大，微小差异的区间也会很窄，所以只解释量级（例如常数比例差 ≥5 个百分点、首次测量中位时间差 ≥15 分钟）。
- M4（短上下文、阶梯形态与预训练分布不符）不能直接测量，只通过“非常数上下文上 R > 1”间接看，结论写成“与之相符”，不写成“证明”。
