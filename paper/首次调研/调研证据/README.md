# 第二轮调研索引

本目录按新的调研主题重建，不沿用第一轮错配论文库的结论。

- [调研报告](report.md)：数据集、模型、奖励机制与 P0/P1/P2 阅读顺序。
- [调研简报](brief.md)：纳入与排除标准。
- [检索日志](research-log.md)：查询范围、核验过程与停止条件。
- [来源证据表](sources.jsonl)：每个结论的来源、页码、质量和局限。
- [证据 PDF](证据)：近期医疗时序与医疗离线强化学习的全文副本。

## 立即开始

1. 阅读 Flusion 和 CDC FluSight Hub，冻结流感目标、数据版本与概率评分。
2. 使用 Chronos 小型版建立零样本和微调基线，记录双 L40 的峰值显存。
3. 精读 medR 的奖励函数；仅将其作为未来决策层的奖励设计参考，不当作流感预测损失。
