# A4 桥接：只用编码的 MIMIC-IV-ED 流感队列重跑方案（2026-10-30）

只含聚合量。锁定前写成，锁定后不改；要改就另立新版本。

## 1. 依据

- **D101**（2026-10-30，A 档，研究者决定）：MIMIC-IV-ED 流感只用 ED 诊断编码 J09/J10/J11/487/488。新版本 `derived/public_mimic_ed_20261030_codeonly`、`derived/public_mimic_hosp_20261030_codeonly`，A4 训练队列 674 → 652 例。见 `logs/2026-10-30/mimic_ed_flu_codeonly_rebuild.md`。
- 研究者 2026-10-30 对"A4-1、A4-2 是否用 652 例队列作为新的锁定版本重跑"回复"Plan and lock it"。

本方案是 A4 的一个新版本。它只把训练队列按 D101 换掉，其余口径一律沿用 9-27/9-28 的运行（`桥接实验结果.md`），不借机修别的问题。

## 2. 要回答的问题

用 652 例队列训练后，A4-1（E0′、E1）、A4-2（E0′）和 A4-4（GAM 截距重校准）在 GD、GAM 上的结果与 674 例相比变了多少。

## 5. 复现对照臂

`experiments/rw_gam2gd/` 的 `cohort.py`、`features.py`、`models.py`、`evaluate.py` 在 9-27 之后都改过：与 `logs/2026-09-27/rw_gam2gd_plan_lock_20260927.txt` 里的 sha256 都不同，`evaluate.py` 还是在 A4 运行之后改的。A4 当时用的代码版本没有留档（`archive/code_snapshots/20261001_pre_cdm_v3` 也不是那个版本）。

所以新版本和 9-27 结果的差，可能一半来自代码改动。为把两者分开，同一份脚本、同一时刻再跑一次 9-27 的 674 例队列（复现对照）：

- Δ代码 = 复现对照 − 9-27 原结果
- Δ队列 = 新版本 − 复现对照（D101 的影响）

复现对照只是重算已锁定的 9-27 分析，不调参、不改口径。

## 6. 外部验证集

GD、GAM 在 9-27 已经评价过一次。本版本会对它们再评价两次（复现对照、新版本），登记为 A4 的新版本。

- 看到结果后不改任何口径。
- 结果不论好坏都报告。
- 差值只给点估计，不做显著性检验（检验方案没有定，属于 A 档）。

## 7. 已知问题（本版本不修，沿用）

1. E1：MIMIC 侧有 15 个 stay 没有链接到住院（两个版本都是 15）。它们在 `e1_label_audit.csv` 里已经写成 `e1=0`：审计生成时就补了 0，脚本里的 `fillna(0)` 实际没有触发。也就是说，未知标签按阴性处理，9-27 报告已列为需修复。
2. A4 的 E0′ 是 ICU/死亡，与总体方案的 E0′（IMV/死亡）同名不同义。
3. 输入只有首日体征，没有住院检验。
4. A4-2 的 GAM_secondary 也在训练集里，不是外部验证，只看 GD。
5. 医院侧用 9-27 的对齐版本，不反映之后的对齐与标签修订（GAM 裁定等）。
6. 结果仍属阶段性初筛，不是完整 A4 验收。

## 8. 预检与停止条件

- **预检**：锁定前先跑 `--dry`。它只构造样本与特征，打印各集合的 n、事件数、变量和"未知标签按 0 补"的个数，不训练、不评价。预检结果写进锁定文件。
- **队列子集检查**：脚本断言新队列 652 例的 MIMIC 标签（E0′、E1）与 9-27 版里同一就诊的标签完全相同。
- **停止条件**：断言失败或运行报错时停下报告，不改定义把流程跑通。
- 复现对照的医院侧 n、事件数如果与 9-27 不同（当前 `cohort.py` 的变化所致），照常记录，不作停止条件。新版本与复现对照用的是同一套医院样本，Δ队列不受影响。

**预检结果**（2026-10-30，`logs/2026-10-30/a4_codeonly_dry_<版本>.log`）：

| 实验 | 复现对照：训练 n / 事件 | 新版本：训练 n / 事件 | GD n / 事件 | GAM n / 事件 | 变量 |
|---|---|---|---|---|---|
| A4-1 E0′ | 674 / 110 | 652 / 108 | 292 / 35 | 173 / 16 | VS001–VS006 |
| A4-2 E0′ | 847 / 126 | 825 / 124 | 292 / 35 | 173 / 16 | VS001–VS006 |
| A4-1 E1 | 674 / 110 | 652 / 108 | 292 / 38 | 173 / 20 | VS001–VS006 |

- 复现对照的各项计数和变量与 9-27/9-28 的 `metrics.json` 完全相同，医院侧样本没有因代码改动而变化。
- 新版本去掉 22 例、2 个事件；三个实验的子集检查都通过。
- 未知标签按 0 补的个数为 0。
- MIMIC 侧 E0′ 与 E1 的事件数都是 110（新版本都是 108）。
