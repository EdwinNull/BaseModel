## 2 总体设计

### 2.1 三类不需要人工裁定的监督信号

| 信号 | 从哪来 | 能回答 | 不能回答 | 用在 |
|---|---|---|---|---|
| 未来观测 | t0 之后真实记录的生命体征、检验值 | 模型对生理轨迹预测得准不准、预测分布是否校准；可作为强化学习的可核对奖励 | 患者是否"转重"（需要临床定义） | F1、F4、P1、P4 |
| 结构化事件 | 公开数据中按规则导出的有创通气、升压药、死亡（mimic-code 概念或 ricu 概念） | 风险模型的判别与校准；奖励设计的效果 | 医院的"重症"口径：GD 的 CRF 语义需要对齐，GAM 侧需要裁定 | F2、F3、F5、P2、P3、AL4、AL5 |
| 归属 | 样本属于哪家医院、哪个年龄层、哪种模态 | 分布差在哪里；对齐方法能缩小多少 | 对齐之后预测是否更准（仍需结局标签来评价） | AL1、AL3、AL4 |

另有两类可以自动生成的辅助信号：教师模型（LightGBM 的袋外概率，用作 P3 的 SFT 目标），以及规则证据（09-25 方案附录 A 的证据代码，用于 P3 的证据奖励）。

### 2.2 三条线之间的关系

```
阶段 0：数据视图 V1–V5、各模型环境与权重、统一评价库、锁定与冒烟
   │
   ├─ F 线（选底座、找机制）
   │    F1 零样本预测 ──→ F4 预测即预警
   │    F2 冻结表示 ──→ F3 观测密度压力测试；F5 监督适配
   │
   ├─ P 线（奖惩机制）
   │    P0 推导与模拟 → P1 TSFM 预测强化学习（底座来自 F1；后训练得到的编码器回到 F2 测风险迁移）
   │    P2 风险头训练目标（底座来自 F2）
   │    P3 LLM 风险 GRPO（承接 09-25 方案）；P4 可选
   │
   └─ AL 线（对齐）
        AL1、AL2 医院（以 CPU 为主）；AL3 公开→医院桥接
        AL4 域适应（底座来自 F2）；AL5 跨模态（编码器来自 F2）
```

### 2.4 本轮不做

| 不做 | 原因 |
|---|---|
| 用规则或 LLM 标签代替裁定，得出医院"重症"主结论 | A 档；这类标签只能作为 AL2 的敏感性证据 |
| 治疗或资源决策的强化学习 | 医院数据没有完整的动作日志；治疗侧离线强化学习的回顾性策略价值也不能单独证明临床获益（09-23 报告 C010） |
| EHR 事件序列基础模型（MOTOR、ETHOS 等，S017、S019） | 需要全量编码事件流（OMOP/MEDS）；医院数据几乎没有编码；投入大，且与本项目的输入不匹配 |
| TTRL 式自洽伪标签强化学习（N25） | 原方法用于有确定答案的推理题。在罕见结局上，组内多数票会强化模型自身的偏差，而且没有可核对的信号 |
| 在线闭源模型对照 | PhysioNet 数据使用协议（DUA） |
| 公开发布在 MIMIC/eICU 上训练的权重 | 同上 |

### 5.1 P0 推导与模拟校验（先于任何 GPU 强化学习）

**P0-a**：加权适当评分规则的 p* 偏移（即 09-25 方案的 E4-0）。用 LightGBM 在 CPU 上跑，约 10 分钟。

**P0-b**：生成式预测的能量分奖励。本计划推导，是否已有文献专门讨论未做系统检索。

- 能量分 ES(P, y) = E‖X−y‖ − ½E‖X−X′‖，是严格适当的评分规则（N28）；一维时就是 CRPS 的样本形式。
- 对策略参数求梯度：∇ES = E[(‖X−y‖ − E_{X′}‖X−X′‖)·∇log p(X)]。成对项里两个样本都来自策略，梯度加倍，所以单样本奖励中成对项的系数应取 **1** 而不是 ½：r_i = −‖x_i−y‖ + mean_{j≠i}‖x_i−x_j‖。E[r_i] 不等于 −ES，但两者的梯度相同。
- GRPO 的组均值基线包含样本自身，而 r_j 又通过成对项依赖 x_i，两者叠加，使成对项的有效系数变为 ½·(G−2)/(G−1)，G=8 时为 0.43。在高斯情形下，不动点 σ* = √(2c²/(1−2c²))，G=8 时为 0.76，因此预测分布会**系统性偏窄**。
- **修正**：
  - 误差项用其余样本误差的均值作基线；
  - 成对项用"不含样本 i 的样本对"的平均距离作基线；
  - 两个基线都与 x_i 无关，因而无偏；
  - 不按组内标准差缩放，改用跨步的全局尺度。
- **玩具模拟**（本机，2026-10-04；策略 N(μ, σ²)，真值 y~N(0, 1)，理想结果 σ=1；6,000 步，5 个种子取均值；脚本见附录 A.3）：

  | 奖励 | 优势估计 | G | 收敛的 σ（理想为 1） |
  |---|---|---|---|
  | −\|x−y\| | 组均值 | 8 | 0.077 |
  | −(x−y)² | 组均值 | 8 | 0.049 |
  | −\|x−y\| | 组均值 + 组内标准差 | 8 | 0.009 |
  | 能量分（照抄公式，成对项系数 ½） | 组均值 | 8 | 0.325 |
  | 能量分（系数 1） | 组均值 | 4 / 8 / 16 | 0.57 / 0.78 / 0.85（推导值 0.54 / 0.76 / 0.88） |
  | 能量分（系数 1） | 组均值 + 组内标准差 | 8 | 0.52 |
  | 能量分（系数 1） | 留一基线 | 4 / 8 / 16 | 0.96 / 1.06 / 0.97 |
  | 能量分（系数 1） | 留一基线 + 全局尺度 | 4 / 8 / 16 | 0.97 / 1.07 / 0.96 |

- **对 P1 的设计约束**：
  - R-f 一律使用留一基线；
  - 其他奖励比较"组均值 + 组标准差"与"只减均值"两种优势估计；
  - 正式实验前，在真实 TSFM 上用 100 个窗口复现这张表的方向。

**P0-c**：奖励函数单元测试，检查取值范围、单调性、尺度不变性、缺失掩码，以及 SpO2 长时间为 100% 的平坦序列在尺度下限下的行为。

### P1 TSFM 预测强化学习（不需要标签）

- **目的**：在完全不需要标签的条件下，系统比较奖励形式、优势估计与优化算法对临床时序基础模型的影响。这是本计划中最"干净"的奖惩机制实验：奖励全部由未来观测核对，没有标签噪声。
- **数据**：
  - 训练：V4 中 MIMIC 1 小时级任务的训练集患者；
  - 测试：MIMIC 测试患者（同分布）；eICU 1 小时级（跨中心）；MC-MED 5 分钟级（跨场景，可选）。
  - 主设置（AD3）：上下文 48 小时、预测 12 小时；变量为心率、呼吸、SpO2、平均动脉压、体温，逐通道单变量。
- **策略模型**：
  - 核心：Chronos-T5-small。它的 token 似然精确，与 LLM 同构，实现最简单；
  - 复核：Lag-Llama（Student-t）、Moirai-MoE-small（混合分布）；
  - Sundial 没有显式似然，只做 RAFT；
  - 确定性模型（Chronos-Bolt、TimesFM-2.5、Time-MoE、MIRA）只做 P1-D。
- **实验网格**：

  | 组 | 底座 | 变化 | 次数 |
  |---|---|---|---|
  | P1-A 奖励 | Chronos-T5-small | R-a、R-b、R-c、R-d、R-e、R-f（留一基线）、R-g、R-c + R-h | 8 × 3 种子 |
  | P1-B 优势与稳定化 | Chronos-T5-small；奖励取 R-c 与 R-f | 组均值 + 组标准差 / 只减均值 / 留一 + 全局尺度 / 真值入组 / GTN-R；β ∈ {0, 0.001} | 约 12 × 2 种子 |
  | P1-C 算法 | Chronos-T5-small | 零样本、SFT（原生交叉熵）、RAFT、DPO（同组最好与最差配对）、GRPO（P1-A 最佳奖励）；按训练样本数和近似算力对齐 | 5 × 3 种子 |
  | P1-D 损失即奖励 | 确定性模型 | MSE、MAE、Huber、分位数损失；LoRA 与全参（≤50M） | 约 30 次 |
  | P1-E 复核 | Lag-Llama、Moirai-MoE-small | P1-A 中最好的 3 个奖励 | 2 × 3 × 3 种子 |

- **训练设置**（起点，E-1 探针后再定）：
  - 组大小 G=8，每步 64 个窗口；
  - 学习率：小模型全参 1e-5，LoRA 1e-4；训练 1 个 epoch；
  - KL 的参考模型为初始模型；
  - 采样温度 1.0，不做截断，以保持策略梯度无偏；
  - 按验证集 WQL 早停。
- **指标**：
  - 准确度：WQL、MASE、CRPS（100 个样本）；
  - 校准与锐度：覆盖率@80/95、区间宽度；
  - 事件：AUROC、Brier（定义同 F1）；
  - 外推：eICU 上的同一组指标。
- **训练监控**：近零方差组比例、有效优势比例、KL、样本标准差（塌缩信号）、覆盖率漂移。
- **迁移检验**：把最佳 P1 检查点的编码器放回 F2 做风险探针，看无标签后训练能否改善风险表示。F2 的协议不变。
- **主假设**（AD6，从中预登记 1–2 个）：
  - **H-P1a**：点误差类奖励（R-a 至 R-e）使覆盖率@80 比零样本低 ≥10 个百分点（分布塌缩）；R-f（留一基线）使覆盖率保持在名义值 ±5 个百分点以内。
  - **H-P1b**：有界或相对奖励（R-b、R-c、R-e）的近零方差组比例与测试 WQL 都优于 R-a。
  - **H-P1c**：R-g（不适当的事件奖励）提高事件灵敏度，但事件 Brier 比 R-f 差。
  - **H-P1d**：最佳强化学习配置与同底座 SFT 相比，在 MIMIC 测试集和 eICU 上的 WQL 差值。S006 以"可泛化的预测"为目标；09-23 报告记录的同类工作中，强化学习相对监督微调的追加提升通常很小（S001、S007）。这里在临床数据上检验。
- **算力**（估计）：Chronos-T5-small 单次 1–3 小时（单卡），P1-A/B/C 约 50 次，合计 3–5 卡·天；P1-D、P1-E 约 2–3 卡·天。E-1 实测后替换。
- **实现**：TRL 的 GRPOTrainer 面向文本 LLM，不能直接用于 TSFM。写一个约 300 行的最小 GRPO/PPO-clip 循环（`reward_bench/grpo_tsfm.py`），奖励与优势函数用附录 A；分别为 Chronos-T5（token 似然）、Lag-Llama 与 Moirai（分布似然）实现 `log_prob(samples | context)`。

### P2 风险头的训练目标（监督学习中的"奖惩"）

- **目的**：在最便宜的设置里检验"把奖惩写进损失"会怎样改变判别与校准，为 P3 的奖励选择提供对照。
- **底座**：LightGBM（手工特征）；F2 最好的 TSFM 冻结嵌入 + MLP 头。数据用 V1，≥65 岁为主评估人群。
- **目标函数**：BCE、Brier、焦点损失（γ=2，N46）、类加权 BCE（w=3、10）、AUC 代理（LibAUC 的 AUC-M）、AP 代理（N40），以及 24/48/72 小时联合的离散时间风险模型。每种之后再接事后校准（Platt、保序回归）。
- **主检验 H-P2**：类加权后，平均预测的偏移与 p* = wq/(wq+1−q) 的预测一致，延续 C020。AUC 与 AP 代理相对 BCE 的 ΔAUPRC、ΔBrier 只作描述。
- 5 个种子，以 CPU 为主，单卡数小时。

### P3 LLM 风险预测强化学习（承接 09-25 方案）

- 沿用 09-25 方案 §6–§7：SFT-cls / SFT-cot，G0–G9 组，假设 H2–H4、H6。数据换成 B1v2。
- 新增组（Qwen3-1.7B，各 3 个种子）：
  - **G10 年龄层优势重加权**（DRPO 式，S021）：按 ≥85、75–84、65–74、<65 分层，T = max(√N·μ, ε)。检验老年分层的 AUPRC 与 Brier。
  - **G11 离线偏好**：从 SFT-cot 对每个提示采样 8 条，按 Brier 取最好与最差配对做 DPO（β=0.1），或按阈值做 KTO（N42）。与 G1 在相同提示数下比较。
  - **G12 时效效用奖励**（PhysioNet 2019 式，S047）：窗口常数只是占位，正式使用需与临床约定。预期会破坏校准，作为"不适当奖励"的对照。
- **依赖**：`.venv_rl`、Qwen3-1.7B/4B 权重、E-1 探针。
- RLCR（N24）报告"正确性 + Brier"这类有界的适当奖励能同时保持准确率与校准，与 G1 的设计一致，因此不另设 RLCR 组。

### P4（可选）LLM 时序推理强化学习的迁移

- Qwen3-1.7B 以文本形式预测生命体征（Time-R1、TimeMaster 式，S002、S030），奖励用 R-b 或 R-c 加格式分。
- 之后从这个检查点开始做 P3 的 SFT-cot，看"无标签的可核对奖励"能否给风险预测带来增益。

### AL1 医院间的无标签分布对齐诊断与协调

- **目的**：不碰任何结局标签，回答两院差异有多少来自记录方式、多少来自人群，并给出可选的协调方法及其代价。
- **数据**：CDM v3.1 中 T-day 口径的 15 个共享变量（GAM 173 次、GD 297 次住院），加上 V5 的公开来源，构成五源图谱。
- **做法**：
  1. **域分类器分解**：分别只用数值、只用测量过程特征（每个变量的观测次数、时间精度、末位为 0/5 的比例、缺失模式）、两者都用，做患者分组交叉验证，计算 AUROC。现有的 0.709±0.026 作对照。
  2. **协调方法**：每院 z 分数；分位数映射到合并分布；ComBat（以年龄、性别为保护协变量，用 neuroCombat、pycombat 等成熟实现）；末位堆积平滑（对以 0/5 结尾的呼吸、心率记录，在取整区间内均匀抖动，种子固定）。
  3. **评价**（全部不用标签）：协调后域分类 AUROC 与 SMD 下降了多少；院内的临床结构是否保留，包括变量间相关矩阵的差异，以及 URB-65 组分的单调关系是否不变。
- **产出**：哪类差异可以被协调、协调要付出什么代价；作为 AD7 的决策依据。
- **限制**：协调也会抹掉真实的病例构成差异（例如 GD 患者年龄更大），所以结果只作方法学证据。
- **算力**：CPU，约 1 天。

### AL2 裁定价值评估（标签不确定性的界）

- **目的**：在不能裁定的这段时间里，量化"裁定与否会不会改变结论"，帮你判断 S2 的优先级。它**不产生最终标签**。
- **数据**：GAM 173 次住院。已有标签源：规则组件；Qwen3-14B 预标注（呼衰 61 例，解析失败 1 例）；v2 人工裁定（IMV、NIV、ICU、DEATH，1 名裁定人）。**GD 不载入**。
- **做法**：
  1. **来源一致性**（只输出计数）：呼衰上比较规则与 Qwen3-14B；四个组件上比较规则、Qwen3-14B 与 v2 人工（09-28 已有 κ）。
  2. **事件数上下界**：把呼衰分成"两源同为阳性 / 同为阴性 / 不一致"三态，得出 GAM 重症事件数的上下界。
  3. **部分识别的界**：分别用四种标签跑一次 GAM 内部 5×5 交叉验证（LR、LightGBM、TabPFN）：不一致者全记阳性、全记阴性、只用规则、只用 Qwen3-14B。报告 AUROC/AUPRC 的范围，以及模型排序是否变化。
  4. **（可选）潜类别模型**：再加两个本地标注器（Qwen3-8B、DeepSeek-R1-Distill-Qwen-7B；提示词运行前固定，贪心解码），用 Dawid–Skene 潜类别模型（N30）估计每例的后验概率，只报告"高度不确定"的例数。没有人工金标准，模型的条件独立假设无法检验。
- **判读**：
  - 若四种标签下模型排序和 CI 基本不变，说明裁定对"模型比较"的边际价值低，但对事件数与终点定义仍然必要；
  - 若排序翻转，说明 S2 是医院线的硬前提。
- **盲法保护**：
  - 若 S2 可能在 3 周内恢复，暂缓 AL2；
  - 运行时，逐例的中间结果只存 `derived/`（700/600），日志只写聚合量，裁定人不得查看。
- **需要 AD8**。算力：CPU，加上可选标注器的单卡数小时。

### AL3 公开数据 → 医院的桥接与对齐方法

- **前置修复**：
  - 未知标签记为缺失，不再当阴性；

### AL4 公开数据上的多中心与跨年龄域适应基准

- **目的**：在标签可靠的公开数据上弄清：目标域没有标签时，哪些对齐方法真正有用，以及没有目标标签时怎样选超参。这正是 GD 新批次将要面对的情形。
- **场景**：
  - S1：MIMIC-IV → eICU（跨中心）；
  - S2：MIMIC-IV 中 18–64 岁 → ≥65 岁（跨年龄，对应项目关注的老年人群；N19 在 MIMIC-IV 上做过按年龄组的无监督域适应）；
  - S3（可选）：eICU 不同地区的医院之间。
- **任务**：V1/V2 的 Y24 终点，输入为同一个 1 小时视图。
- **方法**：
  - 仅源域（GRU、TCN）；
  - DANN、Deep CORAL、MMD；
  - CLUDA（官方代码）、RAINCOAT；
  - AdaTime 中的其余方法（N35）；
  - TSFM 冻结嵌入 + LR，检验预训练本身是否减小漂移；
  - TENT 式测试时适应；
  - 只做重校准：需要少量目标标签，作为参照上界。

- **主假设 H-AL4**（AD6）：多数无监督域适应方法相对"仅源域 + 重校准"的 ΔAUPRC，其 CI 含 0；不用标签的选择与上界之间存在可观的差距。

### AL5 跨模态对齐：时序 ↔ LLM

- **目的**：在同一个风险任务上比较几种把时序接进 LLM 的对齐方式，并用"去 LLM 消融"检验 LLM 是否必要。N22 在通用预测上发现，去掉 LLM 后性能并不下降。
- **数据**：V1 的 Y24，按患者抽训练子集（例如 2 万个 landmark）。
- **臂**：
  1. 文本序列化 + 零样本（Qwen3-8B / 14B）；
  2. 文本序列化 + SFT（Qwen3-1.7B，LoRA，即 P3 的 SFT-cls）；
  3. 软提示：时序编码器 + 投影到 LLM 嵌入空间。用 OpenTSLM-SP 1B 在本任务上微调（S031）；ChatTS（N23）是同类思路；
  4. 去 LLM 消融：同一编码器和投影，把 LLM 换成 2 层 Transformer 或 MLP 分类头；
  5. 参照：F2 最好的 TSFM 嵌入 + LightGBM；TabPFN（摘要特征）。
- **指标**：AUPRC、Brier、ECE、解析失败率、训练与推理卡时。
- **主假设 H-AL5**：臂 4 相对臂 3 非劣（ΔAUPRC 的非劣界为 −0.02）。
- **算力**：约 2–3 卡·天。

### A.1 奖励（`reward_bench/rewards.py`，规划稿）

```python
"""P1 预测奖励与优势估计（规划稿参考实现，只依赖 numpy）。

约定：
- samples: (G, H) 数组，同一个上下文下策略采样出的 G 条未来轨迹，已还原到原始单位。
- y:       (H,) 真实未来；mask: (H,)，1 表示该时刻有真实观测，缺失点不计分。
- scale:   窗口的误差尺度，由上下文计算（window_scale），让不同患者、不同变量的奖励可比。
每个函数都要有虚构数据单元测试（P0-c）。
"""
import numpy as np

# 每个变量的尺度下限。SpO2 常年 100% 时上下文几乎不变，不设下限会让归一化误差爆炸（LF8）。
SCALE_FLOOR = {"HR": 1.0, "RR": 0.5, "SPO2": 0.5, "MAP": 1.0, "TEMP": 0.1}


def window_scale(context, var):
    """上下文的稳健尺度：一阶差分绝对值的均值（MASE 分母的思路），再与变量下限取大者。"""
    c = context[~np.isnan(context)]
    s = float(np.mean(np.abs(np.diff(c)))) if len(c) > 1 else 0.0
    return max(s, SCALE_FLOOR[var])


def _masked(samples, y, mask):
    """只保留有真实观测的时刻（G 条轨迹与真值同步截取）。"""
    m = mask.astype(bool)
    return samples[:, m], y[m]


def r_neg_mse(samples, y, mask, scale):
    """R-a 负均方误差，无界。作为对照：一个很差的样本会抬高组内标准差，压扁其他样本的优势（S005）。"""
    x, t = _masked(samples, y, mask)
    return -np.mean(((x - t) / scale) ** 2, axis=1)


def r_inverse(samples, y, mask, scale, k=20.0):
    """R-b 倒数误差 1/(1+k·δ)，δ 为归一化平均绝对误差，取值 (0,1]（REATS，S005；δ 的原文定义执行前核对）。"""
    x, t = _masked(samples, y, mask)
    delta = np.mean(np.abs(x - t) / scale, axis=1)
    return 1.0 / (1.0 + k * delta)


def r_exp_accuracy(samples, y, mask, floor):
    """R-c 指数精度：误差按真实未来的标准差归一化后取 exp(-·)，取值 (0,1]。
    这是 TimeRFT 精度项（S006）的整段平均简化版；原文按每个预测块、每个变量计算并逐步分配信用。"""
    x, t = _masked(samples, y, mask)
    sd = max(float(t.std()), floor)
    return np.exp(-np.mean(((x - t) / sd) ** 2, axis=1))


def _softmax(z):
    z = z - z.max(axis=-1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)


def r_variation(samples, y, mask, floor):
    """R-d 中的波动项：把预测段与真实段各自做 softmax，得到"起伏形状"的分布，奖励 exp(-KL)。
    只看形状、不看绝对水平，用来对抗精度项导致的过平滑（S006，权重 0.1）。"""
    x, t = _masked(samples, y, mask)
    sd = max(float(t.std()), floor)
    p = _softmax((x - t.mean()) / sd)                 # (G, H')
    q = _softmax(((t - t.mean()) / sd)[None, :])      # (1, H')
    kl = np.sum(p * (np.log(p + 1e-12) - np.log(q + 1e-12)), axis=1)
    return np.exp(-kl)


def r_relative(samples, y, mask, base_forecast, scale, floor_err=0.01):
    """R-e 相对改进：相对基础预测（零样本或 SFT 模型的中位数预测）的误差下降比例，裁剪到 [0,1]（PostTime，S007）。
    基础预测已经很好时，分母接近 floor_err，任何偏离都得 0 分，需要监控"无梯度"的比例。"""
    x, t = _masked(samples, y, mask)
    b = base_forecast[mask.astype(bool)]
    e_i = np.mean(((x - t) / scale) ** 2, axis=1)
    e_b = float(np.mean(((b - t) / scale) ** 2))
    return np.clip((e_b - e_i) / max(e_b, floor_err), 0.0, 1.0)


def energy_loo_advantages(samples, y, mask, scale):
    """R-f 能量分奖励的无偏优势（留一基线）。直接返回优势，不返回奖励。

    能量分 ES(P,y) = E||X-y|| - 0.5·E||X-X'|| 是严格适当评分规则（Gneiting & Raftery 2007）。
    成对项中两个样本都来自策略，梯度加倍，所以单样本奖励取
        r_i = -||x_i - y|| + mean_{j≠i} ||x_i - x_j||   （成对项系数为 1）
    r_j 通过成对项依赖 x_i，若用 GRPO 的组均值基线，会把成对项的有效系数压到 0.5·(G-2)/(G-1)，
    预测分布系统性偏窄（P0-b：G=8 时 σ=0.78，理想值 1）。因此两项分别用与 x_i 无关的基线：
      误差项：其余 G-1 个样本误差的均值；
      成对项："不含样本 i 的所有样本对"的平均距离。
    要求 G >= 3。"""
    x, t = _masked(samples, y, mask)
    x, t = x / scale, t / scale
    G = x.shape[0]
    d = np.linalg.norm(x - t, axis=1)                                # 每条轨迹到真值的距离
    P = np.linalg.norm(x[:, None, :] - x[None, :, :], axis=2)        # (G,G) 两两距离，对角线为 0
    a_err = -d + (d.sum() - d) / (G - 1)
    spread = P.sum(axis=1) / (G - 1)
    pairs_without_i = (P.sum() / 2.0 - P.sum(axis=1)) / ((G - 1) * (G - 2) / 2.0)
    return a_err + (spread - pairs_without_i)


# 评测用生理事件：沿用 09-25 方案附录 A 的阈值。只用于评测与 R-g，不是告警阈值（AD4）。
EVENTS = {
    "SPO2": lambda v: v <= 91,
    "RR": lambda v: v >= 25,
    "HR": lambda v: v >= 111,
    "MAP": lambda v: v < 65,
}


def has_event(traj, var, min_consecutive=2):
    """轨迹中是否出现连续 >= min_consecutive 个点满足阈值；要求连续是为了减少单点伪迹。"""
    run = 0
    for hit in EVENTS[var](traj):
        run = run + 1 if hit else 0
        if run >= min_consecutive:
            return True
    return False


def r_event(samples, y, mask, var):
    """R-g 事件一致性（不是适当评分规则，作对照）：采样轨迹与真实轨迹"是否出现事件"一致得 1 分。
    事件罕见时，"永远预测不发生"也能拿到很高的期望奖励。"""
    x, t = _masked(samples, y, mask)
    e_true = has_event(t, var)
    return np.array([float(has_event(xi, var) == e_true) for xi in x])


# 生理合理范围与相邻两点的最大变化（下限, 上限, 最大单步变化）。
# 示例值按 1 小时采样设定；执行时以 alignment/common.py 的 apply_plausibility 为准，并按采样间隔调整。
PLAUSIBLE = {"HR": (20, 250, 40), "RR": (4, 60, 15), "SPO2": (50, 100, 10),
             "MAP": (20, 200, 40), "TEMP": (32, 43, 1.5)}


def penalty_plausibility(samples, var):
    """R-h 约束层：任一点越出合理范围，或相邻两点变化超限，记 -1，否则记 0。与主奖励相加使用。"""
    lo, hi, max_step = PLAUSIBLE[var]
    bad_range = ((samples < lo) | (samples > hi)).any(axis=1)
    bad_step = (np.abs(np.diff(samples, axis=1)) > max_step).any(axis=1)
    return np.where(bad_range | bad_step, -1.0, 0.0)
```

```python
def group_advantages(r, mode="grpo"):
    """适用于不依赖组内其他样本的奖励（即 R-f 以外的全部奖励）。
    grpo：减组均值，再除以组内标准差（GRPO 默认）；
    mean：只减均值（Dr. GRPO 的建议，N26；对应 09-25 方案的 G7 组）。"""
    a = r - r.mean()
    if mode == "grpo":
        a = a / (r.std() + 1e-6)
    return a


class GlobalScale:
    """跨步的全局优势尺度（指数滑动平均）。P0-b 中它不改变 σ 的收敛点，可以替代组内标准差。"""

    def __init__(self, decay=0.99):
        self.decay, self.v = decay, None

    def __call__(self, a):
        m = float(np.mean(a ** 2))
        self.v = m if self.v is None else self.decay * self.v + (1 - self.decay) * m
        return a / np.sqrt(self.v + 1e-8)


def near_zero_std_fraction(reward_groups, tol=1e-3):
    """近零方差组比例：组内奖励几乎相同的组对梯度没有贡献（PostTime 报告从 27.97% 降到 4.66%，S007）。"""
    return float(np.mean([np.std(g) < tol for g in reward_groups]))
```

用 score function 估计梯度：d log p / d mu = eps/sigma，d log p / d log_sigma = eps^2 - 1。"""
import numpy as np


def run(kind, G=8, steps=6000, lr=0.02, seed=0):
    rng = np.random.default_rng(seed)
    mu, log_s, gscale = 1.0, np.log(0.3), GlobalScale()   # 故意从偏离、过窄的初值出发
    for _ in range(steps):
        s = np.exp(log_s)
        y, eps = rng.normal(), rng.normal(size=G)
        x = mu + s * eps
        if kind == "abs_grpo":                              # 点误差奖励 + 组均值基线
            a = group_advantages(-np.abs(x - y), mode="mean")
        elif kind == "energy_grpo":                         # 能量分奖励 + 组均值基线（有偏）
            r = -np.abs(x - y) + np.abs(x[:, None] - x[None, :]).sum(1) / (G - 1)
            a = group_advantages(r, mode="mean")
        else:                                               # 能量分 + 留一基线 + 全局尺度（无偏）
            a = gscale(energy_loo_advantages(x[:, None], np.array([y]), np.ones(1), 1.0))
        mu += lr * np.mean(a * eps / s) * s                 # 乘 s 只为步长稳定，不改变不动点
        log_s = np.clip(log_s + lr * np.mean(a * (eps ** 2 - 1)), np.log(1e-3), np.log(10))
    return mu, float(np.exp(log_s))
