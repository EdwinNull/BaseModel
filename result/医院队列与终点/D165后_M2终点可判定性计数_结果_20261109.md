# D165 后 M2：两院呼吸恶化终点可判定性计数结果

2026-11-09。对应执行方案 v2（`plans/医院队列与终点/D165后_两院呼吸恶化终点核验与前瞻验证_执行方案_v2_20261108.md`）第四节，以及 Codex 的列映射与交接文档。研究者在本机运行计数脚本，交回的是区间化的聚合报告；本文只引用其中的区间数，没有接触病例。所有口径都是候选口径，没有计算任何模型分数，也没有登记 D 编号。

## 结论

两院共用一个 7 天阶梯终点，在回顾数据上做不成。卡住的是 GAM，原因在结构上，跟事件多少无关：GAM 的 primary 风险集里，没有一个人能确认预测时点是"未吸氧"（L0 为 0），基线支持未知的有 70–79 人。所以 L0→L1 这一级在 GAM 无从判定，7 天阶梯终点的未知数大于事件数，过不了 G1。GAM 能用的只有两部分：高于低流量的共同分量（高流量/无创及以上、诊断类、死亡），整个住院期 10–19 个事件；以及只算呼吸≥30 的生理口径。

GD 的阶梯终点在结构上可以判定。基线支持靠医嘱推断，几乎都能定下来（L0 80–89、L1 110–119、未知 <10）；升级时间来自医嘱，精度到分钟；整个住院期的复合终点按区间判断通过 G1。但事件只有 20–29 个（7 天内 10–19 个），处在 v2 第七节的前两档：只能做描述和预先指定的固定评分。另外，L0 本身是医嘱推断出来的，有效性待核实。

生理类口径做不成复合终点。按 3.3 定义的"已核实新发生理恶化"，GD 的确认阴性不到 10 人，GAM 为 0，原因是吸空气 SpO2 和 P/F 对几乎所有人都无法确认阴性。生理类里只有只算呼吸≥30 的版本（D126）有像样的阴性集合；但 GD 的呼吸记录高度模板化，GAM 的呼吸≥30 多数在下一次测量就恢复了。

按 v2 第六节的分支，结论落在"只有一院可判定"：GD 做描述和人工核验试点，GAM 只报计数，两院共同终点转由前瞻采集解决。这个分支属于 A 档，由研究者确认。

## 一、未知从哪里来

| 项目 | GD | GAM |
|---|---|---|
| primary 风险集：基线 L0 / L1 / 未知 | 80–89 / 110–119 / <10 | 0 / 10–19 / 70–79 |
| 基线靠"结束时间缺失按仍在用"定下来的（全部索引住院） | 10–19 | 40–49 |
| 7 天阶梯：E / 确认阴性 / U | 10–19 / 170–179 / <10 | <10 / 70–79 / 10–19 |
| 7 天共同分量（≥L2、诊断类、死亡）：E / 阴性 / U | 10–19 / 180–189 / <10 | <10 / 70–79 / <10 |

| 次要终点"呼吸支持升级或死亡"，7 天：E / N / U | 60–69 / 260–269 / <10 | 10–19 / 90–99 / 10–19 |

GAM 的未知集中在 L1 这一级：7 天内 L1 分量的确认阴性为 70–79，U 为 10–19。原因就是基线是否吸氧无法确认。GAM 没有氧疗医嘱，SpO2 记录也从不和吸氧状态写在同一行（T4 中各组均为 0 行），"未吸氧"拿不到正面依据。升到 L2 及以上的事件不受基线未知影响，但时间来自病历和护理正文的书写时间（精度为 note），新发类别只能记为"首测即异常"。

GD 的未知很少，问题在别处：L0 是从"没有生效的氧疗医嘱"推出来的。预测时点后新开低流量氧、却没有低氧佐证的，7 天内 20–29 人，整个住院期 30–39 人；按 D87 的写法，这些都不算事件。GD 预测时点后 SpO2 每天的测量次数，事件组和无事件组的中位数都是 0，所以"有没有低氧佐证"在 GD 主要反映有没有测，不一定反映病情。新开氧疗到底是常规还是病情变化，要靠 C2 的答复和人工核验判断。

## 二、primary 与阶梯的分歧从哪里来

Codex 的规则探针发现过一种分歧机制：同级别低流量医嘱重新开立，可以触发 primary 事件。真实数据里这种情况没有发生。GD 基线 L1、预测后又有低流量医嘱的就诊有 20–29 次（医嘱 40–49 条），但由这些医嘱触发 D87、而阶梯上没有升级的事件为 0。GAM 没有氧疗医嘱，这一项也是 0。

GD 的实际分歧主要来自结局窗。primary 是整个住院期的取值；在 7 天窗内，primary 事件里阶梯判为事件的 10–19 个、判为阴性的也是 10–19 个；换到整个住院期，阶梯判为阴性的降到 <10 个。剩下的少数 primary 事件阶梯判为阴性，从分量表推断，可能是 ICU 或升压药触发的：GD 整个住院期升压药 10–19 个、ICU <10 个，这两项在 v2 里单列为硬结局，不在阶梯上。这一点需要研究者用本机精确表核对。GAM 整个住院期没有"primary 事件、阶梯阴性"的情况。

"支持未变的生理命中"，GD 整个住院期 10–19 个，GAM <10 个。这些只进生理敏感性口径。

## 四、测量过程与记录质量

呼吸频率的记录明显是估出来或套模板的：

| 项目 | GD（来源：操作记录） | GAM（来源：护理表格） |
|---|---|---|
| 呼吸记录条数 | 3550–3559 | 3100–3109 |
| 恰为 20 | 1670–1679（约 47%） | 520–529（约 17%） |
| 恰为 18 | 550–559（约 16%） | 850–859（约 27%） |
| 末位为 9 | 740–749（约 21%） | 310–319（约 10%） |
| 取 16、18、20、22 合计 | 约 67% | 约 60% |
| ≥3 个时刻且全程同一数值的就诊 | 10–19 / 190–199 | 0 / 80–89 |

GD 近一半的呼吸记录恰好是 20，呼吸≥30 的事件不到 10 个，所以呼吸分量在 GD 基本提供不了信息。GAM 的数值分布宽一些，但呼吸≥30 首次命中后 4 小时内有机会复测的，恢复的有 10–19 个，再次≥30 的不到 10 个。GAM 的生理类事件 93% 由呼吸触发（J 线），也就是说，它们多数是单次读数。这并不能证明这些读数是伪差，但支撑不了"持续的呼吸恶化"这种解读。

血气和 SpO2 的测量跟着病情走。GD 预测后做过血气的，阶梯事件组 10–19 人里几乎都做过，无事件组 170–179 人里不到 10 人；physiologic 风险集里，做过血气的事件比例为 40–49 / 50–59，没做过的为 10–19 / 210–219。GD 预测后的 SpO2 记录也几乎只出现在事件组（280–289 行，无事件组不到 10 行）。P/F 首次命中后 4 小时内没有复测的有 10–19 个。GAM 做过血气的事件比例为 10–19 / 20–29，没做过的为 10–19 / 90–99。这与 J 线"GD 生理类事件依赖是否开了血气"的结论一致。

GAM 同一分钟、同指标、同值的重复体征记录去重了 7530–7539 行（GD 为 1140–1149 行），提示同一读数被多个来源重复录入。脚本已显式去重，计数不受影响。

## 六、其他可以排除的担心

死亡但没有可确认支持升级的，两院都是 0；预测时点前已有治疗受限的，两院都 <10，排除治疗受限的敏感性候选与主候选落在同一区间。A4 的取舍对计数影响很小。GD 7 天内离院的有 80–89 人，占风险集四成多；他们在 7 天窗里按无事件处理，这条假设属于 A5，要在核验中抽查。

导出的 D0 列与说明书"入院即重型"的含义对不上：在 primary 风险集内，D0 = event 的人数与 O1 事件数相当，阶梯事件也全部落在这部分人里，看起来更像"住院期任一时刻达到重型"。规则文档 v0 对 D0 的定义正是"住院期间任一时刻达到重型及以上"，与说明书第 8 节不一致。v2 第二节引用的"入院即重型 GD 56%、GAM 33%"需要研究者确认出处的口径。
