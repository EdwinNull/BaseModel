01

八条主要发现

每条下方一行写的是它对后续工作的含义。数字为 3 个 seed 的均值，另有说明的除外。

发现 1

删得越多，区分度降得越多

drop40 的 ΔAUPRC：BRITS −0.032、mTAND −0.022、Raindrop −0.023，9 个 run 的 95% CI 都不含 0。drop20 时较小（−0.016、−0.009、−0.007），CI 不含 0 的 run 分别为 3/3、2/3、0/3。

所以：删 20% 时，只有 BRITS 每个 seed 都测得出下降。
见 06 删减影响
发现 2

删连续 5 分钟：AUPRC 看不出，AUROC 看得出

三个模型的 ΔAUPRC 都接近 0，9 个 CI 全部含 0；但 BRITS、Raindrop 的 ΔAUROC 约为 −0.017、−0.020，6 个 CI 全部不含 0。mTAND 的 ΔAUROC ≈ 0。

所以：只报 AUPRC 会漏掉这类变化。
见 06 删减影响
发现 3

群体指标不变，不代表个体预测不变

Raindrop 在 continuous5min 下 ΔAUPRC ≈ +0.001，但平均 |Δp| 为 0.046，和它在 drop40 下相当（0.047）；Flip Rate 为 6.2%。

所以：ΔAUPRC 要和 |Δp|、Flip Rate 一起报告。
见 07 个体漂移
发现 4

概率往哪个方向走，因模型而异

drop40 时，冻结阈值上的阳性预测率：BRITS 升高 3.8 个百分点，Raindrop 降低 6.7 个百分点，mTAND 降低 2.1 个百分点。

所以：阈值冻结时，这会直接变成报警率的系统性变化。
见 08 方向
发现 5

BRITS 区分度最高，对删减也最敏感

原始 AUPRC：BRITS 0.313 ± 0.004，mTAND 0.271，Raindrop 0.266，LSTM 参考 0.275。BRITS 在 drop40 下仍有 0.281，但它的 |Δp| 和 Flip Rate 是三个模型中最大的。

所以：模型之间没做配对检验，也都没调参，差异不能直接归因于结构。
见 05 区分度
发现 6

mTAND 漂移小，可能部分来自"只看末次值"

seed 2027 中，只要每个变量的末次观测都还在，51%–73% 的 visit 预测完全不变；seed 2026、2028 只有 0.07%–2.3%。

所以：不能直接说 mTAND "对不规则采样更稳健"。
见 09 mTAND
发现 7

校准指标反映的是加权口径

pos_weight ≈ 7.08 把概率整体推高：Brier 0.18–0.22、ECE 0.27–0.34，比"一律报患病率"（Brier 0.106）还差。LSTM 用的是同一口径。

所以：Brier、ECE 和 |Δp| 的绝对大小不宜跨口径比较。
见 11 校准
发现 8

训练 seed 的影响大于单个 run 的 CI

BRITS 在 drop40 下的 Mean |Δp|：三个 seed 为 0.055–0.086，而单个 run 的 bootstrap CI 只有约 0.003–0.004 宽。

所以：比较漂移指标要看多 seed 的均值 ± SD。
见 10 seed
02

实验怎么做

口径全部沿用正式版，六个模型一致；本页只列出与结果解读直接相关的部分。

任务与数据

  • 输入：入室后 0–15 分钟的六项生命体征（HR、RR、SpO2、SBP、DBP、MAP），不加其他变量。
  • 标签：decomp_60，即 (15, 75] 分钟内出现 HR > 110、MAP < 65 或 SpO2 < 90。
  • 队列：，不删 visit。
  • 数据：梁睿颖冻结的 benchmark，8 个文件的 sha256 全部核对通过。

评价规则

  • 只在 Original Train 上训练一次；标准化器也只在这里拟合。
  • checkpoint 与早停看 Original Validation 的 AUPRC；阈值取验证集上 F1 最大的点，之后冻结。
  • 四套 test 由同一个 checkpoint 打分，每套从自己的观测文件重算 mask、时间间隔、时间戳和长度。
  • 扰动集上不调任何东西；每套只评价一次。
  • CI 为按 CSN 的 paired bootstrap，1,000 次，bootstrap seed 2026。

四套测试集的输入规模

后三行是看到结果后补做的描述统计（见 13）。continuous5min 改动的 visit 最少，而且改动时多半保留了末次观测，这一点对理解 06–09 节很重要。

三个模型

BRITSmTANDRaindrop
输入表示1 分钟网格 16 × 6，加 mask 和时间间隔 δ；正向、时间反转各一套每个 visit 自己的观测时间戳（不网格化），时间按固定窗口缩放为 t/15每个 visit 自己的观测时间戳，补齐到 max_len = 21（由 Original Train 决定）
处理缺失 / 不规则的方式双向 RITS 插补（历史回归 + 特征回归 + 衰减），与分类联合学习多时间注意力：从观测时间点插值到 128 个参考时间点观测传播 + 时间位置编码 + Transformer，按真实长度做掩码均值池化
实现PyPOTS 1.5 BackboneBRITS，两个方向各接一个线性头，概率取均值按参考代码移植 mTAND-Enc（不含 VAE 重构）按 PyPOTS 1.5 BackboneRaindrop 写成批量版，单元测试证明与原版一致（误差 < 1e-5）
主要超参数hidden 64；重构权重 0.3hidden 256，embed_time 128，1 头，MLP 300-300d_model 24，2 层 2 头，FFN 48，dropout 0.2
优化Adam，lr 1e-3，batch 64Adam，lr 1e-4，batch 50Adam，lr 1e-4，batch 128，按验证 AUPRC 降学习率

三个模型都用 BCEWithLogitsLoss(pos_weight = 阴性数 / 阳性数)，最多 30 epoch，patience 6，与 LSTM 分支相同；超参数取论文或参考代码的常用设置，没有在本数据上调参。

解读前要知道的四个实现事实
  • Raindrop 的"图"是退化的：PyPOTS（以及其移植的官方 Raindrop_v2）调用观测传播层的方式，使它等于对每个变量单独做 relu(Linear(x))，变量之间不传递消息。本实现按原样复现，没有自行"修好"。
  • mTAND 用固定窗口缩放时间：参考代码按每个 batch 的最大时间归一化，那样一个 visit 的预测会受同 batch 其他 visit 影响，配对 Δp 就不成立了。
  • BRITS 是离线双向模型：它用到了窗口内的"未来"观测，只适用于 15 分钟固定时点的离线评估，不能表述为在线预测。
  • 预测与 batch 无关：三个模型中，单个 visit 单独预测与放进 batch 中预测，结果之差 ≤ 2e-6，所以 Δp 只反映这个 visit 自身输入的变化。

原始测试集上的区分度

点为点估计，横线为 95% CI。LSTM 的 5 个 seed 只画点估计（来自梁睿颖分支，未复核）。

怎么读

  • BRITS 的 AUPRC 在三个 seed 上都高于 mTAND、Raindrop 和 LSTM 的点估计，但模型之间没有做配对检验（方案未预设），三个模型也都没有调参。

06

删减对区分度的影响

Δ = 扰动 − Original，同一批患者配对计算。实心点表示 95% CI 不含 0，空心点表示含 0。

CI 不含 0 的 run 数

要点
  • 剂量反应：drop20 → drop40，三个模型的 ΔAUPRC 都变得更负，9/9 个 run 方向一致。
  • continuous5min 与随机删减不同：它只改动了 76.8% 的 visit，而且改动的 visit 中 61.9% 保留了每个变量的末次观测。三个模型的 ΔAUPRC 都接近 0，但 BRITS 和 Raindrop 的 AUROC 下降且 CI 不含 0。AUPRC 不变而 AUROC 下降，可能说明排序变化主要发生在低风险区间（推测，未检查）。
07

同一个患者，预测变了多少

|Δp| 是同一患者在扰动前后两次预测概率之差的绝对值；Flip Rate 是在冻结阈值下判定结果改变的患者比例。小圆点为各 seed，竖线为均值。

要点
  • 群体指标会掩盖个体变化：Raindrop 在 continuous5min 下 ΔAUPRC ≈ 0，但 Mean |Δp| 与它在 drop40 下相当。在 ΔAUPRC 的 CI 含 0 的那些情形（Raindrop 的 drop20 与 continuous5min、BRITS 的 continuous5min）里，Flip Rate 仍有约 4%–7.5%。
  • BRITS 漂移最大，mTAND 最小：但 |Δp| 的绝对大小受 pos_weight 推高概率的影响（见 11），mTAND 的小漂移也可能部分来自"只看末次值"（见 09）。
  • 预测相关系数 r 在 0.87–0.97 之间：整体排序大体保留，但个体层面的变化不可忽略。
08

删减把概率推向哪个方向

冻结阈值下被判为阳性的比例。空心点为 Original，实心点为扰动后；悬停可看带符号的平均 Δp。

要点
  • BRITS：删减后概率普遍升高，带符号 Mean Δp 在 drop40 下为 +0.028 至 +0.057，报警率升高。
  • Raindrop：随机删减后概率普遍降低（drop40 下 −0.010 至 −0.029），seed 2028 在 drop40 下报警率从 14.0% 降到 7.3%；但在 continuous5min 下概率反而小幅升高。
  • mTAND：平均水平几乎不变（|带符号 Mean Δp| ≤ 0.006），报警率小幅下降。
  • 本页没有分析造成方向差异的机制。
09

mTAND seed 2027 的"末次观测"现象

事后探索。只看有观测被删的 visit，按"六个变量的末次观测是否都还在"分两组，统计预测完全不变（|Δp| < 1e-9）的比例。

观察
  • seed 2027 中，末次观测都保留时，大部分 visit 的预测完全不变；末次观测被删时，这一比例只有 1%–6%。
  • seed 2026、2028 选中的是第 3 epoch，没有这个现象。
  • BRITS（3 个 seed）和 Raindrop seed 2027 只有在输入完全不变时，预测才完全不变。
  • 所有 run 的预测都没有塌缩：原始测试集上不同的概率值有 个（共 5,236 例）。
推测与含义（未直接验证）

seed 2027 训练到第 18 epoch，多时间注意力在 float32 下可能已饱和到每个变量最近的观测上。这一点没有直接检查注意力权重。

如果属实，mTAND 的低漂移有一部分来自"主要看末次值"，而不是对不规则采样的稳健建模；而且这个性质随 checkpoint（seed、epoch）而变。

10

训练 seed 的影响

bootstrap CI 只反映测试样本的不确定性，不包括训练随机性。下表把两者放在一起：以 drop40 为例，比较 3 个 seed 的极差和单个 run 的 CI 宽度（3 个 run 的中位数）。

要点
  • 原始 AUPRC 和 ΔAUPRC 的 seed 间极差小于单 run 的 CI 宽度：这两项单看一个 seed 问题不大。
  • Mean |Δp| 的 seed 间极差是单 run CI 宽度的 4–10 倍，三个模型都是；Flip Rate 在 BRITS、Raindrop 上也超过 CI 宽度。
  • 只看一个 seed 比较模型的漂移，结论可能反过来。例如 drop40 的 Flip Rate：seed 2026 是 BRITS 高于 Raindrop（13.4% 对 9.4%），seed 2027 反过来（7.1% 对 11.0%）。
11

校准：指标反映的是加权口径

pos_weight = 阴性数 / 阳性数 ≈ ，与 LSTM 分支相同。它让模型把概率整体推高，所以 Brier 和 ECE 很差。

ΔBrier 不能读成"删减后校准变好"
概率整体偏高时，概率往下移就会让 Brier "变好"。Raindrop 删减后 ΔBrier 为负，正是这个原因；ΔBrier 的符号基本跟随带符号 Mean Δp（逐 run 数值见附录）。同理，|Δp| 的绝对大小也在这个被推高的概率尺度上。

泄漏、偏倚与局限

泄漏检查

  • 输入只来自 0–15 分钟；标签窗口 (15, 75] 分钟，两者不重叠。
  • 推理不读 label；所有拟合（标准化、pos_weight、max_len）只用 Original Train。
  • checkpoint 和阈值只用 Original Validation；扰动集上不调任何东西。
  • 每套 test 只评价一次；所有补充分析只读已保存的预测。

偏倚与适用范围

  • 人群：聚合画像显示 train 中 HR ≤ 110、SpO2 ≥ 90、MAP ≥ 65，由此推断 benchmark 排除了前 15 分钟已达到终点的 visit（未查阅其构建代码）。结论只适用于这类就诊。
  • 删减方式：三种删减都是预先生成的随机或连续区块删除，不是真实的、与病情相关的信息性缺失。本实验不能回答"临床上测得少的病人"会怎样。

看到结果之后才加的内容

内容写成时间是否影响模型、阈值、预测
summarize.py（§19 检查与表格）训练启动后、读取任何结果前否
补充指标：预测相关系数、Brier 的 CI、ΔBrier（supplement_metrics.py）读取结果后否；原有 CI 被逐位复现
带符号 Mean Δp读取结果后否；不在正式版指标里
输入改动统计与 mTAND 诊断（posthoc_diagnostics.py）读取结果后否
LSTM 参考值、本页数据导出读取结果后否

这些脚本的 sha256 都追加在方案锁文件中，并注明写成时间。

局限

  • 一个数据集（MC-MED）、一个任务、一个 15 分钟时点；每个模型 3 个 seed。
  • 没有调参；bootstrap CI 不含训练随机性；校准指标受加权口径影响。

未验证

  • LSTM 参考值只从对方的 results.json 读出，没有复核代码与运行。
  • mTAND 注意力饱和只是推测；没有任何外部数据验证。
