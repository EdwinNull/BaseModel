## 1 D139：训练集内交叉拟合与成分消融

### 1.1 数据与折

- 只用训练集：MC-MED 42,983 次就诊，MIMIC-IV-ED 309,776 次。
- 5 折按患者（MRN / subject_id）分组：`sha256("ed_ts_bench_cv_d139:<MRN>")` 映射到 [0, 1)，乘 5 取整。同一患者只落在一折。
- LightGBM 的早停：在每折的 4 折训练部分里，再按患者哈希（盐 `ed_ts_bench_cv_d139_inner`）取 10% 作为早停集，其余 90% 拟合。LR 不早停，用全部 4 折。
- 每个就诊得到一个折外预测（OOF）。每个配置只跑 seed 2026 一次，变异来自折与 bootstrap。

### 1.2 特征与配置

特征矩阵按锁定代码生成：`tabular.summary_features` + `patch3_features.matrix(step="3b")`。年龄标准化与补丁 3 的缩放、词表、化验面板都沿用补丁 3 在整个训练集上拟合的结果。这些预处理不用标签，但留出折的数据参与了缩放分位数、主诉词表和化验面板的选择（无监督的轻微泄漏），报告中注明。

输入按列名分块（每列只属于一块，有未归类的列即报错）：

| 块 | 列 | MC-MED | MIMIC-IV-ED |
|---|---|---|---|
| 窗口生命体征摘要 | `<变量>_{last,mean,min,max,n,since_last}` | ✓ | ✓ |
| 年龄与 ESI（补丁 1） | `age_z`、`esi_*` | ✓ | ✓ |
| 到达方式 | `arrival_*` | ✓ | ✓ |
| 主诉 | `cc_*` | ✓ | ✓ |
| 共病 | `elix_*`、`hist_any` | ✓ | ✓ |
| 用药 | `meds_any`、`meds_n_z` | ✓ | ✓ |
| 既往就诊 | `prior_ed_n_z`（MIMIC 另有 `prior_adm_n_z`） | ✓ | ✓ |
| 分诊 | `tri_*`（MC-MED 分诊生命体征，MIMIC 疼痛评分） | ✓ | ✓ |
| t0 前化验 | `lab_*` | ✓ | ✓ |
| 既往 30 天化验 | `labp_*` | — | ✓ |
| 窗口数值（PI/HRV） | `num_*` | ✓ | — |

配置：补丁 1 = 窗口摘要 + 年龄与 ESI；3a = 补丁 1 + 到达、主诉、共病、用药、既往就诊、分诊；3b = 3a + 化验（MC-MED 另加窗口数值）；另有 3b 逐块去掉一块，共 10 个消融。每个数据集 13 个配置 × 2 个模型 × 5 折。去掉"窗口生命体征摘要"就是只用静态输入，可看时序在 3b 之上还多给多少。

模型设置与锁定的 `tabular.fit_predict` 相同（LR：中位数填补 + 缺失指示 + 标准化，C=1；LightGBM：同一组参数，只把早停集换成上面的内层 10%）。

### 1.3 评价（只用训练集 OOF，只出聚合量）

- 每个配置：OOF 总体 AUROC、AUPRC。不做 Platt，不报 Brier 和 O/E（5 折模型拼起来的概率没有统一校准）。
- 配对差：同一批患者聚类 bootstrap（B = 1000，seed 2026，两边用同一组重抽样），对总体和全部登记格子（D104 各轴 + D137 的 ≥75）算 AUROC 差及 95% 区间，并给 bootstrap 双侧 p。
  - 主要：3a − 补丁 1、3b − 3a；次要：3b − 补丁 1。
  - 消融：3b − (3b 去掉某块)，正值表示这块有贡献。同一模型 × 同一格子内对 10 个块做 Holm 校正。
- 子集减补集：补丁 1、3a、3b 各用 `subgroups.evaluate_subgroups` 算子集减补集的 AUROC 差（B = 1000），与补丁 3 发现集结果对照。

### 1.4 预先写好的读法

- 补丁增益（总体）：交叉拟合的区间不含 0 且与发现集同号 → "在训练集内复现"；区间不含 0 但反号 → "与发现集矛盾"；区间含 0 → "未复现"。
- ≥75 与 MIMIC ≤1 × ESI 1–2：3b 的子集减补集区间上限 < 0 → 差距在独立估计中仍在。
- 成分：Holm 校正后区间仍不含 0 的块记为"有贡献"；重点看 ≥75、低密度格与总体是否由不同的块驱动。
- 交叉拟合的人群是训练集，与发现集不是同一批就诊，AUROC 数值不直接相减，只比方向和是否显著。

### 1.5 算力

CPU 运行。补丁 3 时 MIMIC LightGBM 一次拟合在 30 并发下要 13–25 分钟，单独跑约 5 分钟；65 次 MIMIC LightGBM 拟合按 3 个并发、每个 6–8 线程估计约 2 h。特征矩阵每个数据集只生成一次，缓存到 `derived/ed_ts_bench/cv_d139/<task>/`。OOF 预测写到 `derived/ed_ts_bench/preds_cv/<task>/<模型>_<配置>/`（目录 700、文件 600）。

## 2 D140：Raindrop 3b 敏感性

- 新模型名 `raindrop_p3b_e60w32`，只改两处：`max_epochs` 30 → 60；静态嵌入 `Linear(n_static, 6)` → `Linear(n_static, 32)`，分类头输入相应变宽。早停耐心 6、学习率、调度、batch 128、序列输入和 seed（2026–2030）都不变。两处一起改，回答的是"锁定版 Raindrop 是否受这两处限制"，不区分各自贡献。
- 新写包装模块，不改锁定文件；预测写到 `derived/ed_ts_bench/preds/<task>/raindrop_p3b_e60w32/seed*/`。
- 评价：在发现集上与同 seed 的 `raindrop_p3b` 配对（`patch_eval.paired_run`，含 ≥75 轴），报总体与登记格子的 AUROC 差、跑满 60 轮的个数、最佳轮次。
- 读法：过半数 seed 总体区间下限 > 0 → 锁定版 Raindrop 受限，补丁 3 中 Raindrop 的数值偏低；否则锁定版结论不变。无论哪种，主结果仍用锁定版。
- 等 v2 的 MIRA 分片跑完、两块 GPU 空出后再跑；10 个 run 分到两块卡同时跑。

## 3 D141：≥75 岁诊断（只出聚合量）

两个数据集、<75 与 ≥75 分开，人数 < 10 的格子写 "<10"。

- 结局构成。MIMIC-IV-ED：事件中先进 ICU 与先死亡（未进 ICU）的比例。MC-MED：触发事件的生命体征（`trigger_measure`）构成。
- 去向：急诊去向（MIMIC `disposition`，MC-MED `ED_dispo`）；住院结局（MIMIC 出院去向是否临终关怀、12 h 之后的院内死亡或进 ICU；MC-MED `DC_dispo`）。
- 治疗目标限制（只 MIMIC）：关联住院中有无 DNR/DNI/仅舒适治疗的医嘱（`poe_detail` 的 code status 字段，只按关键词归成四类计数，不输出原文），以及医嘱在事件或预测时点之前还是之后。
- 风险分布：3b 各模型（发现集 5 个模型 × 5 个 seed 的 Platt 后概率；另用 D139 的 OOF）在 ≥75 与 <75 的非事件、事件中的分位数。
- 按成分分开的 AUROC：每种结局成分的事件对全部非事件；把"12 h 后才死亡/进 ICU、出院去临终关怀、有限制医嘱"的非事件剔除后重算 AUROC，看差距缩小多少。
- 读法：若 ≥75 的差距主要来自"死亡未进 ICU"一类，或剔除"标签外重症"非事件后差距明显缩小，则判为标签侧原因，作为数据侧难点报告；否则判为模型侧未解决，交回研究者。只是描述，不做新模型比较。

## 4 D142：4 h 时点的可行性计数（只 MIMIC-IV-ED，只训练集）

- 在 D103 训练集上，按全部、ESI 1–2、密度最低三分位、≤1 × ESI 1–2、≥75 分开数：
  - 就诊数、事件数；
  - 事件发生时刻（距到院）落在 2–4 h、4–6 h、6–10 h、10–14 h 的个数——2–4 h 发生的事件在 4 h 时点下会被排除；
  - 2–4 h 之间离开急诊的就诊数；
  - 在 D136 的 4 h 任务（`derived/tsfm_zs_mimic_ed/task_4h/`，同一纳排口径、窗口改 4 h）中仍保留的就诊数、事件数（4 h 时点的事件窗口为 4–16 h）；
  - 保留下来的就诊在 [0, 4 h) 内生命体征时刻数的中位数与 ≤1 的比例。
- 只出计数，不训练模型；是否另立 4 h 监督版本由研究者看完计数再定（A 档：索引时点）。
