## 1. 口径（★ = 需研究者复核的操作化）

eICU 没有 mimic-code 那样现成的"有创通气"概念，因此需要自行操作化：
- ricu 的 `mech_vent` 在 eICU 中没有数据来源；
- ricu 的 `vent_start` 不区分有创与无创。

| 项目 | V1（MIMIC） | V2（eICU） |
|---|---|---|
| 单位 | 每次住院的首次 ICU 入住 | 每次住院（patienthealthsystemstayid）的首个 unit。同一住院其他 unit 的事件与观测，按 hospitaladmitoffset 换算到首个 unit 的时间轴 |
| 年龄 | ≥18 | ≥18；'> 89' 记为 90（同 ricu）；年龄缺失 84 人排除 |
| ARI ★ | ICD，或病毒检测阳性 | **只用 ICD**。诊断表 icd9code 同时含 ICD-9 与 ICD-10，按逗号拆开，前缀表与 V1 相同。eICU 没有呼吸道病毒检测（lab 无相关条目，microLab 只有流感嗜血杆菌） |
| 流感 | ICD 或检测 | 只用 ICD。**主分析中为 0**，与 09-29 记录一致。eICU 的结论不能写成流感结论 |
| 排除：入科时已气切 ★ | ventilation Tracheostomy ≤6h | 气切证据首次出现 ≤6h。证据包括：careplan Airway 'Intubated/trach-*'、respiratoryCare 'Tracheostomy'、treatment '…\|tracheostomy'（不含 consider/planned） |
| 有创通气 ★ | ventilation InvasiveVent / Tracheostomy | 以下各项取最早时间：① treatment 含 '\|mechanical ventilation' 且不含 'non-invasive'，或为气切、reintubation；② careplan 'Ventilated - *'、'Intubated/*'；③ respiratoryCare 有创气道（Oral/Nasal ETT、Tracheostomy、Double-Lumen Tube）的记录时间，以及非 0 的 ventstartoffset |
| 升压药 ★ | 去甲肾、肾上腺素、去氧肾、血管加压素、多巴胺 | infusionDrug：drugname 匹配 ricu 正则，并加上商品名 Levophed、Neo-Synephrine；速率为数值且 >0。不含多巴酚丁胺、米力农 |
| 死亡 ★ | 院内死亡时间 | hospitaldischargestatus='Expired' 用 hospitaldischargeoffset；unitdischargestatus='Expired' 用该 unit 的出科时间；两者取最早 |
| DNI/CMO ★ | t0 时最近一条有效 code status | careplan Care Limitation 的映射：Full therapy→full code；Do not resuscitate、No CPR→DNR；No intubation→DNI；Comfort measures only→CMO。"No vasopressors/inotropes"（1,800 条）、"No augmentation of care"（1,688 条）等不参与 |
| NIV 标记 | NonInvasiveVent / HFNC | treatment / careplan 中的 non-invasive ventilation。**eICU 无法识别 HFNC** |
| 切分 ★ | 患者级 70/10/20 | 按医院哈希：20% 医院为 tune（调参/校准），80% 为 eval（外部评价，只评价一次） |

**敏感性标记**（只打标记，不删行）：
- `in_main_dxstr`：诊断串为肺炎或下呼吸道感染，这类诊断的 icd9code 可能为空；
- `apache_pneumonia`；
- `ari_known_at_t0`：t0 前已录入 ARI 诊断，对应"可部署"口径。

与 V1 相同，入队使用整个住院期间的诊断。这只决定"谁进入队列"，不进入任何模型输入。

## 3. 逐小时特征与视图

**格式**：与 V1 完全相同，为 `stay_id, var, hour, last, n, t_last_min`，小时范围 −23 到 72。因此 V1 的 `views.py` 可以直接使用。

**通道映射**（★ 为与 ricu 不同或需复核的选择）：
- **心率、呼吸、SpO2**：vitalPeriodic。
- **血压**：vitalPeriodic 有创血压 + vitalAperiodic 无创血压。★ ricu 只用有创血压，这里跟 V1 一样两者都用。
- **体温**：vitalPeriodic + 护士记录 'Temperature (C)'。★ ricu 只用 vitalPeriodic，其覆盖率很低。
- **GCS**：护士记录 'GCS Total'。
- **FiO2**：respiratoryCharting，换算规则同 mimic-code。
- **氧流量**：★ 不使用。护士记录 'O2 L/%' 把 L/min 和 % 混在一起，这个通道在 eICU 上全缺。
- **呼吸支持等级**：★ 由 treatment、careplan、respiratoryCare 分类得到。
- **化验**：labname 按 ricu 对应。
  - ★ 时间取 max(labresultoffset, labresultrevisedoffset)，即结果最晚可用的时间，对应 V1 的 storetime。约 6% 的记录修订时间早于结果时间。
  - ★ glu 只用化验血糖，与 V1 一致；hco3 用生化 bicarbonate。
  - ★ CRP：约 1/3 的记录界面单位标为 mg/L，但数值分布异常（中位数 189、P95 2,418），已置空。其余记录 ×10 换算为 mg/L。

**体征范围过滤**：与 mimic-code vitalsign 相同。化验不过滤，与 V1 一致。

## 4. 与 V1 的主要差异（解读外部验证时需要考虑）

1. **观测密度更低。** GCS、血气、乳酸的覆盖率明显低于 MIMIC，氧流量缺失。这与 F3 的稀疏化压力测试相关：MIMIC 训练的模型到 eICU 上，相当于遇到"错配"的观测过程。
2. **终点构成不同。**
   - Y24 中死亡占比更高：672/4,492 = 15%，V1 为 8%。
   - 有创通气来自记录时间，可能晚于实际插管。
   - eICU 的 NIV 标记比例（36%）远高于 V1（15%）。treatment 中的 non-invasive ventilation 可能包含睡眠呼吸暂停患者的长期 CPAP，未区分。
3. **入科时已气切更多**（632 对 96）。careplan 的 'Intubated/trach-chronic' 记录了慢性气切患者。
4. **没有流感病例**，也没有病毒检测，ARI 只依赖 ICD。
5. **时间轴是相对的**：eICU 只有分钟偏移，只给出院年份，2014 年和 2015 年各约一半。因此做不了时间外推切分。

## 5. 需研究者复核的项目（A 档相关）

1. 有创通气的三源并集定义，以及记录时间滞后可能带来的标签偏差。
2. 入科时已气切的证据来源，以及是否把 'Ventilated - chronic dependency' 也列为排除。
3. Care Limitation 的映射（是否把 "No augmentation of care"、"No vasopressors/inotropes" 视为 DNI/CMO 一类）。
4. ARI 只用 ICD；是否把 `in_main_dxstr`（诊断串）或 APACHE 肺炎纳入主分析。
5. 医院级 20/80 切分及其盐值。
6. 死亡时间取住院出院偏移。ricu 用的是 unit 出科偏移。

在研究者确认之前，以上口径按"阶段口径"使用：可以用于方法开发和 tune 医院上的调参，**eval 医院上的正式评价等确认后再做**。
