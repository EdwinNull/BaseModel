## 1 结论

1. **Q7：双重平均（ens_bag）6 个比较全部"优于" tabpfn_lgbm。**
   - ens_bag 是 TabPFN（温度 1.0）与 LightGBM 5 种子平均的等权 logit 平均。
   - ΔAUROC：MC-MED +0.0016、+0.0011、+0.0007；MIMIC-IV-ED +0.0010、+0.0007、+0.0005（n = 1,000、2,500、5,000）。正向抽样 17–20 次。
   - 只换温度（ens_t1 − tabpfn_lgbm）的差在 ±0.0001 以内，所以这点增益来自 LightGBM 的多种子平均。
   - MC-MED 发现集上方向一致：+0.0016、+0.0006、+0.0008。
   - 幅度小，但在第四轮的基础上稳定：两个增益来源（多模型平均、TabPFN 的多样性）可以叠加。
2. **Q8：TabPFN 改用 8 个子模型几乎没有再提高。**
   - ens_bag8 − ens_bag：MC-MED +0.0000、+0.0002、+0.0002，MIMIC-IV-ED +0.0001、−0.0000、+0.0001。
   - 两库都只有 n = 5,000 一格判"优于"，幅度 ≤ 0.0002，其余持平。
   - TabPFN 单独看，8 个子模型比 4 个高 0.0001–0.0007；进入平均后这点差别基本被吸收。
3. **按事先写定的规则，最终候选为 ens_bag。**
   - 规则：起点 ens_t1；Q7 两库都至少 2 个 n"优于"且无"差于"才升级；再看 Q8。
   - meta 中的记录：
     - Q7 两库各 3/3"优于" → 升为 ens_bag；
     - Q8 两库各 1/3"优于" → 不升级。
4. **ens_bag 与单个 LightGBM 相比（次要）：**
   - MC-MED +0.0120、+0.0103、+0.0072；MIMIC-IV-ED +0.0094、+0.0070、+0.0055。20 次抽样中 19–20 次为正。
   - AUPRC：MC-MED 0.256 → 0.271、0.287 → 0.298、0.309 → 0.318；MIMIC-IV-ED 0.434 → 0.466、0.486 → 0.516、0.518 → 0.542。
5. **与三者平均（tabpfn_lgbm_lr）比，取决于数据（次要）：**
   - MC-MED 上 ens_bag 高 0.004。
   - MIMIC-IV-ED 上 n = 1,000 时低 0.0023，n = 2,500、5,000 时持平。
   - LR 好的数据上，把 LR 也平均进来在最小样本时还有一点帮助。但 LR 的好坏在目标医院事先不知道，这一项不进入候选。
6. **校准：**

|---|---|---|---|---|

   - 温度 1.0 让平均后的斜率接近 1，观察/预期也比 tabpfn_lgbm 更接近 1。
   - 小样本时观察/预期仍偏高：MC-MED n = 1,000 为 1.09；MIMIC-IV-ED n = 1,000、2,500 为 1.14、1.11。
     - 这部分主要来自 LightGBM：在 MIMIC-IV-ED 上，lgbm_bag 的观察/预期为 1.25、1.14、1.05，原因没有单独查。
     - 第四轮的平均后再校准（avg_rcl）能把它拉回 0.94–1.02。用于 ens_bag 时需要 LightGBM 各种子的交叉拟合预测，本轮没有做。

## 4 五轮汇总：小样本情景下的配方

| 轮 | 问题 | 结论 |
|---|---|---|
| 第二轮（D152） | TabPFN 对 LightGBM；先验 | TabPFN 只在 MIMIC-IV-ED 略好；同库先验很有用（上界）；跨库先验输入有错位 |
| 第三轮（D153） | 对齐后的跨库先验；平均的复现 | 跨库先验在结局不同时用处很小，作偏置会拖累，线暂停；TabPFN + LightGBM 平均在新评价集上复现 |
| 第四轮（D154） | 增益来源；学组合方式；校准 | 约一半增益来自平均本身；学组合方式不如等权；温度 1.0 修正 TabPFN 校准 |
| 第五轮（D155） | 双重平均；TabPFN 子模型数 | 两个来源可以叠加；8 个子模型不必要；最终候选 ens_bag |

- **候选配方 ens_bag：**
  1. 在小样本上用 5 个种子各自做内部交叉验证调参，训练 5 个 LightGBM，logit 取平均。
  2. 训练 TabPFN v2（4 个子模型），温度设为 1.0。
  3. 两者 logit 等权平均。
  4. 若需要校准好的概率，再用交叉拟合预测做一次截距 + 斜率的再校准（第四轮 avg_rcl 的做法，本轮未在 ens_bag 上测）。
- **相对单个 LightGBM 的增益：** MC-MED +0.007 到 +0.012，MIMIC-IV-ED +0.0055 到 +0.0094，样本越小增益越大。
- **不改** 终点、标签、切分、纳排。是否把它作为目标医院的模型路线，属 A 档，由研究者定。

## 5 局限

- **S 集已经用了三次。** 五轮里一共比较了十几种做法，最终候选是在同一集合上挑出来的，它对 tabpfn_lgbm 的优势（+0.0005 到 +0.0016）尤其可能偏乐观。这是需要确认集的原因（§6）。
- **只在两个美国急诊数据集上做过。** 结局、人群、特征都与目标医院（老年人流感转重）不同。增益的方向可能可以迁移，大小不一定。
- **校准：** 小样本时观察/预期偏高的问题，本轮只描述，没有在 ens_bag 上测再校准。
- **TabPFN 的数值可复现性：** 受线程数与进程状态影响（第三、四轮报告 §1），对 AUROC 的影响 ≤ 1e−4 量级。
