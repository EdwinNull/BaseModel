## 3 GAM 新格式：一整套文件一起读

### 3.1 现状与问题

- flucase 现在有两个 GAM 单文件格式：`gam_ip`（住院 6 张表）、`gam_op`（门诊 5 张表），每个文件单独导入；
- 病例库合并按就诊编号：同一就诊编号再导入时，新读到的内容**整体替换**旧版本（"更新"）。护理记录如果单独作为一个文件导入，读出的就诊只有体征，会把同一住院已有的病历、检验、诊断换掉。**所以护理记录必须和它所属的住院 / 门急诊在同一次导入里读**；
- GD 已经是这种读法：`gd_raw` 是"整套导出"格式（`ehr_bundle`），一次导入一整套文件，按表头认表，再按编号挂接。

### 3.2 设计

新建整套格式 **`gam_raw`（GAM式原始导出，病历系统多文件导出）**：

| 部分 | 怎么认 | 读成 |
|---|---|---|
| 门诊、急诊 | 按表头认表（诊断病史 / 病历信息 / 处方 / 检验 / 检查；急诊的表头以扫描为准） | 门急诊就诊（setting = ed），沿用 `gam_op` 的读法；门诊、急诊另记就诊类型 |
| 住院（已有的旧导出） | 住院病历 / 住院诊断 / 西成药医嘱 / 草药处方 / 检验 / 检查 | 住院就诊，沿用 `gam_ip` 的读法 |
| 护理记录 | 按表头认（列名以扫描为准；宽表——每个体征一列——和长表——项目名称 + 值——两种都支持） | 体征 VS001–006（时间 = 记录时间，`time_kind = measured`，来源类型"护理"）；SpO2 的吸氧状态（护理记录有吸氧标注时取标注，标 `o2 = 标注`）；吸氧方式 / 流量作为氧疗、高流量、无创的结构化佐证；科室 / 病区作为 ICU 判断的另一来源；意识、出入量先按原名保留 |

- 挂接：护理记录按编号挂到同一套文件里的就诊；编号对不上的按"病人编号 + 记录时间落在哪次就诊里"挂（同 GD 的检验）；都挂不上的列进问题清单，不导入。
- 旧格式 `gam_ip` / `gam_op` 保留，已导入的病例不受影响；以后 GAM 的数据走 `gam_raw`。服务器上 GAM 用 `gam_raw` 重新导入一次（同一就诊编号按"更新"建新版本，旧版本保留、可撤销）。
- 读取器版本、格式配置都是数据，扫描后按真实列名写；虚构样例生成器同步加护理记录表。
