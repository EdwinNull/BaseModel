# 数据集

按老年人流感个体转重预测的用途区分：个体病程开发、跨医院外部验证、不规则时序评测、辅助表示预训练和公共卫生背景。每个子目录均含独立精读文档和 SVG 数据流图。

完整的单页版本见 [医学时序数据集对比](数据集对比.md)。

| 优先级 | 条目 | 访问与用途 |
|---|---|---|
| P0 | `03_MIMIC_IV` | 个体病程开发、转重标签原型和主训练候选 |
| P0 | `04_eICU` | 多中心跨医院外部验证和校准迁移 |
| P0/P1 | `05_HiRID` | 高频不规则监测和连续时间模型评测 |
| P1 | `02_PTB_XL` | ECG 表示预训练和管线压力测试 |
| P2 | `01_FluSight` | 流感季节/地区背景，不是个体转重主数据 |

MIMIC-IV、eICU-CRD、HiRID 也不是天然的流感专病队列；必须根据病毒检测、流感诊断或可审计的感染代理构造队列，不能把一般感染/呼吸重症结果直接称为流感转重结果。
