# J6b MC-MED 上的监督模型参照：结果（2026-11-05）

研究者 2026-11-05 回复“加上参照”（D129）。方案是 `plans/零样本决策读出/J6b_监督模型参照_方案_20261105.md`，按 `W/logs/2026-11-05/J6b_plan_lock.txt` 锁定后运行一次。

这一步没有调用决策模型，零样本的预测直接读 J6。全部结论是**探索性估计**，这是发现集的又一次使用，要计入 ed_ts_bench 的多重比较。不是临床模型的验证，也不能外推到老年流感住院。本文只含聚合量。

## 结论

1. **论文的方向只在 Z1 上重现。** 零样本减监督模型的 AUROC 差，Z1 在收住院上比在 `decomp_60` 上更负：差中差是 −0.060（95% CI −0.078–−0.043，对 LR）和 −0.041（−0.058–−0.024，对 LightGBM）。Z2 是 −0.013（−0.033–0.006）和 +0.006（−0.014–0.025），区间都含 0。按方案的读法，这只算部分成立。
2. **这个相对比较不受 Observation 归属的影响。** Observation 算收住院时，Z1 是 −0.065、−0.046，Z2 是 −0.011、+0.007。它修正了 J6 的一处读法：归属会改变绝对 AUROC，但零样本和监督模型一起变，差距基本不变。
3. **`decomp_60` 上 Z1 没有明显输给 LR，但输给 LightGBM。** Z1 − LR 是 −0.011（−0.024–0.002），Z1 − LightGBM 是 −0.040（−0.051–−0.028）。Z2 对两者都差（−0.041、−0.069）。
4. **收住院上两个零样本都明显输给监督模型。** Z1 差 0.072–0.081，Z2 差 0.054–0.063，区间都不含 0。这支持 J5 的预期：O3 的住院分量上零样本会吃亏。
5. **监督模型的校准也更好，但它们用了标签。** LR、LightGBM 用 3.9 万次就诊训练，校准截距接近 0，斜率 1.01–1.11。零样本没有用任何标签。这不是公平的模型优劣比较，只回答“差距在哪个结局上更大”。

## 假设、泄漏与偏倚

- 特征走 J6 的白名单，`ED_dispo` 只进标签。测试里塞入禁用列，特征不变；同一次就诊的特征与 state 里的数字一致。
- 早停和拟合都在训练集内，发现集不参与。这比 ed_ts_bench 更严：那边的早停用了验证集，所以这里的 `decomp_60` 数字（LR 0.702、LightGBM 0.731）和那边（0.705、0.734）略有不同，输入也不一样。
- 两个结局的基础难度不同，差中差去掉了一部分，去不掉问题卡的差别：`decomp_60` 的问题卡写明了数值判据，收住院的没有。Z1 的差中差可能有一部分来自这里。
- 8 个差中差和 12 个配对差没有做多重比较校正。

## 局限

- 队列已排除前 15 分钟就异常的就诊，主诉和分诊体征不进输入。
- 监督模型没有调参，也没有用时序特征。更强的监督模型可能拉大差距，尤其是 `decomp_60`，ed_ts_bench 的 BRITS 已到 0.730。
- 没有做提示扰动，没有做亚组分析。
- 全年龄、单一中心的急诊数据，不能代表老年流感。

## 未验证

- Z1 与 Z2 为什么不一致：模型本身、读出校准，还是问题卡的影响。
- 这个方向能否在确认集或别的数据上重现。确认集已用掉（D109、D111）。
- 换成论文的结局（死亡、住院天数）时是否一样。

## 对 J 线的影响

- **J5：** 住院分量上零样本吃亏的预期有了支持。O3 建议的“两个分量各报一遍”不变。
- **J2 的 J4：** 住院数据上病情型好于治疗代理型的预期只在 GD 成立。MC-MED 上 Z1 的方向相符，但这是不同人群、不同结局，不能用来解释两院差距。
