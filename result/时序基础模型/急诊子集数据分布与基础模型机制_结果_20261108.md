# 急诊子集的数据分布差异与时序基础模型的反应：结果（2026-11-08）

> 回答研究者 11-07 的问题：分诊等级、到达方式等子集在数据上有什么物理差异（例如 ESI High / Moderate / Low 三组的分布差异），这些差异会对基础模型产生什么影响。
> 方案：`plans/时序基础模型/急诊子集数据分布与基础模型机制_描述分析_方案_20261108.md`（11-08 09:43 锁定，sha256 见 `W/logs/2026-11-08/subset_physics_plan_lock.txt`）。描述分析，结论为探索性（D111）。§5.2–§5.3 的三项诊断是**看过结果后补的，没有预先登记**。
> 只含聚合量。High / Moderate / Low = ESI 1–2 / 3 / 4–5。

## 0 一页结论

**三组 ESI 在数据上最大的差别不是体征数值，而是测量过程。**

1. **测量过程差别最大。** 以 MIMIC-IV-ED 的 2 h 窗口、HR 为例，High / Moderate / Low 三组 2 h 内只有分诊那一次测量的比例是 51% / 81% / 87%，上下文为常数的比例是 52% / 82% / 88%。高危组在头 2 h 内会被反复测量，低危组基本只有分诊值。
2. **数值水平的中位数几乎相同。** HR 末值中位数是 82 / 82 / 80 次/分。差别在尾部：上下文里 HR 已经超过 110 的比例是 14% / 6% / 4%，MAP 低于 65 的比例是 4.3% / 0.8% / 0.3%。
3. **未来走向不同：分诊之后体征整体回落，低危组回落得更多。** HR 的"末值 − 未来值"平均为 +4.0 / +5.7 / +8.5 次/分。所以低危组的 HR 对 LOCF 来说并不更容易预测，三组的 LOCF MAE 是 10.4 / 11.1 / 11.6。SpO₂ 的方向相反，高危组更难（1.73 / 1.55 / 1.36）。
4. **到达方式和年龄有同样的结构。** 急救车送达、≥75 岁的就诊重复测量更多（只有一次测量的比例：急救车 58% 对自行到达 76%；≥75 岁 57% 对 <65 岁 74%）。自行到达、<65 岁的分诊 HR 更偏高，之后回落得更多。

**这些差异经三条路径作用到零样本基础模型。**

- **常数上下文上，八个模型的输出都等于 LOCF。** 两库、所有子集上，"八模型平均 MAE / LOCF MAE"在常数上下文里都是 1.000。所以 Moderate、Low 两组 80%–90% 的"就诊 × 变量"，模型实际做的就是 LOCF。
- **非常数上下文上，模型比 LOCF 差 8%–18%（MIMIC-IV-ED）。** 在 HR 上，七个模型把预测从末值往上下文均值拉回 47%–113%，真实体征只回到约 32%。TimesFM 则是顺着最后一步外推。上下文波动越大，模型吃亏越多：HR 按上下文标准差四分位，比值从 1.01 升到 1.37。
- **体征水平被实例标准化去掉了，模型用不上"人群回归"。** 末值比人群中位数高 10 次/分，未来平均会比末值低约 4 次/分（HR 斜率 −0.41）。模型的这个斜率是 −0.02，常数上下文上恰好是 0。

**所以，零样本预测在 High 组"更差"，是测量过程的构成造成的。** 按上下文形状（常数 / 非常数）标准化以后，High 与其余两组的 HR 差值从 +0.056 降到 0.000 [−0.010, +0.011]。也就是说，高危组非常数上下文更多，而模型只在非常数上下文上吃亏，并不是高危生理让模型更难。到达方式的情况相反：原始差值为 0，但在同一形状内，自行到达更差（非常数 HR：1.261 对 1.133，8 个模型都同向）。原因是分诊 HR 偏高之后回落，而模型往回拉。

**这也解释了 ③ 的发现。** ③ 中嵌入的增益来自"首次测量时间"，对应的就是分诊体征里缺了这一项的就诊。这类就诊只占 1.4%，D103 转重率却是 45%，而其余就诊是 4.8%。

## 5 这些差异怎样作用到基础模型

记 R = 八模型平均 MAE / LOCF MAE，R>1 表示模型比 LOCF 差。各项都在共同未来观测上计算。

### 5.1 常数上下文：八个模型都等于 LOCF

| | MIMIC-IV-ED HR / MAP / SpO₂ | MC-MED HR / MAP / SpO₂ |
|---|---|---|
| R（常数上下文） | 1.000 / 1.000 / 1.000 | 1.000 / 1.000 / 1.000 |
| R（非常数上下文） | 1.184 / 1.105 / 1.085 | 1.229 / 1.080 / 1.206 |
| R（全部） | 1.057 / 1.036 / 1.027 | 1.215 / 1.040 / 1.193 |

- 所有子集里，常数上下文的 R 都是 1.000，区间宽度为 0。
- 逐个模型看，常数上下文上的 MAE 与 LOCF 相同到小数点后三位（MIMIC-IV-ED HR：七个模型 11.729，Time-MoE 11.727，LOCF 11.729）。
- 模型预测段内"最大偏离末值 < 1"的比例（八个模型的中位数）是 73.6%（HR），与常数上下文比例 70.2% 接近。

**机制（从输出推断）：** 常数序列做实例标准化后尺度为 0，模型无论在标准化空间里预测什么，还原后都是一条水平线，等于末值。这和 ③ 中"常数序列的嵌入只剩长度"是同一件事。

对子集的含义：
- Moderate、Low 组 80%–90% 的"就诊 × 变量"是常数上下文，模型在这些就诊上就是 LOCF。
- Low 组 R≈1.00（1.004），不是模型做得好，而是模型什么也没做。

### 5.2 非常数上下文：往上下文均值回拉（看过结果后补的诊断）

对每个非常数上下文，记 d = 末值 − 上下文均值。分别用模型预测偏离（预测 − 末值）和真实偏离（未来值 − 末值）对 d 做回归，得到斜率：
- 斜率 −1：预测回到上下文均值；
- 斜率 0：等于 LOCF；
- 斜率 >0：继续最后一步的方向。

|---|---|---|---|---|---|---|

### 5.5 与此前结果的关系

- **终版第三部分 §11A** 说"ESI 1–2 的 HR 模型 / LOCF 为 1.060 对 1.021，8/8 模型更高"。现在可以说清楚：这完全来自高危组的非常数上下文多，同形状内没有差别。
- **③ 冻结嵌入：**
  - 常数上下文的嵌入只剩"变量 × 长度"，长度 = 8 − 开头空格数。
  - MIMIC-IV-ED 中长度小于 8 的，几乎都是分诊体征缺了这一项的就诊（§2.5），转重率约 45%。这就是 S + L 追平 S + E 的原因。
  - 它是测量流程信号，集中在 High 组和急救车送达。
- **风险分不超过 Context-max：**
  - 越阈风险分能用上的组间差异在尾部水平（§2.2），而预测在常数上下文上等于末值，在非常数上下文上往均值回拉。所以预测段的最大值不会比上下文里最异常的值更有信息。
  - MC-MED 上下文里没有越阈的就诊，预测几乎不会越阈，R-max 退化为 0。

## 7 局限

- 描述分析，结论为探索性。区间没有做多重校正。MC-MED 只用 A 半，Low 组只有 133 次就诊。
- §5.2–§5.3 的回拉斜率、标准差四分位、人群回归，以及 §5.4 对"构成掩盖"的解释，都是看过结果后才做的。
- R 是八模型平均，在 MC-MED 上被 TimesFM 主导；逐个模型的 R 见 `subset_physics_per_model_r.txt`。
- 模型看到的"阶梯"形状来自前处理：格内取均值，再前向填充。换一种输入方式（不填充、给出时间戳，例如 MIRA 原生支持的不规则时间）可能得到不同结果，这里没有试。
- MIMIC-IV-ED 的"只有一次测量"近似"只有分诊值"，没有按来源（triage / vitalsign）逐条核对。
- 人群回归的斜率里，生理回落和测量误差造成的回归均值分不开；人群中位数取自同一验证集。
- 只讨论零样本预测路线。监督模型能直接使用绝对水平和人群信息，不受 §5.3 的限制。
