# 六模型观测删减敏感性实验：任务说明

## 1. 这项实验到底想回答什么

我们现在不是单纯比较“哪个模型预测最准”，也暂时不直接证明某类模型一定更脆弱。

当前更准确的研究问题是：

> **在完全相同的急诊患者、标签和原始生理记录下，当观测被随机减少或连续移除时，不同缺失处理机制的模型，预测性能和患者级风险概率会发生多大变化？**

第一轮实验更适合表述为：

> **比较不同 missingness handling（缺失处理）机制的模型，在统一 observation sparsening（观测稀疏化）扰动下的性能下降与预测漂移。**

当前有一个待验证假设：

> **显式利用 observation process（观测过程）的模型，可能对观测方式变化表现出不同程度的敏感性。**

注意：这只是待验证假设，不能预先说“越显式利用 observation process（观测过程）的模型一定越脆弱”。

六个模型的架构、容量、优化方式和缺失处理方法同时不同，因此最终如果观察到差异，我们更谨慎地表述为：

> **不同模型机制与 observation-policy sensitivity（观测策略敏感性）存在关联。**

而不是直接证明某个单一机制具有因果作用。

## 2. 六个模型与分工

### 梁睿颖负责

1. Forward Fill + LSTM（前向填充 + 长短期记忆网络）
2. GRU-D（带缺失衰减的门控循环单元）
3. OPL-MT-MNAR structured-only（显式非随机缺失模型，仅结构化数据）

### 你负责

1. BRITS（双向递归插补时序模型）
2. mTAND（多时间注意力网络）
3. Raindrop（图引导不规则时序模型）

六个模型不是严格的“由弱到强 observation process（观测过程）依赖”排序，而是代表不同缺失 / 不规则采样机制：

| 模型                          | 主要缺失 / 不规则观测处理机制                                               |
| --------------------------- | -------------------------------------------------------------- |
| Forward Fill + LSTM         | 规则化后前向填充，主要通过填补后的数值间接感知缺失                                      |
| GRU-D                       | 显式使用 mask（缺失掩码）、time gap（时间间隔）和 decay（衰减）                      |
| BRITS                       | 双向插补 + 时序预测联合学习                                                |
| mTAND                       | 直接利用 irregular timestamps（不规则时间戳）                              |
| Raindrop                    | 建模不规则时间和变量间关系                                                  |
| OPL-MT-MNAR structured-only | 显式建模 time gap、count、missing rate、measurement frequency 等观测过程信息 |

第一轮重点是比较这些不同机制在统一扰动下的表现差异，而不是强行对六个模型做“依赖观测过程程度”的线性排序。

## 7. 统一输入原则：数据相同，但允许模型保留自己的缺失机制

六个模型必须从同一份冻结 observation parquet 开始。

但是不同模型可以进行其原始方法所需要的 preprocessing（预处理）。

例如：

- Forward Fill + LSTM：可以规则网格化并 forward fill（前向填充）
- GRU-D：必须从当前这套 observation 数据重新计算 mask（缺失掩码）和 delta / time gap（时间间隔）
- BRITS：按其原始方法构造双向插补输入
- mTAND：保留 irregular timestamps（不规则时间戳）
- Raindrop：按照其原始不规则时序输入形式构造样本
- OPL-MT-MNAR：从当前 observation 数据重新计算 time gap、measurement count、missing rate、measurement frequency 等

关键原则：

> **模型特有的输入转换可以不同，但原始 CSN、Time、Value 和 observation availability（观测是否存在）必须来自同一冻结数据。**

Drop20 / Drop40 / Continuous5min 后的所有 mask、time gap、count、frequency 等派生缺失特征，都必须重新从对应扰动数据计算，不能沿用 Original 的派生特征。

## 10. 统一评价指标

### 10.1 预测性能

每套测试数据计算：

- AUPRC（精确率-召回率曲线下面积）——主性能指标
- AUROC（受试者工作特征曲线下面积）——辅助性能指标

由于当前阳性率约 12%，第一轮结果解释时优先关注 AUPRC。

另外建议同时报告相对 Original 的变化，例如：

```text
ΔAUPRC = AUPRC_perturbed - AUPRC_original
ΔAUROC = AUROC_perturbed - AUROC_original
```

---

### 10.2 Prediction Drift（预测漂移）

对完全相同的患者进行配对比较：

```text
delta_p = abs(prob_perturbed - prob_original)
```

分别比较：

- Drop20 vs Original
- Drop40 vs Original
- Continuous5min vs Original

报告：

- Mean Δp
- Median Δp
- P90 Δp

这是本实验最核心的一组指标之一。

---

### 10.3 Prediction Flip Rate（预测翻转率）

每个模型只在 Original Validation（原始验证集）选择一次分类 threshold（阈值）。

第一轮统一建议：

> **使用 Original Validation 上使 F1 score（F1分数）最大的 threshold。**

得到 threshold 后立即冻结。

该模型的：

- Original test
- Drop20 test
- Drop40 test
- Continuous5min test

全部使用同一个 threshold。

不同模型可以有不同 validation-derived threshold（验证集确定阈值），但同一个模型四套 test 的 threshold 必须完全一致。

Prediction Flip Rate 定义为：

```text
Original 预测类别 != Perturbed 预测类别
```

的 test visit 比例。

注意：Flip Rate 是辅助解释指标，核心仍然是患者级连续概率变化 Δp。

## 11. 加入不确定性：统一 paired bootstrap 95% CI

六个模型都保存患者级预测以后，统一进行 bootstrap（自助法）不确定性评估。

建议：

- bootstrap unit：CSN
- 进行 paired bootstrap（配对自助采样）
- 每次同时抽取该 CSN 在 Original 和 Perturbed 中的预测
- 建议至少 1,000 次 bootstrap

对以下指标报告 95% CI（95%置信区间）：

- Original / Drop20 / Drop40 / Continuous 的 AUPRC
- AUROC
- ΔAUPRC
- ΔAUROC
- Mean Δp
- P90 Δp
- Flip Rate

这样六模型之间如果只相差很小，不会只凭一个点估计做过度解释。

## 12. 第一轮 Random Drop 的解释边界

当前：

- Drop20
- Drop40

更准确地叫：

> controlled random observation thinning（受控随机观测稀疏化）

它们不能直接等价成“真实医生 measurement policy（测量策略）”。

Continuous5min 更接近短时间连续监护缺失 / 观测中断。

因此第一轮论文和 PPT 中推荐说：

> **模型对 observation sparsening（观测稀疏化）的敏感性**

而不要直接说：

> “我们已经模拟了真实医院测量策略变化。”

后续如果第一轮结果有差异，再扩展：

- Monitor-only thinning（只降低监护仪记录密度）
- Monitor / Chart 分层 thinning
- state-dependent deletion（状态依赖删除）

这些才更接近真实 measurement-policy shift（测量策略变化）。

## 16. 六项统一执行规则（正式锁定）

下面 6 条规则从本周六模型 pilot（预实验）开始统一执行。  
它们不改变各模型原本的结构，但用于保证六个模型最终结果可公平比较。

### 16.1 规则网格统一为 1 min（1分钟）

仅针对需要规则网格输入的模型，例如：

- Forward Fill + LSTM（前向填充 + 长短期记忆网络）
- GRU-D（带缺失衰减的门控循环单元）
- BRITS（双向递归插补时序模型）

统一采用：

```text
时间分辨率：1 min
时间点：0, 1, 2, ..., 15
总时间格：16
```

同一变量在同一分钟内如果存在多条真实记录：

```text
取均值
```

某一分钟没有该变量记录：

```text
保持 missing（缺失）
```

之后如何处理 missing（缺失），由各模型自己的原始机制决定。

例如：

- LSTM：可继续进行 forward fill（前向填充）
- GRU-D：使用 mask（缺失掩码）和 time gap（时间间隔）
- BRITS：按照其双向插补机制处理

注意：

mTAND（多时间注意力网络）和 Raindrop（图引导不规则时序模型）本身用于处理 irregular timestamps（不规则时间戳），**不要为了“统一”而强制转成 1 min 规则网格**。

统一的是原始 observation（观测）来源，不是强迫所有模型使用相同内部表示。

---

### 16.2 Best checkpoint（最佳检查点）统一按 Original Validation AUPRC 选择

所有模型统一规定：

```text
Checkpoint selection metric:
Original Validation AUPRC
```

Early stopping（早停）也只监控：

```text
Original Validation AUPRC
```

不能出现：

- 一个模型按 validation loss（验证损失）选最佳模型；
- 一个模型按 AUROC（受试者工作特征曲线下面积）选；
- 一个模型按 test performance（测试性能）选。

不同模型可以使用不同：

- learning rate（学习率）
- batch size（批大小）
- hidden dimension（隐藏维度）
- epoch（训练轮次）
- dropout（随机失活）

但最终 best checkpoint（最佳检查点）的选择依据必须统一为：

> **Original Validation AUPRC（原始验证集精确率-召回率曲线下面积）**

---

### 16.3 增加 Calibration（概率校准）指标

Prediction Drift（预测漂移）中的 Δp 是非常重要的患者级指标，但不同模型的 probability calibration（概率校准）可能不同，因此不能仅根据 mean Δp（平均预测漂移）大小给六个模型做强排序。

第一轮统一至少额外报告：

- Brier Score（布里尔分数）

建议优先在：

- Original Validation
- Original Test

上报告 Brier Score。

如实现方便，可进一步补充：

- ECE（期望校准误差）

最终解释模型 sensitivity（敏感性）时，应联合观察：

- ΔAUPRC
- ΔAUROC
- Mean / Median / P90 Δp
- Prediction Flip Rate（预测翻转率）
- Brier Score（布里尔分数）

如果不同模型之间 Δp 接近，且 paired bootstrap 95% CI（配对自助法95%置信区间）明显重叠，不做“谁绝对更敏感”的强排序。

### 16.5 Normalization（标准化）只能使用 Original Train 拟合

所有 normalization / scaling（标准化 / 缩放）参数只能根据：

```text

```

计算。

例如：

- mean（均值）
- standard deviation（标准差）
- median（中位数）
- IQR（四分位距）
- min / max（最小值 / 最大值）

都只能从 Original Train（原始训练集）拟合一次。

拟合完成后 scaler（标准化器）必须冻结，并统一应用到：

```text

Original Test
Drop20 Test
Drop40 Test
Continuous5min Test
```

禁止：

- 在 Validation（验证集）重新拟合 scaler；
- 在 Drop20 上重新算均值 / 标准差；
- 在 Drop40 上重新算均值 / 标准差；
- 在 Continuous5min 上重新算均值 / 标准差。

否则等于让模型在测试阶段适应 perturbation（扰动），会影响公平性。

统一原则：

> **Scaler fit on Original Train only, then freeze.（标准化参数只在原始训练集拟合一次，然后冻结。）**

不要因为多 seed 或 Source 扩展影响周一前六模型主结果交付。

## 19. 最终公平性检查

任何模型提交结果前都检查：

- 是否使用唯一 frozen benchmark
- 是否覆盖 test 全部 5,236 个 CSN
- 是否没有自行删 visit
- 是否 label 来自 manifest_final.parquet
- 是否训练只使用 Original train
- 是否 validation 只使用 Original validation
- 是否一个 checkpoint 测四套 test
- 是否扰动后重新计算模型需要的缺失派生特征
- 是否 test threshold 未重新调参
- 是否保存患者级 prob

如果任一项失败，先修复，再进入六模型总表。
