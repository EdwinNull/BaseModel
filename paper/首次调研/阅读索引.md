# 首次调研：合并阅读索引

本目录合并第一轮经过身份修复的直接相关论文与第二轮定向检索结果。阅读对象按项目决策需要分为三部分，而不是按原始文件编号堆放。

| 部分 | 内容 | 优先入口 |
|---|---|---|
| [时序基础模型](时序基础模型/README.md) | 个体病程预测、医学时序表示与转重风险建模 | [模型对比表](时序基础模型/模型对比.md)、MIRA、MOMENT、医学 Chronos 微调 |
| [强化学习/后训练奖惩机制](强化学习_后训练奖惩机制/README.md) | 奖励、惩罚、偏好、约束、离线策略评估 | medR、势函数塑形、DR-OPE、CQL/CPO |
| [数据集](数据集/README.md) | 个体病程、ICU 不规则时序、跨医院验证与流感背景 | [数据集对比表](数据集/数据集对比.md)、MIMIC-IV、eICU、HiRID |

## 建议阅读顺序

1. [MIMIC-IV](数据集/03_MIMIC_IV/阅读笔记.md) 与 [数据集对比表](数据集/数据集对比.md)：先固定 `t0`、转重标签、预测窗口和时间泄漏规则。
2. [MIRA](时序基础模型/06_MIRA/阅读笔记.md)、[MOMENT](时序基础模型/04_MOMENT/11_阅读笔记.md) 与 [医学 Chronos 微调](时序基础模型/07_Chronos_医学微调/阅读笔记.md)：建立不规则时序、表示学习和小模型后训练基线。
3. [eICU-CRD](数据集/04_eICU/阅读笔记.md) 与 [HiRID](数据集/05_HiRID/阅读笔记.md)：做跨医院和高频不规则外部验证。
4. [Chronos](时序基础模型/01_Chronos/08_阅读笔记.md)、[Lag-Llama](时序基础模型/03_Lag_Llama/10_阅读笔记.md)、[TSPFN](时序基础模型/08_TSPFN/阅读笔记.md)：补足规则化概率和小样本分类对照。
5. [FluSight](数据集/01_FluSight/阅读笔记.md) 与 [Flusion](时序基础模型/05_Flusion/19_阅读笔记.md)：最后用于季节强度/地区背景，不作为个体转重主线。

## 证据与排除

- 本轮筛选标准、来源与优先级依据在 [调研报告](调研证据/report.md)。
- 原始库的错配、替换与主题不匹配记录在 [迁移前论文身份核对](../首次调研阅读/00_论文身份核对.md)。该文件是历史存档；当前有效口径以本索引和 [调研证据](调研证据/README.md) 为准。
- Phi、Qwen、Mistral、BioGPT、ClinicalBERT、MedAlpaca、PMC-LLaMA 等通用/医学文本模型不列为本轮三主题精读对象：它们可以作为文本解释层候选，但没有直接构成医学时序预测基础模型、医疗时序奖惩机制或目标数据集的证据。

## 使用边界

- 治疗策略 RL 的奖励、WIS 和安全约束不能直接改写为个体转重预测损失；只有在明确行动、状态转移和决策日志后，才建立独立的治疗决策 RL 任务。
- 公开数据分为可直接下载与凭证/数据使用协议访问；实际项目排期以数据申请完成和原始版本审计为准。
- “双 L40 可用”只表示推荐先做小模型后训练试验，不表示所有模型的预训练或任意上下文长度均可运行。
