五个模型放在一起看

每个点是一个 seed，竖线是 5 个 seed 的均值。这一节只描述，不做检验；OPL-MT-MNAR 出来后同样加一行。

看到的

  • Raindrop 的 seed 间差异最大（AUPRC 的 SD 为 0.013，其余四个模型 ≤ 0.003），只看一个 seed 容易把它的位置看错。
  • 五个模型都没有在本数据上调参，差异不能直接归因于结构。
看到的
  • 随机删 40% 时，五个模型的 ΔAUPRC 都为负：GRU-D −0.036、BRITS −0.033、mTAND −0.024、Raindrop −0.024、FF-LSTM −0.016。原始区分度最高的两个模型掉得最多。
  • 随机删 20% 时方向相同，幅度约为删 40% 时的三分之一到一半。
  • 删连续 5 分钟时，AUPRC 和 AUROC 不一致：Raindrop 的 ΔAUPRC 只有 −0.001，ΔAUROC 却是 −0.020，和 GRU-D 一样；mTAND 两项都接近 0（ΔAUPRC +0.004）。只报 AUPRC 会漏掉这类变化。
看到的
  • drop40 下，Mean |Δp| 最大的是 GRU-D（0.071）和 BRITS（0.064），最小的是 mTAND（0.035）；Flip Rate 最高的是 Raindrop（9.7%）和 BRITS（9.2%），最低的是 mTAND（6.2%）和 FF-LSTM（6.4%）。

03

待定①：模型之间怎么比

你在 paired_seed_model_comparison.csv 里已经用了一种方法：同一个 seed 下，拿 GRU-D 的 Δ 减去 LSTM 的 Δ。我觉得这个方法好，因为它把训练随机性算进去了，而 10-21 的结果显示，seed 之间的差异比单个 run 的 bootstrap CI 还大。

差值(模型, seed s, 扰动 v) = Δ指标(模型, s, v) − Δ指标(FF-LSTM, s, v)　　差值 < 0 ⇒ 这个 seed 下该模型比 LSTM 掉得多
看到的
  • drop40 时，四个模型的 ΔAUPRC 在 5 个 seed 里都比 FF-LSTM 更负（都是 5/5）：平均多掉 GRU-D 0.020、BRITS 0.017、mTAND 0.008、Raindrop 0.008。
  • continuous5min 下分成两组：GRU-D、BRITS 的 ΔAUPRC 比 LSTM 更负（4/5、5/5），mTAND、Raindrop 则 5 个 seed 都比 LSTM 掉得少（0/5）。换成 ΔAUROC，Raindrop 又是 5/5 比 LSTM 掉得多。
  • 按你的条件，GRU-D 和 BRITS 几乎每个 seed 都是"原始更强、掉得也更多"；mTAND、Raindrop 原始就不比 LSTM 强（0/5、1/5），所以几乎不满足。

你定义的"原始更强、且掉得更多"条件

按你 five_seed_sanity.json 里 condition 的定义：同一个 seed 下，原始 AUROC 和 AUPRC 都高于 LSTM，并且该扰动下 ΔAUROC 和 ΔAUPRC 都比 LSTM 更负。表中是满足条件的 seed 数（满分 5）。

我的提议
  • 六模型统一用你的方法，覆盖从 drop40、continuous5min 扩大到三种扰动，把 drop20 也加上。
  • 每个模型都和 FF-LSTM 比，报 5 个 seed 差值的均值 ± SD，以及差值 < 0 的 seed 数。
  • n = 5，不做显著性检验，表述用"5 个 seed 中 k 个"。
  • 这一方法已经写进我的方案锁（10-22），计算在登记之后。
想问你

待定②：校准口径

两边都用了 pos_weight ≈ 7.08 的加权 BCE。它不影响排序，但会把预测概率整体推高，所以五个模型的 Brier 都比"所有人一律预测患病率"还差。

会变的和不会变的

指标Platt（严格单调）Isotonic（分段常数）
AUROC、AUPRC、ΔAUROC、ΔAUPRC不变基本不变（会产生并列值）
Flip Rate不变：阈值在校准后的验证集上按同一 F1 规则重选，判定与原来完全一样可能变
Brier、ECE、ΔBrier变（变好）变（变好）
Mean |Δp|、Median |Δp|变（数值缩小）变

我 10-21 的报告里写的是"会改变 Flip Rate"，用 Platt 时这句不对，会在报告里更正。

我的提议
  • v1 不动：所有 Brier、ECE、ΔBrier 标注"pos_weight 加权口径下"，不拿来比较模型的校准能力。
  • 如果 PPT 或论文需要"概率可以直接读"，再登记 v1.1：六个模型统一在 Original Validation 上做 Platt，测试集只用来评价。只用新的预测文件，不重新训练。
  • v1.1 的主要变化是 |Δp| 变小，排序类指标和 Flip Rate 不变，所以主要结论不受影响。

五模型数值表与说明

A1 五个 seed 的均值 ± SD

与 five_model/five_seed_mean_std.csv、policy_shift_degradation_five_seed.csv 相同（SD 为 ddof=1），这里保留 3 位小数。

A2 名词

Δ（ΔAUPRC 等）
扰动后的指标减原始指标，同一个 checkpoint、同一批病人。负数表示变差。
Mean |Δp|
每个病人扰动前后预测概率之差的绝对值，再对 5,236 人取平均。
Flip Rate
在验证集上选好的阈值固定不动，扰动前后判定（阳性 / 阴性）不同的病人比例。
配对差值
同一个 seed 下，某模型的 Δ 减 FF-LSTM 的 Δ；小于 0 表示该模型掉得更多。
pos_weight
BCE 里给阳性样本的权重，取训练集阴性数 / 阳性数 ≈ 7.08。
再校准
在验证集上拟合一个单调函数，把预测概率映射到更接近真实发生率的数值。
