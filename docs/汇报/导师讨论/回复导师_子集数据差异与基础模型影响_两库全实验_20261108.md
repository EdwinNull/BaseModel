## 一、回复正文（可直接发送）

老师您好：

您问分诊等级、到达方式等子集在数据上有什么物理差异，以及这些差异对基础模型有什么影响。我把两个数据集、整个实验过程（零样本预测、零样本风险读出、冻结嵌入 + 线性探针、监督模型参照）的结果放在一起回答。

先说结论：子集之间最大的差别在"怎么测"，不在"测出来是多少"。零样本基础模型恰好对"怎么测"最敏感，对"测出来是多少"却看不见。所以子集上的表现差异，大部分来自测量过程，而不是模型对某类病人的生理有特定缺陷。

**一、两库数据上的差异**

1. 测量过程（差别最大）。
   - MIMIC-IV-ED（到院后 2 小时、15 分钟一格）的数据很稀。2 小时内只有分诊那一次测量的比例，High / Moderate / Low 依次为 51% / 81% / 87%；全体约 70%–78% 的输入序列是常数。
   - MC-MED（安置床位后 15 分钟、监护仪每分钟记录）的数据很密，心率序列中常数只占约 21%。High 与 Moderate 差得不多，心率只有一分钟有观测的比例为 13% / 22%；Low 组大多不上监护仪，只有一次手工记录（59%）。
   - 到达方式：两库都是急救车送达的测得更早、更多。MC-MED 第一个心率在第 3 分钟，自行到达在第 7 分钟；MIMIC-IV-ED 只有分诊值的比例为 58% 对 76%。
   - 年龄：两库都是 75 岁及以上的测得更多。
2. 数值水平。两库三组的中位数都很接近，心率约 78–82 次/分，差别在异常的尾部。MIMIC-IV-ED 上下文中心率超过 110 的比例为 14% / 6% / 4%，平均动脉压低于 65 的比例为 4.3% / 0.8% / 0.3%。MC-MED 的任务定义已排除一开始就异常的就诊，所以没有这一项差异。
3. 后续走向。分诊之后体征整体回落。
   - MIMIC-IV-ED 上回落明显：心率平均下降 4.0 / 5.7 / 8.5 次/分，低危组最多；自行到达下降 6.8，急救车送达下降 2.8。
   - MC-MED 从安置床位开始算、只看 60 分钟，心率只降 1–2 次/分，平均动脉压降 3.6–5.3 mmHg。
4. 结局率。高危组、急救车送达的转重率更高：MIMIC-IV-ED 为 11.4% / 1.0% / 不足 10 例；MC-MED 为 17.0% / 11.0% / 7.3%。
5. 一个流程信号。MIMIC-IV-ED 有 1.4% 的就诊分诊体征里没有心率，这类就诊的转重率约 45%，其余就诊为 4.8%。它们集中在高危组和急救车送达。

**二、对基础模型的影响（按实验阶段）**

1. 零样本预测（两库，2 小时和 4 小时上下文）
   - 输入是常数序列时，八个模型都先按序列自身做标准化，输出就是一条水平线，与"沿用最后一个值（LOCF）"完全相同。MIMIC-IV-ED 中、低危组 80%–90% 的输入属于这种情况。
   - 输入有波动时，七个模型把预测往这段序列的均值拉回，TimesFM 则顺着趋势外推，结果都不如 LOCF。
     - MIMIC-IV-ED：八模型平均差 8%–18%。
     - MC-MED：TimesFM 的误差约为 LOCF 的 2 倍；其余七个模型的中位数比 LOCF 差 0%–4%。
   - 标准化把绝对水平去掉了，模型看不到"这个值偏离正常多少"，也就用不上"偏高的值会回落"这条规律。按末值偏离人群水平做回归，真实数据的斜率在 MIMIC-IV-ED 为 −0.41 到 −0.75，在 MC-MED 为 −0.13 到 −0.31；模型只有 −0.02 到 −0.13，常数输入上恰好为 0。
   - 因此，MIMIC-IV-ED 上高危组看起来"预测更差"，是因为高危组有波动的输入更多。在相同的序列形状下比较，差异就消失了。
   - 自行到达在相同形状下反而更差，两库方向一致（MC-MED 上主要来自 TimesFM）。原因是分诊值偏高、之后回落，而模型往回拉。
   - 上下文加长到 4 小时后，预测不再那么平直：紧贴最后一个值的比例从 72%–83% 降到 38%–43%。但误差仍然不低于 LOCF。
2. 零样本风险读出（先预测轨迹，再看是否越阈）
   - MC-MED：一开始就异常的就诊已被排除，预测又基本不会越阈，所以截断风险分几乎全为 0。AUROC 为 0.50–0.52，ESI、到达方式各子集也都在 0.50 附近，子集之间的差值只是噪声。改用连续分数后为 0.64–0.67，仍低于直接看上下文里最异常的值（0.69）。
   - MIMIC-IV-ED：截断分 0.62–0.64，连续分 0.72–0.73，都低于直接看上下文最异常值（0.66 / 0.76）。
     - ESI 3 不比 ESI 1–2 差。
     - 最差的格子是"2 小时内最多一次生命体征测量的高危就诊"。但 LOCF、上下文最大值和五个监督模型在这一格同样明显更差，说明是这个子集本身信息太少。
3. 冻结嵌入 + 线性探针（MIMIC-IV-ED）
   - 在摘要特征上加入嵌入有小幅增益，但增益全部来自"多早测到第一次体征"，也就是上面的分诊缺测信号。对常数序列，嵌入只编码"哪个变量、序列多长"。
   - 在完整的监督特征上，增益为零。≥75 岁的差距没有变化；稀疏高危就诊的差距在摘要特征上缩小 0.010–0.015，在完整监督特征上不变。
   - 按此前的决定，MC-MED 上不再重复这一步。
4. 监督模型参照（两库，五个监督模型）
   - MC-MED：ESI、到达方式子集上没有一个模型稳定变差。难的是窗口内观测少的就诊（≤15 个值，−0.07 到 −0.08）；确认集上方向相同，但幅度大多不到发现集的一半，判为未复现。
   - MIMIC-IV-ED：
     - 急救车送达的子集更差。在 ed_ts_bench 发现集上，补丁前五个模型中有四个判为差（−0.029 到 −0.035），确认集上复现。输入加到补丁 3（到达方式、化验、主诉等）后为 −0.018 到 −0.027，五个模型都仍判为差。
     - 稀疏高危就诊最难（−0.19 到 −0.23），加入化验、主诉后为 −0.09 到 −0.10。
     - 输入里没有 ESI 时，高危组的风险被低估（观察/预期比 1.18–1.27），低危组被高估（0.33–0.43）。把 ESI、年龄加进输入后，校准恢复。
   - 两库共同、最稳定的子集信号是 ≥75 岁排序更差，但原因不同：MIMIC-IV-ED 是老年非事件病例本身病情更重；MC-MED 是老年事件多由血氧触发。

**三、总结**

1. 子集差异的主体是测量过程：重复测量多少、是否上监护仪、多早开始测。数值水平的中位数几乎相同，差别在异常尾部和分诊后的回落。
2. 零样本基础模型有三个特点：
   - 实例标准化让它看不见数值水平；
   - 遇到常数输入就退化为 LOCF；
   - 遇到有波动的短序列会过度回拉或外推。

   因此它们在子集上的表现差异，主要跟着"有多少有波动的输入"走，而不是跟着病情走；风险读出也不会超过直接看上下文里最异常的值。
3. 监督模型能直接使用绝对水平、ESI、年龄等信息。它们在子集上的问题集中在"窗口里信息太少"的稀疏高危就诊和老年人，属于数据侧的难点。

说明：
- 结论均为探索性。
- MC-MED 的分布描述用了训练集、验证集和测试集的一半；另一半按规定作为确认集，不再使用。
- "往均值回拉""向人群水平回落"等几项，是看过初步结果后补做的诊断。
- 详细表格见附件。

想请老师定两件事：
1. 今后报告子集结果时，是否固定加上测量过程分层（输入序列是否为常数；MIMIC-IV-ED 看分诊是否缺测，MC-MED 看是否上监护仪），并与 ESI 交叉报告？
2. 是否需要做一个保留绝对水平的零样本对照，例如把绝对值作为协变量输入？我倾向先不做：零样本预测在两库都没有超过"直接看上下文最异常值"，这一步即使有改善，也只是在 LOCF 附近修正。

## 三、可能的追问

- **MC-MED 为什么只用一部分数据？** 测试集的另一半按 D111 留作确认集，规定不再使用。分布描述中，有未来值的部分（回落、模型误差）只在测试集 A 半（2,634 次）上计算，其余在 51,068 次上计算。
- **急救车送达的数字为什么和讨论稿第三部分 §12.1 不一样？** §12.1 是在零样本评价队列（37,806 次）上用补丁前的监督参照，只有 Raindrop 判为差；这里引用的是 ed_ts_bench 发现集（38,242 次）的结果。两处队列和判据不同，讨论稿 §12.1 已加注。
- **为什么不做显著性检验？** 这是描述分析，模型误差比值给出了按患者聚类的 bootstrap 区间（B = 1000），没有做多重校正。
- **分诊缺测是不是直接进抢救？** 这是推断，数据里没有能核对的流程字段。
- **"往均值回拉"是不是所有模型都有？** 八个模型中有七个；TimesFM 是外推。Chronos-2 回拉最少，误差也最接近 LOCF。
