## 1 复现核对：TabPFN 未达容差，对指标没有实质影响

- **lgbm：** 与第三轮逐位一致，两库所有行最大差 0。
- **tabpfn**（温度 0.9，由原始 logit 计算）：
  - n = 2,500、5,000：40 次拟合全部在 1e−7 以内一致。
  - n = 1,000：MC-MED 12/20 次、MIMIC-IV-ED 9/20 次拟合有差，最大 0.0022、0.0045。
  - 每个 GPU 进程的第一次拟合（r = 0–3）都与第三轮一致，差异只出现在同一进程里已经跑过其他拟合之后。
  - 单次拟合在全部评价行上的 |ΔAUROC| 最大 4e−5。
- **原因：** 没有完全查明。TabPFN 的结果受同一进程中此前运行的影响。
  - 查过一个候选：TabPFN 是否分块计算由当时的空闲显存决定（`tabpfn/memory.py`）。
  - 但如果是这个原因，差异应出现在格子更多的 n = 5,000，而实际只出现在 n = 1,000，所以可能性不大。
- **影响：** 比本轮讨论的最小效应（约 0.001）小两个数量级以上，不影响判读。
- 冒烟时只跑了每进程的前两次拟合，所以没有暴露这一点。以后若需要逐位复现，每次拟合用一个新进程。

## 2 结论

1. **Q5：在小样本内部学习组合方式不如等权平均。12 个比较中 10 个"差于"，2 个"持平"，没有"优于"。**
   - stack（交叉拟合的 α 加权 + 再校准）：
     - n = 1,000、2,500 两库都"差于"：MC-MED −0.0042、−0.0015，MIMIC-IV-ED −0.0016、−0.0006。
     - n = 5,000 两库都是 −0.0002，区间在 0 以下，但反向抽样只有 8 次，判"持平"。
     - 原因：α 估计得很不稳定。n = 1,000 时 20 次抽样的 α 散布在 0.0–0.9；n = 5,000 时收窄到 0.3–0.8。权重的估计误差抵消了"学权重"的好处，样本越小越明显。这与预测组合文献中的"组合难题"一致（Smith 与 Wallis 2009，基于摘要）。
   - pfnboost（以 TabPFN 交叉拟合 logit 为起点的 LightGBM）：6 个全部"差于"，−0.0027 到 −0.0076。
     - 原因：以对数损失早停时，从 TabPFN 起点出发只加了很少的树。轮数中位数 MC-MED 3、3.5、3，MIMIC-IV-ED 1、1、2；"不加树"被选中 4–8 次（每格 20 次）。
     - 结果它几乎就是 TabPFN 本身：与 TabPFN 的差只有 −0.0006 到 +0.0027。平均里 LightGBM 带来的那部分多样性就丢掉了。
2. **Q6：增益大约一半来自"多模型平均"本身，另一半是 TabPFN 特有的。**
   - LightGBM 5 种子平均（lgbm_bag）本身就比单个 LightGBM 高：MC-MED +0.0063、+0.0041、+0.0029，MIMIC-IV-ED +0.0043、+0.0038、+0.0025，每格 20/20 次为正。
     - 这相当于 tabpfn_lgbm 增益的 44–61%。小样本下单个 LightGBM 的方差很大。
   - tabpfn_lgbm 对 lgbm_bag：两库三个 n 全部"优于"，+0.0025 到 +0.0050。多出的这部分来自 TabPFN。
   - tabpfn_lgbm 对 lgbm_lr（LightGBM + LR 平均）：
     - MC-MED 全部"优于"，+0.010 到 +0.011。MC-MED 上 LR 明显差（比 LightGBM 低 0.045），平均进来没有帮助。
     - MIMIC-IV-ED 上 n = 1,000、2,500"持平"（−0.0011、+0.0009），n = 5,000"优于"（+0.0015）。MIMIC-IV-ED 上 LR 与 LightGBM 相近（n = 1,000 时还略高），LightGBM + LR 平均拿到了与 TabPFN 相同的增益。
   - 三者平均（tabpfn_lgbm_lr）：MIMIC-IV-ED 上比 tabpfn_lgbm 再高 +0.0033、+0.0012、+0.0004；MC-MED 上低 0.003。是否有用取决于 LR 在该数据上的好坏。
3. **校准：温度 1.0 基本修正了 TabPFN 的观察/预期，平均后再校准最稳。AUROC 都不变。**

   - 按交叉拟合 logit 选出的温度：MC-MED 中位数 1.00（范围 0.95–1.10），MIMIC-IV-ED 1.10–1.15（1.00–1.20）。数据都偏向比默认 0.9 更平缓的温度。

   - 再校准后 MIMIC-IV-ED 的观察/预期略低于 1。可能的原因是抽样的事件率（5.4–5.5%）略高于 S 集（5.3%），没有单独核对。

## 5 读法（方案 §4，看结果前写定）

- **读法 1（stack 或 pfnboost 两库都有"优于"）：** 不成立。
- **读法 2（Q5 全部持平）：** 不成立。
- **读法 3（Q5 有"差于"）：成立。** 在这种样本量下学习组合方式会过拟合，或者像 pfnboost 那样退化成单一模型。保留等权平均。
- **读法 4（Q6 两个对照在两库都被"优于"）：** 只在 MC-MED 成立。
- **读法 5（某库某个对照"持平"）：** MIMIC-IV-ED 成立。在 n ≤ 2,500 时，LightGBM + LR 平均拿到了与 TabPFN + LightGBM 相同的增益。LR 好的数据不一定需要 TabPFN，LR 差的数据（MC-MED）则需要。
- **读法 6（校准）：** avg_rcl 在 6 格中 5 格达标，AUROC 不变。TabPFN 单独使用时，温度改为 1.0 是不需要额外数据的简单修正。建议在小样本流程里加入这两步中的一个：要校准好的概率时用 avg_rcl，否则至少把 TabPFN 温度设为 1.0。

## 6 局限

- **评价集：** S 集第二次使用，第三轮结果已经看过。本轮问的是新问题，但候选做法越来越多，在同一集合上挑选会带来乐观偏差。
- **复现：** TabPFN 在 n = 1,000 有进程状态相关的小差异，见 §1。
- **stack 的设计：** 只学了一个权重加两个再校准系数，已经是很克制的形式，仍然不如等权。没有试收缩到 0.5 的权重。
- **pfnboost：** 按方案用交叉拟合的 TabPFN logit 作起点。原文（arXiv 2502.02672）如何取训练集分数、是否对 logit 做中心化，我们没有核对全文；原文的结论可能依赖与这里不同的设置。
- **lgbm_bag 的种子数：** 只用了 5 个，更多种子可能还会再涨一点。
- **TabPFN：** 仍是 `n_estimators` 4。lgbm_bag 的结果提示，TabPFN 自身多一些子模型也可能降低方差，本轮没有测。
