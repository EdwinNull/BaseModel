# 老年人流感转重预测：基础模型后训练调研

本仓库汇集项目现阶段的医学时序基础模型、文献精读及后训练/强化学习奖惩机制调研成果。目前主要是研究材料与方法论分析，尚不包含经验证的临床预测模型或患者数据，不应用于临床决策。

## 材料目录

| 入口 | 放什么 |
|---|---|
| [docs](docs/README.md) | 项目说明、数据规范、操作教程、终点核验与汇报文字 |
| [plans](plans/README.md) | 按研究主题分类的实验方案、候选规则与执行计划 |
| [result](result/README.md) | 与方案对应的聚合结果、配图、计数报告与阶段总结 |
| [research](research/README.md) | 按调研主题分类的文献报告、来源记录与展示页 |
| [PPT](PPT/README.md) | 演示文稿成品、模板、生成脚本和素材 |
| [paper](paper/) | 论文库与精读笔记，沿用既有主题结构 |

寻找同一实验时，先在 plans 中按主题找方案，再到 result 的同名主题查结果。文件名保留原日期、D 编号和版本；目录位置不表示方案已经锁定、当前有效或结果已经确认，具体状态以正文为准。

目录规则及旧路径查询见 [整理说明](docs/目录导航/目录整理说明_20261109.md)。
