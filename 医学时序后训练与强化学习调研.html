结论先行

八条结论

标"新"的是本轮（09-25）得出或改写的结论，标"延续"的是前几轮已有、本轮再次得到支持的结论。

新C011

医学时序大模型的 RL 后训练已经成型

ECG、EHR 纵向记录、可穿戴行为序列上都出现了全文工作。配方一致：SFT 热身，再用 GRPO 或 DAPO；奖励是可自动核对的结局分加格式分，不训练人类偏好奖励模型。S030 S032 S034 S036

新C012

预测侧的风险 RL 已经出现在 EHR 上

EAG-RL 在 MIMIC-IV 住院死亡与 30 天再入院上用 GRPO 训练 7B 模型，奖励是概率对数得分；EHR-R1 对 18 个风险任务用 F1 作奖励。任务形式与转重预测同构，但都不是流感或老年人群。S036 S034

新C013

奖励分三层，过程层很少见

结局层（指示函数、Jaccard、F1、序数高斯、对数得分）几乎人人都用；用可核对的外部证据做过程奖励的，只有 ECG-R1 的证据覆盖和 EAG-RL 的专家特征对齐。S032 S036

新C014

时效奖励最值得借给转重预警

PhysioNet 2019 效用函数：发病前 12 到 6 小时报警从 0 升到满分 1，之后到发病后 3 小时降回 0；漏报最多扣 2 分，误报每小时扣 0.05 分。停时策略用正确 +1、错误 −1 加等待惩罚。S047 S049

延续C015 · C008

治疗侧奖励十年变化不大

仍是终末生存加 SOFA/乳酸或治疗靶区间。Raghu 2017 的中间奖励常数被 2026 年的 SepsisAgent 原样复用；新变化是动作成本、指南违规和分布外惩罚。S051 S037 S062

延续C016

数据集集中在 MIMIC，外部验证稀少

EHR/ICU 线几乎都用 MIMIC-III/IV，ECG 线用 MIMIC-IV-ECG 与 PTB-XL。公开的跨中心组合只有 YAIB 支持的 MIMIC、eICU、HiRID、AmsterdamUMCdb。S046 S038

新C017 · C018

基线清单相当固定，LLM 并未稳赢

LLM 线必比 GPT-4o 与同底座 SFT，却很少对比 LightGBM、GRU-D 这类强监督基线。HEARTS 与 ICU 不规则时序基准都发现 LLM 落后于专门模型或需多花约 10 倍训练。S042 S045

新C019

底座不大，但没有一篇装得进双 L40

底座多为 1B–8B，报告的总显存 160–640GB。单卡 48GB 的 TimeMaster 与 EAG-RL 都用了 4 张卡。双 L40 共 96GB，需缩小组大小与序列长度后实测。S030 S036 S035

对本项目意味着什么

主线不变：先固定 t0、复合终点与预测窗口，做监督或生存后训练。在它之后，新增一条有文献依据的"预测侧 LLM-RL"实验线：奖励只放有界的适当评分规则，老年漏报代价留在阈值和决策曲线里处理，不写进奖励权重。理由见奖励权重推导。

已知的失败模式

预测奖励（第 3 轮，通用时序为主）

  • 无界负误差加组归一化，优势被异常样本主导。S005
  • 绝对误差在强基线附近没有组内区分度，27.97% 的组近零方差。S007
  • 只优化点误差会得到过平滑、趋势错误的预测。S006
  • 精确匹配对序数或近邻结果没有梯度。S004
  • 不做监督热身，RL 会破坏输出格式。S002
  • 先看过真值的合成思维链会把后见之明写进推理。S007
  • 人类偏好或另一个大模型的评分，不能替代可核对的未来观测。S008

医学时序（本轮新增）

  • 零样本 LLM 做胰岛素规划时，思维链让小模型给药更激进，低血糖风险上升；7B 到 70B 没有继续提升。S063
  • 只有终末奖励时，ICU-Sepsis 中随机策略与临床策略回报同为 0.78，最优仅 0.88。S060
  • 4 小时步长只是惯例；1–2 小时步长在离线脓毒症 RL 中更好更稳。S064
  • 世界模型单独接给 LLM 并不稳定，需要 SFT → 行为克隆 → RL 分阶段。S037
  • 过程奖励的"裁判"本身未经验证：证据由 DeepSeek-V3.1 抽取，对齐目标是 Concare 的注意力。S032 S036
  • SOFA 下降不保证乳酸安全，治疗有效与安全需分开评估。S062

推论：为什么老年漏报代价不写进奖励权重

w = 1：最优输出 = 真实风险 正例加权 w 后的最优输出 p*

奖励用 Brier 型适当评分 S(p, y) = 1 − (p − y)²。真实风险为 q 时，期望奖励在 p = q 最大。给正例乘权重 w 后，最优输出变为

p* = w·q / (w·q + 1 − q)

所以奖励里只放适当评分规则，保持概率校准；老年漏报代价放在决策阈值、决策曲线和 65+/75+ 分层的灵敏度要求里。对数得分同理，且在 ŷ 接近 0 或 1 时无界，需裁剪到 [0.01, 0.99]。罕见结局还会让同一提示的一组采样奖励几乎相同、优势为零，可对阳性过采样（需回检校准）或改用"相对强基线的评分改进"。S007

一个可执行的奖励草案（待消融，λ 从 0 起）：

R = 0.1·Rfmt + 0.9·[1 − (p − y)²] + λ·Revid，　Revid = Jaccard(推理中引用的 t0 前异常事件, 参考事件集)

参考事件集可由规则抽取（SpO₂ 下降、氧疗升级、呼吸频率升高）或取 LightGBM 的重要特征，对应 ECG-R1 的证据覆盖与 EAG-RL 的专家对齐两种做法。
