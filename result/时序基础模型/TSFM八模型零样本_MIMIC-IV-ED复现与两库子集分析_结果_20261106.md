## 0 一页结论

1. **全量运行完整。** MIMIC-IV-ED 验证集跑了八个主模型加 Time-MoE-officialnorm，每个 114,268 条序列，没有失败的批。另在 MC-MED 上补跑了 Time-MoE-officialnorm（13,377 条）。
   - 用同一评价脚本复算梁睿颖的 MC-MED 总表，最大绝对差：AUROC 1.1e-16、AUPRC 8.3e-17、MAE 3.6e-15。
   - 移植一致性：在她的冒烟清单上，确定性模型与她的全量预测一致，最大差 ≤7e-4（§2）。
2. **预测：没有一个模型明显好过"沿用最后一个值"（LOCF）。**
   - MIMIC-IV-ED 上，八个模型的 HR、MAP 总体 MAE 都不如 LOCF：HR 最好的 Chronos-2 为 10.94，LOCF 为 10.76；SpO₂ 基本持平。
   - MC-MED 上，最好的模型与 LOCF 持平（HR 4.68 对 4.69）。
   - 两库名次相近：Chronos-2 第一，Timer-XL、TimesFM、Time-MoE（冻结路径）垫底。
   - 原因之一：MIMIC-IV-ED 有 70% 的上下文只有 1 个观测格（基本只有分诊值）。72%–89% 的预测序列 12 h 内都没有离开最后一个值 ±1（SpO₂ 为 ±0.5）。
3. **风险分：两库的"越阈"型标签上，"先预测、再套阈值"都退化了（AUROC ≈ 0.50）。**
   - MC-MED `decomp_60` 和 MIMIC-IV-ED 越阈标签上，七个模型的 AUROC 为 0.500–0.521，99% 以上的就诊风险分为 0。
   - 这两个标签都先排除了上下文里已经越阈的就诊。剩下的就诊上下文都正常，而模型的预测基本平直，所以几乎从不越阈。
   - LOCF 和 Context-max（直接对上下文最异常值套规则）按构造就是 0.500。
4. **MIMIC-IV-ED 的 D103 标签（进 ICU 或死亡）上，零样本 AUROC 为 0.617–0.638。**
   - 对照：LOCF 0.602；Context-max 0.659，比七个模型都高；监督参照 0.845–0.879。
   - 信号几乎全来自前 2 h 已经越阈的 4,410 次就诊：其中 75%–88% 的就诊风险分大于 0，其余就诊里只有 ≤1.1%（TimesFM 为 3.6%）。
   - 在"2 h 内未越阈"的就诊里，AUROC 为 0.499–0.507（TimesFM 0.551）。也就是说，规则分主要反映的是"上下文是否已经异常"；预测这一步还丢掉了上下文峰值的一部分信息。
5. **Time-MoE 在 MC-MED 上的"最好" AUROC（0.600）来自归一化路径，不是预测能力。**
   - 冻结代码直接把原始值输入，第 1 步输出平均比最后一个值高：HR +32 次/分、MAP +33 mmHg、SpO₂ +14%；99.9% 的 SpO₂ 序列预测超过 100。
   - 按官方做法先 z-score 输入后，MAE 与 LOCF 持平，AUROC 降到 0.500（MC-MED）和 0.618（MIMIC-IV-ED D103）。
6. **子集：没有"只有零样本模型差"的子集。** 达到判据的零样本缺陷有两类：
   - 子集本身难：监督模型同样差，最突出的是 MIMIC-IV-ED 的"vitalsign ≤1 次 × ESI 1–2"，16 个分数全部判为差。
   - 规则退化。

   两库共同的方向是 ≥75 岁排序更差：
   - 监督模型在 MIMIC-IV-ED 差 0.027–0.032，在 MC-MED 差 0.046–0.102，各有 1–2 个模型过了 Holm 判据。
   - 零样本模型在 MIMIC-IV-ED 同向（−0.021 到 −0.029），但没有过判据。
7. **与调研假设对照（只写一致或不一致）。**
   - 一致：H3（归一化不稳）、H5（亚组差异来自数据侧）、H6（急性信号被平滑）、S2、S4 / C3。
   - 大体不一致：H1（除 patch 最长的 Timer-XL 外，patch 模型与点级 token 模型没有分开）。
   - 不一致：S5（ESI 3 不比 ESI 1–2 差）。
   - S1 只部分一致：老年组的排序也更差，不只是校准问题。

   - 上下文里其实有信号：把最后一个 HR 值直接当连续分数（方案外描述量，不作为参照模型），MC-MED 上 AUROC 为 0.645，高于任何零样本规则分。问题在于阈值规则把阈值以下的差别全部截成 0。
2. **D103 上的信号来自"已经异常"的就诊。** 前 2 h 内已越阈的 4,410 次就诊中，各模型风险分大于 0 的比例为：

   | Timer-XL | 88% |
   | MIRA、Sundial | 81% |
   | Chronos-2 | 81% |
   | LightGTS、VisionTS | 79% |
   | TimesFM | 75% |
   | LOCF | 66% |

   - 七个模型都排在 Context-max 和 LOCF 之间：预测比"只看最后一个值"多保留了一点上下文里的异常，但比"直接看上下文最异常值"少。
3. **与监督模型差 0.21–0.26 AUROC（D103）。** 监督参照用的是 6 项体征的整段窗口并经过训练，零样本规则分只用三项体征和一个固定阈值。这个差距说明的是"先预测、再套规则"这种读出方式的上限，不说明模型表示本身没有信息。

- 结论：这不是"预测轨迹越阈"的能力。两库都按她的原样复现了主表，Time-MoE-officialnorm 只作补充、不进排名（方案 §6）。主表要不要改，交研究者定（§9）。

### 6.2 MIMIC-IV-ED，越阈标签（探索）

所有子集里七个模型（不含 Time-MoE 冻结路径）的组内 AUROC 都在 0.485–0.528，LOCF 和 Context-max 恒为 0.500。达到判据的 10 个格子中，AUROC 差的绝对值都在 0.02 左右或更小，分布在到达方式、密度、密度 × ESI、65–74 岁等格子，全部归为**规则退化**，不解释。

### 6.3 MC-MED，`decomp_60`

- **零样本：** 23 个可解释的子集里没有一个判为差或判为好。七个模型的组内 AUROC 多在 0.497–0.536，唯一例外是 TimesFM 在观测 ≤15 个的组里为 0.605（差 +0.094，Holm 后不显著），与总体一样是规则退化。所以这个库上无法用零样本规则分谈子集缺陷。
- **监督参照**：只有 LightGBM 在 ≥75 岁上判为差（824 / 119，14.4%；差 −0.102，区间 [−0.161, −0.045]）。LR、BRITS、Raindrop 同向（−0.080 到 −0.085，区间上限都 <0），但 Holm 后不显著；mTAND −0.046，区间含 0。

- 观测 ≤15 个（576 / 49）：监督模型差 −0.039 到 +0.012，不显著。

## 7 缺陷原因：与调研假设对照

依据 `research/时序基础模型与子集/tsfm-survey-20261105/REPORT.md` 的 C1–C7、H1–H6、S1–S6。只写"一致 / 不一致 / 本次无法检验"，不写成已证实。

- 模型在 15 点（MC-MED）或 8 格（MIMIC-IV-ED）的短上下文上基本输出持平轨迹。
- 固定阈值规则又把阈值以下的差别全部截成 0。
- 结果是风险分退化成"上下文里是否已经越阈"。凡是先排除已越阈就诊的标签，都会退化到 0.5。

子集层面能看到的，是与监督模型共有的数据侧难点（稀疏窗口、高龄），以及规则退化本身。

## 8 局限

1. **MC-MED 共同风险队列含 D105 的 B 半。** B 半在 D109 用作确认集，D111 定为不再使用。本次 MC-MED 只是描述性复算，零样本模型没有拟合、也不选公式，结论标为探索性。MIMIC-IV-ED 只用验证集，没有碰测试集。
2. **Sundial 有随机采样。** 本次设了种子 2026，但批划分不同，与她的运行不会逐点一致（冒烟清单上平均差 0.1–0.24）。
3. **MIMIC-IV-ED 的 MAP 是推算值**：用同一来源、同一时间的 SBP、DBP 按 (SBP+2·DBP)/3 计算。
4. **MIMIC-IV-ED 的未来观测稀疏**：每条序列 12 h 内平均约 2.4 个实测点。预测误差主要由少数时点决定，+1h、+4h、+12h 各步上的点更少。
5. **越阈标签队列里有 2,514 次就诊 (2h,14h] 内没有任何实测体征。** 按 MC-MED 的规则（实测越阈才算阳性）记为阴性，这会压低患病率。
6. **监督参照不是同一输入。** 它们是补丁前的版本：6 项体征、整段窗口、经过训练。只作上限参照，不参与排名。
7. **方案外的描述量**（平直比例、超界比例、早期越阈组内的阳性比例、上下文水平当分数的 AUROC、Time-MoE 偏移）都是看完主结果后补的。它们只用来解释，不作为判据，也不进主表。
8. **ESI 4–5 两库都事件不足。** MC-MED 不能按种族、时段分组（S3、S6 无法检验）。
