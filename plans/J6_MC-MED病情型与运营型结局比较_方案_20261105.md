# J6：MC-MED 上病情型与运营型结局的零样本比较（方案，2026-11-05）

**状态：运行前写定。** 研究者 2026-11-05 对“J6 按建议做吗？用发现集，Observation 主分析算未收住院，敏感性算收住院。”回复“按建议做”，登记为 D128。依据是 `plans/J线后续_待决定事项方案草稿_20261105.md` §4。

全部结论标探索性。公开数据不出服务器，不发给任何在线 LLM/API，只用本地模型。文档只放聚合量，人数 <10 不展示。

## 1 要回答的问题

论文的观察（p.16）是：零样本在跟病情走的结局上不输监督模型，在受医院流程影响的结局上明显更差。J 线的医院数据因为判据不可比，回答不了这个问题。

J6 问：同一批急诊就诊、同样的输入，零样本对 `decomp_60`（病情型）和急诊去向（运营型）的判别与校准有多大差别？

**这不是论文比较的完整复现。** 论文比的是零样本相对监督模型，这里只比零样本在两个结局上的绝对表现。两个结局的基础难度不同，差值不能直接读成“零样本更不擅长运营型结局”。

## 2 设计

| 项目 | 内容 |
|---|---|
| 数据 | ed_ts_bench 发现集：验证集 + 测试集 A 半，8,085 次就诊、5,726 名患者。确认集（测试集 B 半）已用掉（D109、D111），不碰 |
| 队列 | 冻结的 `measurement_policy_benchmark_v1`，只读。已排除前 15 分钟 HR>110、MAP<65 或 SpO2<90 的就诊 |
| 预测时点 | 到床后 15 分钟 |
| 输入 | 年龄、性别、分诊等级、到达方式，0–15 分钟 6 项体征的最近值和最差值，白名单取 |
| 不进输入 | `ED_dispo`、`DC_dispo`、`Admit_service`、`Hosp_LOS`、`ED_LOS`、`Dispo_time`、`Admit_time`、`Departure_time`、`Dx_*`、`Hours_to_next_visit`、`Dispo_class_next_visit`。主诉和分诊体征也不进，这是草案的选择 |
| 病情型标签 | `decomp_60`：到床后 15–75 分钟内出现 HR>110、MAP<65 或 SpO2<90，999 个阳性 |
| 运营型标签 | 由原始 `visits.csv` 的 `ED_dispo` 派生。Inpatient、ICU 算 1，Discharge 算 0 |
| Observation | 主分析算未收住院，敏感性算收住院（D128）。敏感性只换标签，不再查询模型，问题卡用主分析那张 |
| 模型 | Z1、Z2，英文，读出与 J2 相同 |
| 前向 | 2 个模型 × 2 个结局，不超过 32,340 次，完全相同的请求只算一次 |

## 3 运行前的闸门

任何一条不满足就停，不换定义重跑：

- 8,085 次就诊、5,726 名患者、999 个 `decomp_60` 阳性；
- 去向 Discharge 4,467、Inpatient 2,219、Observation 1,234、ICU 165，没有别的取值；
- 没有确认集的实例；
- 锁定文件里列的哈希全部相符，含 `visits.csv` 和 benchmark 的三个文件。

## 4 预先写定的输出

患者（MRN）聚类 bootstrap 2000 次，种子 20261105。

1. 两个结局各自的 AUROC（95% CI）、校准截距和斜率。
2. 同一批就诊上，admission 减 `decomp_60` 的配对 AUROC 差。
3. Observation 算收住院时的 AUROC、校准截距和斜率。
4. Z1 对 Z2 的配对差：AUROC、校准截距、校准斜率。

## 5 怎么读

- 第 2 项的 CI 不含 0，只说明两个结局上的判别不同，不说明原因。
- 校准和判别分开看。
- `decomp_60` 的问题卡写明了判据，admission 的问题卡只写去向，两张卡的信息量本身不同。
- 这个发现集是 ed_ts_bench 补丁线在用的，这里的结果也要计入它的多重比较。
- J2b 显示 Z2 在小分层上对提示改动不稳定，读 Z2 时要记住这一点。这次没有做提示扰动实验，不在批准范围内。

## 6 不做的事

- 不改冻结的 benchmark；
- 不训练运营型结局的监督模型，所以没有和论文一样的相对比较；
- 不跑 Z3、中文、提示扰动；
- 不把这里的结果外推到全部急诊就诊，也不外推到老年流感住院。
