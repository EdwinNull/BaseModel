# 医学数据集构建调研（2026-10-25）

服务于老年流感转重预测项目的数据集构建：34 篇论文按阅读顺序分 7 站存放。

- `论文路径讲解图_数据集构建.html`：阅读路线图、每篇的设计要点（页码/章节）与对本项目的建议、按项目环节汇总的改动。用浏览器直接打开。
- `设计要点笔记.md`：逐篇原始笔记（题录、阅读依据、要点、项目落地）。
- `00_论文身份核对.md`：每份 PDF 的标题核对结果。
- `papers_manifest.json` + `download_papers.py` + `一键下载论文.bat`：一键重新下载（已有文件自动跳过）。
- 子文件夹 `01_…` 至 `07_…`：PDF（*.pdf 已被 .gitignore 排除，不入库）。

阅读顺序：01 数据库范本 → 02 多中心协调与公共数据模型 → 03 队列、时间零点与标签 → 04 数据质量与缺失 → 05 数据收集与病例报告表 → 06 样本量、验证设计与数据集文档 → 07 面向基础模型的数据底座。

本目录不含病例内容或真实计数。
