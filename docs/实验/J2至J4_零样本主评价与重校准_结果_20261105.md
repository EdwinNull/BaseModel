# J2–J4 零样本主评价、重校准与口径比较：结果（2026-11-05）

本文对应 `plans/零样本决策读出J线_参照MedJev_实验计划_20261029.md` §3.5 的 J2、J3、J4。研究者 2026-11-05 确认 6 项（D120–D125）后，按 `W/logs/2026-11-05/J2_plan_lock.txt` 锁定运行，真实数据只评价了一次。模型都在 L40 上离线运行，病例内容没有发给任何在线服务。

本文只含聚合量，人数 <10 的单元格不展示。事件数少，所有结果都是**探索性估计**，不是临床模型的验证，也不构成任何诊疗建议。怎么解释、怎么定口径归研究者。

**2026-11-05 补充：** 不含氧疗的 state 对照和 GD 55 例补查已按 D127 完成，见 `docs/实验/J2b_不含氧疗对照与GD补查_结果_20261105.md`。那是探索性的新版本，本文的数字不变。读第 4 条结论时要一起看：拿掉氧疗项后 Z1 的判别基本不变，所以“概率跟着氧疗走”不等于判别来自这一项。

## 结论

1. **不用本院标签，判别能力只在少数分层上站得住。** Z1（OpenJev-Flash-9B）的 7 个分层里，只有 GD 的 physiologic（AUROC 0.704，95% CI 0.634–0.774）和 GD 的 o2_new（0.664，0.528–0.785）的区间不含 0.5。其余 5 个分层的区间都含 0.5。
2. **两院方向相反，但 physiologic 在两院不是同一个结局。** GD 上 physiologic 明显好于 primary（Z1 差 +0.210，CI 0.085–0.346），GAM 上反过来（−0.228，CI −0.462–0.011），Z2 也是如此。事后核查发现，GD 的 physiologic 事件 84% 由 P/F≤300 触发，GAM 93% 由呼吸≥30 触发，因为 GAM 基本没有 P/F 和 FiO2 记录。所以这个反转不能读成“病情型对治疗代理型”。但判据不同不是两院差距的主因：两院都只算呼吸≥30 时，Z1 仍是 GD 0.740（0.637–0.838）、GAM 0.530（0.400–0.659）。研究者 2026-11-05 定下：physiologic 主报 GD，这个只算呼吸的结果作跨院敏感性分析（D126）。
3. **Z1 没有比 Z2 排序更好，校准截距更好。** 7 个分层的 AUROC 差只有 1 个区间不含 0，而且是 Z2 更高（GD physiologic，−0.062）。校准截距在 6 个分层上 Z1 更接近 0，physiologic 上差距约 1；校准斜率没有一致的优势。这与论文“主要改善校准”的方向一致。
4. **Z1 的概率主要跟着“是否已吸氧或有呼吸支持”走。** 用 p 预测这一状态的 AUROC 是 0.82–0.88，而这一状态本身预测 primary 的能力很弱。GD primary 上 Z1（0.579）几乎没有超过这一状态单独排序（0.569）。
5. **未重校准的概率不能直接用。** Z1 在 primary 和 O2 上明显高估（O/E 0.28–0.42），在 GD 的 o2_new 上低估（1.82）。同中心只调截距能修正整体偏差。Platt 在这个样本量上不稳定，斜率翻负时会把排序倒过来，所以这里更支持只调截距。
6. **校准参数只能部分跨院迁移。** primary 上跨院调截距有明显改善，o2_new 上反而变差。
7. **监督模型大多在 25–100 个标签内追上零样本。** GD physiologic 上差距最清楚：100 个标签时监督模型 0.77–0.79，零样本 0.71。例外是 GD o2_new 和 GAM primary，在可用的标签预算内没有追上。锁定输出里的交叉点有一部分是 Platt 翻转造成的，见下面的 J3c。
8. **Z3 的排序与 Z1、Z2 同一量级，但概率不能用**：校准斜率只有 0.03–0.19。
9. **对 O2_NEW 还是 o2_hypox，零样本没有给出一致的证据。** 两个中心方向相反，区间都含 0。这里只作证据，不替研究者定口径。
10. **字段缺口比样本量更急。** GD 几乎没有 SpO2，GAM 没有 FiO2 和 P/F。这决定了 physiologic 能不能跨院比较，要在前瞻表单定稿前解决。

P/F 判据只看 `EXT_PF` 这个字段（`grading.py:235`）。GAM 基本没有这个字段，也没有 FiO2，所以 P/F 事件在 GAM 上几乎不可能被判定。GD 的 SpO2 也不是序列化器漏掉的，导出里本来就很少。

**Z1 在不同事件上的排序（AUROC）：**

| 分析 | GD | GAM |
|---|---|---|
| 全部 physiologic | 0.704 | 0.558 |
| 呼吸≥30 是首先触发判据的事件，对全部非事件 | 0.786（10 个事件） | 0.538（28 个事件） |
| P/F 是首先触发判据的事件，对全部非事件 | 0.688（51 个事件） | 事件 <10 |
| 标签重判：两院都只算呼吸≥30，任何时候出现都算（D126） | 0.740（25 个事件） | 0.530（28 个事件） |
| 只在之后做过血气的人里 | 0.699（n = 76） | 0.432（n = 33） |
| 单独用最差呼吸频率排序 | 0.696 | 0.656 |
| 单独用年龄排序 | 0.675 | 0.631 |

血气与事件的关系：GD 之后做过血气的人事件率 74%，没做过的人里事件 <10 例；GAM 分别是 58% 和 15%。Z1 预测“之后会做血气”的 AUROC 是 0.648（GD）和 0.673（GAM）。

**Z1 主要在读“是否已吸氧或有呼吸支持”（primary 人群）：**

| 项目 | GD（n = 191） | GAM（n = 84） |
|---|---|---|
| 预测时点已有氧疗或呼吸支持 | 62% | 18% |
| Z1 预测这一状态的 AUROC | 0.875 | 0.878 |
| p 的中位数：有 / 无 | 0.404 / 0.163 | 0.476 / 0.230 |
| 这一状态单独预测 primary 的 AUROC | 0.569 | 0.455 |
| Z1 预测 primary 的 AUROC | 0.579 | 0.711 |

读法：

- **字段差异是确认的事实。** 两院的 physiologic 主要判据不同，所以 J4 的反转不能读成“病情型对治疗代理型”。
- **判据不同不是主因。** 两院都只算呼吸≥30 时，Z1 是 GD 0.740、GAM 0.530，Z2 是 0.790、0.530，GAM 上 physiologic − primary 也基本不变（Z1 −0.229）。GAM 的事件离预测时点更远，呼吸测得更勤，这些因素各占多少没有量化。
- **“血气开单就是信号”这个假设不成立。** 我原来怀疑 GD 的排序来自谁被开了血气，但只在做过血气的人里 GD 仍有 0.699。不过 GD 的 physiologic 事件几乎只出现在做过血气的人身上，这个测量依赖仍然存在。
- **GD primary 上 Z1 几乎没有超过“已吸氧”这一条信息**（0.579 对 0.569）。GD 多数患者在预测时点已经吸氧，这条信息区分不了后续事件。
- **GAM physiologic 上简单指标比 Z1 好。** 单用最差呼吸频率 0.656，Z1 只有 0.558，说明 Z1 没有用好 state 里已有的呼吸频率。

### 样本量与前瞻收集（J3c 加 pmsampsize）

`docs/实验/前瞻样本量情景_20261031.md` 的规划基准是结局率 10%、C = 0.75、20 个候选参数，至少 2293 例。下面只回答 J3c 能补充什么，最终样本量归研究者定。

| 路线 | 要多少标签 | 依据 |
|---|---|---|
| 零样本 + 本地只调截距 | 每个中心约 140–280 例（约 30 个事件），把截距估到 ±0.4 | 正态近似：SE ≈ 1 / √(n·p·(1−p))，要 n·p·(1−p) ≥ 24。p = 22% 时 140 例，p = 12% 时 228 例，p = 9.5% 时 279 例 |
| 开发监督模型 | 约 1300–3700 例 | pmsampsize，20 个候选参数：结局率 20%、C = 0.75 时 1322 例；10%、C = 0.70 时 3729 例 |

J3c 的“25–100 个标签追上零样本”不能当开发模型的样本量读。它说明零样本的起点不高，不说明这么少的标签能得到稳定的模型：这些监督模型的校准斜率在 20 次抽样之间波动很大，例如 GD physiologic 100 个标签时 LR 是 0.25–3.03，GD O2 100 个标签时 LightGBM 是 −0.14–2.43。J2 的结局率（primary 12%、O2 9.5%）和这里的 C（0.56–0.77）落在情景表偏难的一侧，所以规划基准不算保守。

**比病例数更急的是字段。** physiologic 能否跨院比较，取决于 GD 补 SpO2（含吸氧状态）、GAM 补 FiO2 或 P/F，以及两院都记录血气时点。病例数再多也补不回这些缺口，所以它们要在前瞻表单定稿前解决。

## 假设

- 评价人群和标签按锁定方案：`value_*` 直接取 flucase 导出的有效层，这里不重算分级。
- O1 的每个口径都排除了基线窗内已经达标的实例（`grading.py` 的 `_progress`），而且基线按该口径自己的判据算，所以不同口径的人群不同，J4 只在共同实例上比较。
- 读出参数沿用官方 helper，没有在本院数据上调过。提示词和问题卡在看到真实数据之前定下。

## 泄漏或偏倚

- **physiologic 有测量偏倚。** 规则集写明“检出率随测量次数变化”（D15）。GD 的事件几乎只出现在做过血气的人身上，GAM 的呼吸测得更勤，两院的主要判据也不同。这些偏倚的大小没有量化。
- **primary 是治疗代理。** 依赖给氧决策和低氧记录，受科室流程影响，两院的差异可能来自流程而不是病情。
- **state 含基线窗内已开始的氧疗和呼吸支持。** 模型看到这些信息是合理的，但 O2 上要注意它们也是病情指标。
- **可评估比例差异大。** o2_new 的可评估实例明显少于其他口径，被排除的实例不一定是随机的，这里没有分析。
- **防泄露测试只覆盖序列化。** flucase 分级本身有没有时间穿越，不在这里的范围内。
- **多重比较没有校正。** 3 个模型 × 2 种格式 × 2 种模式 × 7 个分层，加上配对比较，单个区间不含 0 不能当作确证。两院方向相反这一点在 Z1、Z2 上都出现，但两个模型的输出高度相关，不算独立重复。

## 局限

- 事件少：GD primary 23、GAM primary 10、O2 20，区间普遍很宽。
- J0 预定的容差最大 |Δp| ≤ 0.02 未达到（D120）：fp32 投影对全 fp32 0.0271，vLLM BF16 对 torch fp32 投影 0.0375。
- 没有与 URB-65 比较，计划的 J2 里也没有这一项。监督模型只在 J3c 的小标签预算下比较过，不代表它们的上限。
- J3c 只做主模型 Z1，标签预算上限是可评估数的一半，多数分层只有 1–2 档。
- Platt 列的 AUROC 受斜率翻负影响，不能当作零样本的排序能力来读。
- 阈值相关指标已计算，但灵敏度的分子多数 <10，按小单元格规则这里不展示，也没有做决策曲线。
- 没有做亚组分析（年龄、性别、基础病、免疫状态）。
- 单一时期的回顾数据，没有评估时间漂移。告警提前量是否有临床意义，这里也没有回答。
- D126 的敏感性分析只算在有 J2 预测的实例上。GD 只算呼吸时可评估 326 例（44 个事件），其中 55 例（19 个事件，占 43%）不在 physiologic 人群里，没有这张问题卡的预测。这部分已按 D127 补查，结果见 J2b 结果文档：补齐后 GD 与 GAM 的差距还在。
- 这一节的探索脚本最初用默认日期解析，丢掉了只有日期的记录，发现后全部改为逐种格式解析并重跑，文中是修正后的数字。锁定流程逐条解析，J2–J4 的主结果不受影响。
- GD 的 state 基本没有 SpO2，这是导出本身如此。零样本在 GD 上是在缺这项关键体征的情况下做判断的。
- 小单元格隐藏原来漏了 J4 的 `n_events_a`、`n_events_b`，结果出来后才发现。`mask_small` 已补上，服务器上的两份输出已重写，这些小计数曾出现在对话的工具输出里。锁定时的代码在快照里，这次修改只影响隐藏。
