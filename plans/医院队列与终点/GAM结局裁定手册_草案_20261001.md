## 0 通用原则

1. **三态**：每个判定都只能是 **是 / 否 / 不确定**。证据不足时选"不确定"，不要猜。
2. 每个"是"另外记录三项：
   - **发病日期**：首次满足判据的日期。病程里写明了开始日期，就用该日期；只有书写日期时，记书写日期，并把依据选为"病程描述"。
   - **入院时已存在**：入院 24 小时内已满足判据，或入院初步诊断已列出，记"是"。
   - **主要依据**：诊断 / 血气或检验 / 病程描述 / 影像。
3. **只算本次住院发生的事件。** 以下情况都判"否"：
   - 既往史中的插管、呼衰；
   - 否定或假设语境，如"必要时气管插管""家属拒绝插管""如病情加重转 ICU"；
   - 知情同意等模板中的"可能出现呼吸衰竭"。
4. **隐私**：
   - 工具只显示化名就诊号和已清洗的片段；
   - 不截屏、不抄录、不带出服务器；
   - 各自在自己的终端 ssh 到服务器运行工具，不要在 Claude Code 里用 `!` 运行。

## 1 呼吸机（有创 / 无创）——研究者 2026-10-01 已定

- **"呼吸机"包括有创与无创通气，只有使用呼吸机的通气才计入。**
  这与 GD 的规则一致：治疗记录有通气、结局却未勾"呼吸机"，表示没有使用呼吸机，不计。
- **有创**：经气管插管或气管切开的机械通气。
  - 全麻手术中或术后短时的插管，选"仅围术期"，不计入。这沿用 v2 裁定的类别。
- **无创**：经面罩或鼻罩、由呼吸机提供的正压通气，如 BiPAP、CPAP、"无创呼吸机"。
- **不计入**：经鼻高流量氧疗（HFNC）、普通鼻导管或面罩吸氧、储氧面罩、简易呼吸器短时辅助等没有使用呼吸机的支持。
- **发病日期**：首次开始使用呼吸机的日期。

## 2 入住 ICU、ECMO、院内死亡

v2 已由研究者裁定；本轮由第二名裁定人盲法复读，用于计算人际一致性。

- **ICU**：转入重症监护病房的日期。急诊抢救室、普通病房内的"心电监护"不计。
- **ECMO**：体外膜肺氧合，取开始日期。
- **院内死亡**：死亡记录，或出院记录写明在院内死亡。自动出院后在院外死亡的，不计为院内死亡。

## 3 呼吸衰竭（I 型 / II 型）——本轮重点

判据采用通用的血气定义（以教科书呼吸衰竭定义为参考，需研究者核对）：

| 情形 | 判定 |
|---|---|
| 血气：静息、未吸氧时 PaO2 < 60 mmHg | 呼衰。PaCO2 ≤ 50 mmHg 为 I 型，PaCO2 > 50 mmHg 为 II 型 |
| 吸氧状态下的血气，记录了吸氧浓度 FiO2 | 氧合指数 PaO2/FiO2 < 300 mmHg 视为 I 型证据（**待确认 Q3**）；PaCO2 > 50 mmHg 且 pH < 7.35 视为 II 型 |
| 医生诊断写明"I 型 / II 型呼吸衰竭"，且有血气或临床描述支持 | 是，按诊断分型 |
| 只写"呼吸衰竭"，未写分型 | 有血气时按血气分型；没有血气时记"是"，分型选"不确定" |
| 慢性 II 型呼衰：如慢阻肺稳定期长期高碳酸血症，pH 代偿正常 | 另标"慢性"。是否计入重症见 **待确认 Q4** |
| 慢性基础上急性加重：pH < 7.35，或病程写明加重 | 是，计入 |

**发病日期**：首次满足判据的血气日期，与首次诊断记录日期，两者取较早者。

## 4 其他并发症（是否本轮做，见待确认 Q5）

只判"是否发生"与发病日期，用于次要终点和更严格的重症定义（SEV_C/D）。以医生诊断为主，同时需要有支持证据；括号内为参考标准。

| 并发症 | 判定 |
|---|---|
| 脓毒症 | 感染并出现器官功能障碍（Sepsis-3：SOFA 较基线升高 ≥2；Singer 等，JAMA 2016），或医生明确诊断 |
| 感染性休克 | 脓毒症，且充分补液后仍需血管活性药才能维持平均动脉压 ≥65 mmHg、乳酸 >2 mmol/L（Sepsis-3），或医生明确诊断 |
| ARDS | 柏林定义（ARDS Definition Task Force，JAMA 2012）：1 周内起病；双肺浸润影；不能完全用心衰或容量过负荷解释；PEEP/CPAP ≥5 cmH2O 时 PaO2/FiO2 ≤300 |
| MODS | ≥2 个器官系统功能障碍，或医生明确诊断 |
| 急性心力衰竭 | 医生诊断新发或急性加重的心衰，有 NT-proBNP 升高或影像肺水肿等支持 |
| 急性肾损伤 | KDIGO 肌酐标准：48 小时内升高 ≥26.5 μmol/L，或 7 天内达到基线的 1.5 倍；或医生诊断 |
| 急性肝损伤 | ALT 或 AST > 3 倍正常上限，或医生诊断 |

## 5 流程

1. **独立盲裁**：两人分别运行裁定工具（`--rater`，`--blind`），互不讨论。
   - 第二人裁定全部范围：第 1、3 节（及第 4 节，若采纳），并复读第 2 节与 v2 的有创/无创判定。
   - 研究者只裁新组件。v2 部分沿用已有判定。
2. **共识会**：工具的 `--consensus` 模式只列出两人不一致的项。逐项讨论，结论和原因留痕；仍定不下的记"不确定"。
3. **重测**：裁定完成 ≥3 天后，每人盲法重裁随机 10%，用于评估自身一致性。
4. **"不确定"的用法**：主分析中不进入训练标签；敏感性分析中分别按阳性和阴性处理。
