**五、最值得先做的新分析：边际覆盖不等于轨迹事件可靠**

对未来每个时点都得到合适的 80% 区间，并不能保证“未来连续两个小时低氧”的概率准确。后者依赖时间点之间如何共同变化。

源码已确认：当前 R-f 使用 `np.linalg.norm(..., axis=...)` 的 **L2 欧氏距离**，作用于真实观测掩码选中的未来向量；它已经是单变量跨时点的联合能量分。[S2] 因此，不应把当前 R-f 误称为逐时点 CRPS 平均，也无需再立项“首次改成 L2”。

下面的 L1 公式用来说明边际评分对照的局限，**不是当前 R-f 的实现**。如果评分使用时间维度 L1 距离，则：

\[
S(P,y)=\mathbb E\|X-y\|_1-\frac12\mathbb E\|X-X'\|_1
=\sum_h\mathrm{CRPS}(P_h,y_h).
\]

这只识别逐时点边际分布，对多维联合分布不是严格适当评分。它不识别时间相关性。

一个简单反例：一半轨迹是 `(1,1)`、另一半是 `(-1,-1)`，与一半 `(1,-1)`、另一半 `(-1,1)`，每个时点的分布完全一样；但“两点连续为正”的概率分别是 0.5 与 0。这个数学事实不依赖本项目是否观察到临床收益。

建议先做低成本的**时间依赖负对照**：对同一个输入，在每个预测时点分别打乱 Monte Carlo 样本编号。这样保留各时点全部经验分布、逐时点覆盖率和逐时点 CRPS，却破坏采样轨迹的时间依赖；当前 L2 联合能量分一般也会随之改变。比较打乱前后的联合评分、持续事件概率和 Brier 分数。

这里打乱的是每个时点的“样本配对”，不是把实际观测时间顺序打乱，也不是跨患者混合数据。

如果这项分析显示：相同边际质量却产生明显不同的事件概率，并且不同后训练方法在外院表现不同，就形成了比“再次证明点奖励压缩方差”更有临床信息学意义的结果。若没有这种差异，也如实报告，不按结果反复调整事件阈值。

真正值得补的是：比较当前 L2 联合评分与 DAR 式逐时点边际评分，在相同底座和预算下是否产生可复现的事件概率差异。高维能量分未必对所有依赖错误都敏感，缺测处理也改变评价对象；目标在理想条件下严格适当，不保证有限数据训练后的条件分布或外院结果已经校准。

当前各体征仍逐通道处理。因此现有联合目标仅覆盖单个体征内部的时间依赖，不能写成心率、呼吸、血氧等多体征联合风险模型。优先研究单体征持续事件，避免继续依赖 F4 中跨变量独立配对的近似轨迹来支持强临床结论。

建议先锁定一个主底座 Chronos-T5-small，加一个不同输出分布且稳定的底座作复核，例如 Lag-Llama。现有其他模型进入附录；Moirai 的数值失败需要报告，不为追求完整表格无限补跑。

| 对照 | 用途 | 训练成本控制 |
|---|---|---|
| 零样本 | 基础参照 | 不训练 |
| 原生 SFT | 最重要的强基线 | 优先复用审计合格的既有运行 |
| SFT＋后校准 | 检验便宜修复是否足够 | 仅源验证集拟合；不增加底座训练 |
| 一个代表性点误差奖励 | 显示目标失配 | 不再重复五种近似相同坏奖励的全矩阵 |
| GTN-R | 直接 TSFM 相关方法 | 核对与原论文实现差异，补足主要比较种子 |
| DAR 式经验 CRPS＋留一贡献 | 最直接的分布奖励对照 | 明确从标量 LLM 回归到多步 TSFM 的适配 |
| 当前 L2 联合能量分／正确成对梯度方案 | 检验跨时点联合目标及估计器影响 | 不包装为已证实原创算法 |

DAR 对照应先在标量玩具任务上验证目标与梯度含义，再说明多步如何聚合。还需在同一种距离下单独比较有限采样 V-statistic／U-statistic 和基线，以免把“边际对联合的目标差异”与“估计器差异”混成一个效应。不能把只替换奖励的一段代码称作完整复现 DAR 的 LLM 系统。GTN-R、TimeRFT 等同理：若是启发式变体就标为变体。

连续可微的分布底座另加直接 proper-score 微调，检验是否有必要用 score-function 更新；离散 token 底座用原生交叉熵／似然 SFT 作为直接训练基线，不能假设采样 CRPS 可以无条件反向传播。

主要训练比较至少三个独立种子；先用已有合格结果抵扣，核心矩阵可按“5 个训练配置 × 2 个底座 × 3 个种子”估算为最多 30 个配置运行，实际只补缺项。这不是含全部消融的总上限：直接评分训练、V/U 估计器及组大小分析须另列预算，建议把新增训练总量封顶在 48 次以内，并按重要性裁剪。组大小 K=4、8、16 只在主底座的关键对照上做。无需再执行“所有奖励 × 所有模型 × 所有数据”的笛卡尔积；这里的 48 次是资源管理建议，不是统计充分性的通用标准。

至少输出以下证据：

- 概率质量：既有 WQL、CRPS／区间分数；主终点沿用原锁定假设，新补充终点单独登记。
- 覆盖与宽度：多个预先指定覆盖水平，按预测距离、变量和医院分层；同时报告区间宽度，排除“放宽区间就算成功”。
- 临床相关概率：一至两个事先确定的生理阈值事件，报告发生率、Brier、可靠性曲线；它们是生理事件代理，不自动等于临床转重。
- 稳定性与成本：训练失败数、每个种子、训练时长、显存和预测采样数；比较等数据／等更新预算，并补成本视角。
- 选择规则：最终 checkpoint 与验证集所选 checkpoint 都给出，不能只挑最差 checkpoint 批判某方法，也不能只报第 0 步掩盖训练失败。

源验证集后校准与目标医院适配必须分开。前者只在 MIMIC 验证集拟合；后者若使用 eICU 标签，应单独设置 calibration/tune 部分，不在 eval 上拟合。

参与事件概率比较的后校准方法必须仍输出完整轨迹样本。例如在源验证集拟合逐预测距离的单调分位数映射，对原样本逐点变换并保留原来的样本配对；这种变换并不自动修复时间依赖。若方法只给 conformal 区间，就仅参加区间评价，不能由上下界虚构完整分布或事件 Brier。conformal 的形式覆盖保证也不能不加条件地搬到医院分布偏移下。

**七、先用一周解决四个有效性问题**

**1. 奖励、估计器和完整优化算法要分开。**

服务器实现已经包含正确的成对项系数和排除自身的基线，并不是明显漏掉交叉 score 导数的朴素错误。但留一基线本身不使整个训练算法自动严格无偏。

静态代码审计发现两个需要定量核实的问题：[S2]

- `rewards.py:241–245` 在当前 batch 更新 EMA 后再归一化，尺度仍依赖当前动作；“严格无偏”的表述需要收窄，或改用滞后尺度做对照。
- `grpo_tsfm.py:142–157` 采样设置最小输出长度，会抑制 EOS；求 logp 使用原 logits 全词表 softmax。应检查生成处理后的实际采样分布是否与打分分布一致，以及差异实际多大。

这两项是静态发现，尚未验证影响，不能据此宣布已有结果作废。应先做小型可枚举分布、Monte Carlo 与有限差分梯度核对，再决定受影响的哪些实验需要重跑。

代码每批实际只做一次在线 score-function 更新，ratio 为 1，没有有效的 PPO clipping；论文应据实描述为带组相对优势的在线策略梯度，而不是自动等同完整 GRPO/PPO 复现。

普通独立样本奖励的组均值基线，在简单条件下只引入 `(G−1)/G` 的比例；本项目成对相互作用奖励的情况不同。不得概括为“组均值一般会改变最优分布”。

**2. 未来真实观测与插补必须分开。**

检查未来标签是否包含前向填充、插值或以缺测当正常。持续异常事件尤其不能把“没有记录”作为“未发生”。应预先规定可评价窗口，分别报告筛选后的样本数、缺失率和选择偏差。不同医院对齐采样间隔、预测时长、单位及掩码含义；不能把 MIMIC 和 eICU 不同物理时长的预测当同一任务。

MC-MED 若作为扩展，字典提示 numerics 温度为华氏、triage 为摄氏，监护数值是前 60 秒聚合均值；这些均需在新视图中明确处理。[S7]

**3. 数据使用历史需要重新登记，而不是重新随机切分。**

已核实：[S6]

- 当前 P1 预测任务继承旧 B1 患者切分；旧 B1 test 已用于阶段模型。
- eICU 也有旧项目使用历史。
- MC-MED 旧项目记录有 287 次运行及 40 次探索运行，test 曾三次解锁／再分析，不能直接称 untouched holdout。
- MIMIC 2020–2022 时间段的候选患者已经散布于旧 train/val/test，不能临时按年代切出后就当全新时间外推集。

建立台账：数据版本、患者集合的不可逆摘要／服务器内部标识、任务、输入、标签、训练暴露、调参暴露、结果查看时间和用途。台账在服务器生成，只带聚合信息进入论文。

据此分三类写作：既有探索结果；新方案锁定后的评价；确有证据从未参与开发的新确认资料。新任务的外部迁移评估仍然有价值，但不等于整个数据库历史上从未被使用。预登记后续分析不能抹去之前的接触。

优先寻找真正未参与开发的患者／医院／资料；如果没有，就如实写回顾性外部迁移评价，限制确证性主张，而不是无限延迟论文或虚构独立性。MC-MED 可作为新任务的跨场景扩展，但其 BaseModel 预测视图尚未建好，而且 ED 的观察长度未必适合 ICU 的 48→12 小时设置；先做可行性核查，不能为凑第三库偷偷改变主任务。

**4. 统计单位与措辞需要校准。**

患者级聚类已做，是优点；重叠窗口不能当独立患者。跨院结论增加每院结果与医院／患者分层重抽样，报告医院数及每院可评价人数。多个种子与多次窗口重抽样解决不同不确定性，不可互相替代。

没有显著差异写“未观察到明确增益”；若要写等效／非劣，需要事先确定合理界值并完成相应分析。cov80=0.773 只表示特定评价口径下的总体覆盖，不等于处处校准。

对采样的未来生理值使用逐样本 MSE，会惩罚输出分布方差；对事件概率报告 p 使用 Brier `(p−y)^2` 则是适当评分。不能泛称“MSE／Brier 都不适当”，也不能把正确地确定报告一个事件概率叫作有害塌缩。

**八、论文应当长成什么样**

主文围绕三问展开：点预测与概率可靠性是否分离；奖励目标与估计器各自造成什么影响；哪种修复在外院仍有效且最划算。持续事件评价作为把统计问题连接到医疗用途的桥梁。

**十、什么情况下继续、什么情况下切换**

- **继续主线：** 基线加入后，SFT 与 RL 持平或更好，但产生清楚的外部可靠性与成本结论。这不是失败。
- **降低算法主张：** fair-score 与 DAR 差异很小，就把它作为成熟估计器的实现／复现结论，不包装增量算法。
- **限制事件主张：** 未来观测不足或事件不稳定，只写生理测量概率预测，保留事件分析为探索结果。
- **停止扩张：** 10 月底若外部概率结果没有稳定新信息，不再扫奖励组合；转入严谨实证写作，必要时缩短稿件。
- **切换有效性路线：** 若采样／梯度修复后核心塌缩现象不再成立，不能继续用原现象批评方法。先评估可否写复现／错误分析；否则把 F2“测量过程协调与冻结表示跨院迁移”升为主文。

F2 备选也需要收敛：同患者、同标签、同训练预算、同预处理下比较手工基线与少量代表嵌入，干预计数语义与记录频率，报告每院差异及校准。已有 LR .609→.673 的结果值得研究，但不能省略 LightGBM 几乎不变的事实。该方向同样不应声称“基础模型普遍无效”。

**十一、投稿方向**

首先考虑 **BMC Medical Informatics and Decision Making**：本次核验的官方范围明确包括医疗信息技术／机器学习的设计与评价，采用科学有效性标准，不以预期影响大小作为编辑决定依据；官网列出 SCIE 收录。[J1]

这一定位适合把“可靠性边界、强基线、跨院评价与选择建议”作为贡献。它不意味着容易录用；仍然需要一个值得回答的问题、充分证据和清楚的医疗关联。

如果最终形成较扎实的新方法或完整可复用的软件方法，可评估 **Computer Methods and Programs in Biomedicine**；若只有可靠的实证结果，不要为期刊定位强加新算法。**Journal of Biomedical Informatics** 作为贡献更强时的候选，不建议把它当年底最保守的唯一目标。这两刊本次官方范围页访问受限，未据此确认实时审稿周期或投稿政策。

**PLOS ONE** 可作为科学有效性导向的备选。其官方标准明确考虑阴性与无显著差异结果，但也明确要求重复性研究有充分科学理由；“换数据复现”并不会自动通过。[J2]

不建议根据所谓“几天初审”推断年底能够接收；初步编辑决定与外审录用不是一回事。费用、学校认可目录与投稿时的收录状态在选刊时核对。本报告不估计录用概率，不承诺分区或影响因子。
