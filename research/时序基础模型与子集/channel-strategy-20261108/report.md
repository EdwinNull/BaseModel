# 通道独立 / 通道依赖：相关论文调研（2026-11-08）

> 用途：研究者决定以"解决常数输入"为主要方向，想用多变量来改善（D157）。本调研为可行性实验提供方法来源。
>
> 读到的程度标在每条后。来源编号见 `sources.jsonl`；检索过程见 `research-log.md`。可行性实验的结果见 `result/时序基础模型/常数上下文可行性_结果_20261108.md`，本文 §4 只引用其结论。

## 0 结论

1. **CI 与 CD 的取舍有现成解释**（C01，基于摘要）：
   - CD 容量高，但对分布漂移不稳健；CI 容量低，但稳健。
   - 所以在许多基准上，CI 反而胜过 CD。
   - 后续工作几乎都在找两者之间的折中。
2. **"让模型自己决定什么时候保持个性、什么时候融合"有五类做法**：

| 做法 | 代表 | 怎么决定融不融合 | 能否用于冻结的基础模型 / 零样本 |
|---|---|---|---|
| 门控修正 | ChaTSFM（C06，ICML 2026） | 冻结的单变量基础模型给出预测，适配器学习通道相似度，用门控把稀疏的跨通道信息作为修正加上去，保留通道内动态 | 能；论文就是为此设计的 |
| 个性适配器 + 共享 CD | C-LoRA（C03，CIKM 2024） | 每个通道一个低秩适配器（个性），条件于输入序列；跨通道关系由共享的 CD 模型学 | 需要训练 |
| 按簇共享 | CCM（C02，NeurIPS 2024）；DUET（C05，KDD 2025） | 相似的通道聚成一簇，簇内共享，簇间独立；DUET 用频域度量学习做软聚类，并稀疏化去掉噪声通道 | 需要训练；CCM 称可做零样本 |
| 通道掩码 | PCD（C04，ICASSP 2026） | 注意力矩阵乘以"相似度矩阵 × 数据集参数"的掩码，只部分依赖 | 需要训练 |
| 残差 + 正则 | PRReg（C01） | 先预测残差，再正则化 CD 部分 | 需要训练 |

3. **基础模型的多变量接口**：
   - Chronos-2（C07）用 group attention，让同组序列共享信息。组可以是一个多变量序列的各通道、目标加协变量，或多条相关序列（跨序列学习）。
   - Moirai（C08）支持任意数量的变量。
   - 本项目的八个模型里，只有 Chronos-2 能在零样本下直接做多变量和协变量；其余是单变量（CI）。
4. **临床数据**：CISM（C13，基于摘要）认为，异质的临床变量应先各自独立处理、后期再汇总，以减少有害的早期交互。本项目的监督参照 Raindrop 学的是传感器之间的依赖图，属于 CD 一侧。
5. **与常数输入的关系**：上面这些方法都假设"各通道的序列本身有形状可比"，没有一篇讨论常数或只测一次的通道。见 §3。

## 1 CI 与 CD 的取舍

**C01 Han、Ye、Zhan，"The Capacity and Robustness Trade-off"（arXiv 2304.05206）**（基于摘要）
- 发现：把每个通道当作单变量处理的 CI 方法，常常大幅胜过利用通道间相关的 CD 方法。
- 解释：CD 容量高，但预测分布漂移后的序列不稳健；CI 牺牲容量，换来稳健。
- 修正：PRReg（预测残差 + 正则），作者报告可以胜过 CI。

Adapformer（C10）、DiAG 等后续论文（只读检索摘要）也指出，CD 会引入过多无关信息，容易过拟合；CI 与 CD 谁更好，取决于数据集。

## 2 学习何时保持个性、何时融合

**C06 ChaTSFM（Li 等，ICML 2026）**（会议页摘要）
- 出发点：多数基础模型按通道独立预训练，忽略通道间信息。
- 做法：给冻结的基础模型加一个轻量的通道适配器，分三步：
  1. 构建一个有预算限制、覆盖多种通道依赖的预训练数据集；
  2. 从数据导出的领域描述中学习通道相似度；
  3. 通过门控修正注入稀疏的跨通道信息，目的是不破坏通道内的时间动态。
- 结果：九个基准上，对四个最好的基础模型都有一致的零样本提升。页面没写是哪四个模型，也没给具体数字。
- 与本项目最相关：它正是"冻结基础模型 + 学习何时融合"。可行性实验的 gate 臂按同样思路实现（CI 输出 + 门控的 CD 修正）。

**C03 C-LoRA（Nie 等，CIKM 2024）**（摘要与检索摘要）
- 每个通道配一个低秩适配器，体现个性；它条件于输入序列，形成带身份的嵌入。
- 跨通道依赖由一个全局共享的 CD 模型学。
- 作为插件，对 CI 和 CD 主干都有提升。

**C02 CCM（Chen 等，NeurIPS 2024）**（基于摘要）
- 按内在相似性把通道动态聚类，用簇身份代替通道身份，兼取 CI 与 CD 的长处。
- 长期预测平均提升 2.4%，短期提升 7.2%；称可以做零样本。

**C05 DUET（Qiu 等，KDD 2025）**（基于摘要）
- 时间聚类模块：按分布把样本分簇，每簇一个模式提取器。
- 通道聚类模块：频域度量学习做软聚类，稀疏化去掉噪声通道。
- 25 个数据集、10 个领域上报告最优。

**C04 PCD（Lee 等，ICASSP 2026；初版为 NeurIPS 2024 研讨会论文）**（基于摘要）
- 注意力矩阵逐元素乘以通道掩码。掩码由相似度矩阵与可学习的数据集参数构成，表示部分通道依赖。

**C11 TimeFilter、C12 CSformer**（只读检索摘要）
- TimeFilter：同一簇的通道在某些时段可能完全独立，所以依赖应随时间变化。
- CSformer：先 CI，后混合，用适配器加权。

## 3 这些方法与常数输入

上述方法都在"各通道的形状"上学习何时融合：
- 相似度、聚类和门控，都是从归一化之后的序列中算出来的；
- 所有方法都保留 RevIN 一类的逐通道归一化。

我们的常数上下文有两个特点：
- 归一化之后每个通道都是全 0，通道之间没有可比的形状；
- 冒烟计数显示，HR、MAP、SpO₂ 都是常数的就诊中，约 99% 的 RR 和体温也是常数。

因此：
- 融合只能在"部分常数"的就诊上起作用；
- 在全常数的就诊上，能用的跨通道信息只有各通道的**水平**（例如 HR 偏高、同时 SpO₂ 偏低），而水平恰好被归一化去掉了。

所以这些方法要用在我们的问题上，前提是先把水平信息还给模型（上一轮调研 `research/时序基础模型与子集/constant-context-tsfm-20261108/report.md` §1）。可行性实验正是这样设计的：先比较三种归一化，再在补回水平的基础上比较 CI、CD 和门控。

## 4 对照可行性实验

详见 `result/时序基础模型/常数上下文可行性_结果_20261108.md`。只在训练集内部评价，结论是探索性的。与本调研有关的四点：

- **零样本**：Chronos-2 的多变量（group attention）、协变量、跨病人分组，在 HR、MAP、SpO₂ 都是常数的就诊（占 69%）上与 LOCF 完全相同，与 §3 的推论一致。
- **补回水平之后**，在常数就诊上比较几种通道策略：
  - 普通 CD 比 CI 的 AUROC 高 0.013（0.005 到 0.021），nMAE 只再降 0.002；
  - 门控融合比 CI 高 0.003（不显著），比普通 CD 低 0.010；
  - 加入协变量后，门控与 CI 没有差别。
- **门控学到的方向符合直觉**：通道自己是常数时更多地借用别的通道（HR 门值 0.39，都不常数时 0.18）。但借来的主要是水平信息，与补回统计量重叠。
- **真正的瓶颈在读出**：同一批常数就诊上，直接分类器的 AUROC 为 0.83–0.89，"预测 → 阈值"最好只到 0.69。

所以，门控、聚类、掩码这类"学习何时融合"的方法，不是常数输入问题的主要杠杆。它们更适合各通道有形状可比的场景，例如 MC-MED 那样更密的数据，或更长的窗口。
