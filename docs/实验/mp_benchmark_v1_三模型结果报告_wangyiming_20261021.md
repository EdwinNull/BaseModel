## 0. 结论

1. **运行与检查**：三个模型 × 3 个训练 seed 全部按执行方案跑完。seed 2026 是主结果，2027、2028 是预登记的附加 seed。正式版 §19 的公平性检查 9/9 通过。
2. **原始测试集上的区分度**：测试集 5,236 例，患病率 12.0%。AUPRC（mean ± SD，3 个 seed）为：BRITS 0.313 ± 0.004，mTAND 0.271 ± 0.003，Raindrop 0.266 ± 0.015。
   - 参考：梁睿颖分支的 LSTM（5 个 seed）为 0.275 ± 0.003。
   - 模型之间没有做配对检验，方案没有预设这一项。
   - 三个模型都没有调参，所以差异不能直接归因于结构。
3. **随机删减呈剂量反应。**
   - drop40 的 ΔAUPRC：BRITS −0.032、mTAND −0.022、Raindrop −0.023。9 个 run 的 95% CI 都不含 0。
   - drop20 的 ΔAUPRC 较小：−0.016、−0.009、−0.007。CI 不含 0 的 run 分别为 3/3、2/3、0/3。
4. **continuous5min 下，AUPRC 和 AUROC 给出的结论不同。**
   - 三个模型的 ΔAUPRC 都接近 0，9 个 CI 全部含 0。
   - BRITS 和 Raindrop 的 ΔAUROC 约为 −0.017 和 −0.020，6 个 CI 全部不含 0。
   - mTAND 的 ΔAUROC ≈ 0。
5. **群体指标不变，不代表个体预测稳定。** 以 Raindrop 在 continuous5min 下为例：ΔAUPRC ≈ +0.001，但 Mean |Δp| = 0.046，和它在 drop40 下相当（0.047）；Flip Rate 为 6.2%（drop40 下为 9.1%）。
6. **删减推动概率的方向因模型而异。** 下面是 drop40 时，冻结阈值上阳性预测率的变化（3 个 seed 平均）：
   - BRITS 整体升高，+3.8 个百分点；
   - Raindrop 整体降低，−6.7 个百分点；
   - mTAND 小幅降低，−2.1 个百分点。

   阈值冻结时，这会直接表现为报警率的系统性变化。
7. **校准指标不能直接解读。**
   - 原因：pos_weight ≈ 7.08 的加权 BCE 把概率整体推高。
   - 表现：原始测试集 Brier 0.18–0.22、ECE 0.27–0.34，都比"一律预测患病率"差（这样预测的 Brier = 0.106）。
   - 后果：Brier、ECE、ΔBrier 以及 |Δp| 的绝对大小，主要反映这个加权口径，而不是模型本身的校准能力。
   - LSTM 分支用的是同一口径，Brier 0.215 ± 0.011。
8. **训练 seed 带来的波动大于单个 run 的 bootstrap CI。** 例如 BRITS 在 drop40 下的 Mean |Δp|，三个 seed 分别在 0.055–0.086 之间，而单个 run 的 CI 宽度只有约 0.003–0.004。drop40 的 Flip Rate 在 seed 2026 是 BRITS 高于 Raindrop（13.4% 对 9.4%），在 seed 2027 则反过来（7.1% 对 11.0%）。比较模型的漂移指标时，应看多 seed 的均值和 SD，不能只看一个 seed。

## 6. 观察（描述性，不做因果解释）

### 6.1 随机删减的剂量反应

- 三个模型从 drop20 到 drop40，ΔAUPRC、Mean |Δp|、Flip Rate 都随删减比例增大，9/9 个 run 方向一致。
- BRITS 下降最多，但它的原始 AUPRC 也最高。
- 在 drop40 下，BRITS 的 AUPRC 仍为 0.281（3 个 seed：0.281、0.280、0.283），不低于 mTAND 和 Raindrop 在 Original 上的水平。

### 6.2 continuous5min 与随机删减不同

- 只有 76.8% 的 visit 被它改动过。
- 在被改动的 visit 里，61.9% 保留了六个变量各自的末次观测；drop20 和 drop40 下这一比例只有 31.7% 和 11.7%。
- 三个模型在 continuous5min 下的 ΔAUPRC 都接近 0。
- 但 BRITS 和 Raindrop 的 AUROC 下降，且 CI 不含 0，Mean |Δp| 与 drop20 至 drop40 相当。个体概率确实变了。AUPRC 不变而 AUROC 下降，可能说明排序变化主要发生在低风险区间，对 AUPRC 影响小（推测，未检查）。

### 6.3 个体漂移与群体指标

- 同一个模型，在 ΔAUPRC 的 CI 含 0 的情况下，Flip Rate 仍有约 4%–7.5%。例子：Raindrop 的 drop20 和 continuous5min，BRITS 的 continuous5min。
- 预测相关系数 r 在 0.87–0.97 之间。
- 只报告 ΔAUPRC/ΔAUROC 会低估输入变化对单个患者预测的影响。

### 6.4 概率移动的方向

- **BRITS**：删减后概率普遍升高，带符号 Mean Δp 在 drop40 下为 +0.028 至 +0.057，阈值上的阳性预测率升高。
- **Raindrop**：随机删减后概率普遍降低（drop40 下为 −0.010 至 −0.029），阳性预测率明显下降，seed 2028 在 drop40 下从 14.0% 降到 7.3%。但在 continuous5min 下，Raindrop 的概率反而小幅升高。
- **mTAND**：几乎不改变平均水平（|带符号 Mean Δp| ≤ 0.006）。
- 本报告没有分析造成这些方向差异的机制。

### 6.5 mTAND seed 2027 的"末次观测"现象（事后探索）

- **现象**：mTAND seed 2027 在 continuous5min 下，59.6% 的 visit 预测完全不变（|Δp| < 1e-9），而输入完全未变的 visit 只有 23.2%。
- **按末次观测是否保留拆开看**（只看有观测被删的 visit）：

  | | drop20 | drop40 | continuous5min |
  |---|---:|---:|---:|
  | 六个变量的末次观测都保留时，预测完全不变的比例 | 51.3% | 37.0% | 72.6% |
  | 有变量的末次观测被删时，预测完全不变的比例 | 5.2% | 1.4% | 6.2% |

- **对照**：seed 2026 和 2028（选中的是第 3 epoch）的相应比例只有 0.07%–2.3%。BRITS（3 个 seed）和 Raindrop seed 2027 只有在输入完全不变时，预测才完全不变；Raindrop seed 2026 和 2028 在输入改变时也有少量预测完全不变（≤ 3.1%）。
- **没有输出塌缩**：所有 run 在原始测试集上的不同概率值都有 5,159–5,229 个（共 5,236 例）。
- **推测**：seed 2027 训练到第 18 epoch，多时间注意力在 float32 下可能已饱和到每个变量最近的观测上。这一点没有直接检查注意力权重。
- **含义**：
  - mTAND 的低漂移有一部分可能来自"主要看末次值"，而不是对不规则采样的稳健建模。
  - 这个性质随 checkpoint（seed、epoch）而变。

### 6.6 训练 seed 的影响

- 原始 AUPRC 的 seed 间 SD 很小：BRITS 0.004、mTAND 0.003。Raindrop 是 0.015，主要受未收敛的 seed 2028 影响。
- 漂移指标的 seed 间差异大得多：BRITS drop40 的 Flip Rate 在 7.1%–13.4% 之间。
- 单个 run 的 bootstrap CI 只反映测试样本的不确定性，不包括训练随机性。

## 7. 假设、泄漏与偏倚

### 7.1 泄漏检查

- 输入只来自冻结 benchmark 里 0–15 min 的六项生命体征。标签窗口是 (15, 75] min，与输入窗口不重叠。
- 推理代码 `engine.predict` 只把观测数组送进模型，label 只在计算损失和指标时使用。
- 标准化器、pos_weight、Raindrop 的 max_len（21）都只来自 Original Train。checkpoint 和阈值只来自 Original Validation。扰动集上没有调任何东西。
- 每套 test 只评价一次，有防覆盖机制。所有补充分析都只读已保存的预测。

### 7.2 偏倚与适用范围

- **人群**：聚合画像显示 train 中 HR ≤ 110、SpO2 ≥ 90、MAP ≥ 65。由此推断 benchmark 构建时排除了"前 15 min 已满足终点"的 visit（未查阅其构建代码）。这是 benchmark 的设计，不是本分支的决定。结论只适用于"前 15 min 未达阈值"的就诊。
- **删减方式**：三种删减都是 benchmark 预先生成的随机或连续区块删除，不是真实的、与病情相关的信息性缺失。本实验不能回答"临床上测得少的病人"会怎样。
- **BRITS 是离线双向模型**：它用到了窗口内的"未来"观测，只适用于固定 landmark（15 min）的离线评估，不能表述为在线预测。

## 8. 需要研究者确认的事项

1. **类别加权口径（与梁睿颖一起定）**：pos_weight 让 Brier、ECE、ΔBrier、|Δp| 和 Flip Rate 都受加权影响。
   - 选项 1：保持现状，把 Brier/ECE 标注为"加权口径下"。
   - 选项 2：作为新版本登记，在 Original Validation 上做单调再校准，例如 Platt 或 isotonic，六个模型统一处理。两者都不改变排序，所以 AUROC/AUPRC 不变；Brier、ECE 和 |Δp| 会变。Flip Rate 是否变取决于方法：Platt 是严格单调变换，阈值在校准后的验证集上按同一 F1 规则重选时，每个病人的判定与原来完全一样，Flip Rate 不变；isotonic 会把不同概率合并成并列值，Flip Rate 可能变。（10-22 更正：初版写的是"会改变 Δp、阈值和 Flip Rate"。）
2. **训练预算**：Raindrop seed 2028 在 30 epoch 时仍未收敛。
   - 选项 1：保持预登记结果。
   - 选项 2：登记新版本，对所有模型统一放宽 epoch 上限后重跑。

   不建议只给 Raindrop 补跑。
3. **PPT 与论文表述**：
   - Raindrop 的观测传播层在 PyPOTS（以及官方 Raindrop_v2）的调用方式下，退化为对每个变量独立做 `relu(Linear(x))`，变量之间不传递消息（执行方案 §4.3）。
   - mTAND 用的是 mTAND-Enc，时间按 t/15 缩放。
   - BRITS 是离线双向模型。
   - mTAND seed 2027 的"末次观测"现象（§6.5）。
4. **是否要做模型之间的配对比较**：例如在同一 bootstrap 下比较 BRITS 与 LSTM 的 ΔAUPRC。这需要先登记再算。
5. **六模型汇总**：需要 GRU-D、OPL-MT-MNAR 的结果，以及统一的汇总表格式。

## 9. 局限

- 只有一个数据集（MC-MED）、一个任务（decomp_60）、一个 landmark（15 min）。
- 每个模型只有 3 个训练 seed（10-22 已补到 5 个，见 §12）。
- 所有模型都没有调参，模型间差异可能来自超参数而不是结构。
- bootstrap CI 不含训练随机性。
- 校准指标受加权口径影响（§0 第 7 条）。
- Raindrop 的图结构是退化的（§8 第 3 条），不能代表"有效的变量间消息传递"。

## 10. 未验证

- LSTM 参考值只从对方的 `results.json` 读出，没有复核其代码和运行。§12 中 FF-LSTM、GRU-D 的数字取自对方的 `five_seed_all_results.csv`，同样没有复核其运行（10-22 只核对了阈值规则和扰动后重算派生特征的代码）。
- §6.5 的注意力饱和只是推测，没有直接检查注意力权重。
- 没有在任何外部数据上验证。
