# 研究材料目录整理说明（2026-11-09）

本次整理统一了五个入口：docs 放说明与沟通材料，plans 放方案，result 放结果，research 放调研，PPT 放演示文稿。原 docs/实验 的结果已合并到 result，终点核验操作材料放到 docs/终点核验。仅整理本机仓库，服务器的周目录、方案锁定记录和文件位置沿用原样。

## 文件怎么放

| 材料 | 位置与规则 |
|---|---|
| 新实验方案 | plans 下最接近的研究主题；文件名含任务、日期和版本 |
| 新实验结果 | result 下与方案相同的主题；配图和聚合表跟随所属报告 |
| 操作说明与空白表 | docs 下的数据对齐、终点核验或 flucase 等主题 |
| 汇报文字 | docs/汇报 下的导师讨论、临床沟通、讲稿与问答或课题申报 |
| PPT | 成品按用途分类，生成脚本、素材与模板分别存放 |
| 一轮调研 | research 的主题目录下新建“主题-日期”包，报告与来源记录留在同一包内 |
| 跨主题工作 | 阶段汇总与交接；专题材料尽量归回相应主题 |

日期、版本、D 编号与科学内容沿用原文件。除原名无法表达内容的 `plans/正式版.md` 更名为“六模型观测删减敏感性_任务说明.md”外，保留文件名。草稿、旧版与正式版一起保存，具体效力以文内的决策和锁定状态为准。
