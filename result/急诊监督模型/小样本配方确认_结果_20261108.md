## 1 结论

**两库都确认。ens_bag 相对单个 LightGBM 的小样本增益在确认集上成立，6 个主要比较全部"优于"。**

| 库 | n | ens_bag | lgbm | ΔAUROC | 95% 区间 | Holm p | 正/负 | 判读 |
|---|---|---|---|---|---|---|---|---|
| MC-MED | 1,000 | 0.7321 | 0.7174 | +0.0147 | [+0.0096, +0.0199] | < 0.002 | 20/0 | 优于 |
| | 2,500 | 0.7574 | 0.7470 | +0.0104 | [+0.0062, +0.0147] | < 0.002 | 20/0 | 优于 |
| | 5,000 | 0.7671 | 0.7597 | +0.0074 | [+0.0040, +0.0111] | 0.002 | 19/1 | 优于 |
| MIMIC-IV-ED | 1,000 | 0.8936 | 0.8841 | +0.0095 | [+0.0083, +0.0107] | < 0.002 | 19/1 | 优于 |
| | 2,500 | 0.9060 | 0.8978 | +0.0082 | [+0.0072, +0.0094] | < 0.002 | 20/0 | 优于 |
| | 5,000 | 0.9124 | 0.9060 | +0.0064 | [+0.0055, +0.0074] | < 0.002 | 20/0 | 优于 |

- ens_bag 是 TabPFN v2（4 个子模型，温度 1.0）与 LightGBM 5 种子平均的等权 logit 平均。
- ΔAUROC 为 20 次抽样的配对差均值；区间为确认集按患者整群 bootstrap（B = 1000）；p < 0.002 表示 1000 次重抽样没有一次越过 0；6 个比较一起做 Holm。
- 按方案 §3.6 的判据：两库都是 3/3 个 n"优于"，没有"差于"。
- **没有看到选择带来的乐观偏差：**

| 库 | n = 1,000 | 2,500 | 5,000 |
|---|---|---|---|
| MC-MED（S 集 / 发现集 / 确认集） | +0.0120 / +0.0101 / +0.0147 | +0.0103 / +0.0087 / +0.0104 | +0.0072 / +0.0065 / +0.0074 |
| MIMIC-IV-ED（S 集 / 确认集） | +0.0094 / +0.0095 | +0.0070 / +0.0082 | +0.0055 / +0.0064 |

  确认集上的增益与此前的估计相当或略大。

## 4 局限

- **确认集是第二次使用。** 第一次（D109，11-04）确认的是全量数据训练的时序模型补丁，与这里的小样本表格配方无关；选出 ens_bag 的过程也没有用过确认集。但"确认集只用一次"的规则为此破了例（D156）。
- **只在两个美国急诊数据集上确认。** 结局（MC-MED `decomp_60`、MIMIC-IV-ED 12 h 内 ICU / 死亡）、人群与特征都与目标医院（老年人流感转重）不同。增益的方向在两个数据集上一致，大小在目标医院可能不同。
- **区间只反映确认集的抽样误差**，不含"换一批 20 次抽样"的变化。抽样间的一致性另看正向次数（19–20/20）。
- **MC-MED 确认集较小**（312 个阳性），区间较宽，但 3 个 n 的下限都在 0 以上。
- **校准：** 小样本时的整体低估没有处理（§3）。
