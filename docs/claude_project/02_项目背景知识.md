## 4 数据模型：CDM（服务器实验）与 flucase 导出

**CDM**（服务器 `alignment/`，v3.1）：`encounters`（每次就诊；人口学、锚点规则、流感证据）、`events`（每条体征 / 检验 / 症状；原值、单位、时间精度、来源）、`treatments`、`complications`、`complications_lab_rules`（检验阈值候选标签，和临床判定分开）、`imaging`、`notes`、`crf_view` 宽表 + 字典。编码前缀：VS（体征）、SYM（症状）、TRT（治疗）、CLP（并发症）、COM（基础病）、OUT（结局）。`alignment/derive.py` 的规则只是"候选列"，不是最终标签。服务器上的 GAM→GD 实验仍用 CDM。

**flucase 不再走 CDM**（D40、D44，10-14）：自己的读取器把各院 Excel 直接读成病例记录，每个值能追溯到原表的文件、工作表、行、列和原值。研究者导出：

- `std_v2`：冻结快照的记录层 + 分析层，写在服务器数据区。
- `std_v3`（D68，10-22）：两院同表、同列、同编码、同取值；`encounters`、`events`、分域视图（vitals / labs / treatments 区间 / diagnoses / flu_tests）、`severity_timeline`（带判据"原文 / 代理"标记）、`outcomes`（按口径 `variant` 全部给出）、`review`、编码表、映射表、数据字典、对齐报告（只含聚合量）、manifest 与 SHA256SUMS。默认 Parquet、默认不含 facts（可勾选），另有 CSV、Excel；后台生成 zip，只有管理员能在"数据导出"页下载。导出不定 t0、人群和标签，按列筛。`encounters` 带 `flu_season`、`season_index`（D73）。
- 默认是研究版（含病例ID、真实日期；D37、D41）；以后的共享版（去标识）按"统一数据规范 v1 草案"做，结构相同。

## 5 转重判定口径（当前：规则集 `guideline2025_v0.3`）

依据《流行性感冒诊疗方案（2025年版）》（下称"方案"）。不直接定义"转重 = X"，先派生**分级时间线**，再导出候选结局。规则集 v0.1 → v0.2（D59–D65）→ v0.3（D66–D72，新建运行默认）；旧版本保留。口径状态登记在规则集同目录的 `.decisions.json`（D22），YAML 改动要换版本号重算。

### 5.1 人群、时点与窗口

| 维度 | 口径 | 决策 |
|---|---|---|
| 人群 | 病原学确诊（抗原或核酸阳性）；来源没有检测字段的记"未记录"，不当阴性 | D16 |
| 年龄 | ≥60 岁主分析；≥65 岁（方案高危人群）亚组 | D70 |
| 场景与结局 | 门急诊 O3 为主结局；现有住院数据只做 D0 描述，不叫"转重"；O1、O2 为次要，等新数据 | D9 |
| 时间零点 | 发病时钟（首个流感样症状）对齐；预测时点 t0 = 首次就诊（门急诊就诊时间 / 入院时间）；发病到就诊天数同时作预测变量和分层变量 | D12、D52 |
| 院内发病 | t0 取首次流感阳性（写院内发病的那条病历的时间） | D48 |
| 起点窗 | t0 前后 24 小时；t0 当天只有日期的事件记为起点，打 `same_day` 标记，O1 / O2 中算"不干净事件" | D18 |
| 同一患者多次就诊 | 每人每个流感季取第一次符合人群条件的就诊做索引；之后 14 天内的就诊 / 住院属同一病程；同季更晚的也不另作索引；门急诊与住院分开算。流感季暂按 ISO 第 40 周至次年第 39 周（把一年分完，不丢华南夏季高峰）。服务器 `TaskConfig.repeat_rule = "first_per_season"`，默认 `all` 保持已锁定配置可复现 | D73 |
| 开发与验证 | GAM + GD 合并开发（内部验证 + 按医院内-外交叉验证）；新门急诊数据、新流感季、GD 9/27 以后的新批次作验证。GD 已被看过多轮，不再当外部验证集 | D19 |

### 5.2 分级判据

| 级别 | 方案原文判据 | 代理判据（basis: proxy / weak） |
|---|---|---|
| 中型 | 影像或诊断提示肺炎（PNEU_IMG）；呼吸困难 / 气促（不用咳嗽，D65）。"发热 >3 天"停用（早期预测时属循环定义） | — |
| 重型 | RR ≥30 次/分；静息吸空气 SpO2 ≤93%（COPD 等慢性低氧者不用，D14① 倾向）；PaO2/FiO2 ≤300 | 新开始普通氧疗（D67；"必要时"医嘱和文字不算；长期家庭氧疗者不算新开始，D71）；高流量氧疗 TRT014（D60）；呼吸衰竭诊断 |
| 危重型 | 呼吸衰竭需机械通气（含无创，D61）；休克；ICU + 器官衰竭（器官含 ARDS、急性肝衰竭，D62） | 只要进 ICU 就算（D66；"呼吸与危重症医学科"是普通病房不算；术后转入照算、打围术期标记单独计数，D72）；ECMO；升压药 |
| 不可评估 | 24–48 小时影像进展 >50%（只用"较前进展"等文字做弱代理，只进敏感性口径 `primary_img`，D63）；急性坏死性脑病 | — |

判据分三类：**生理类**（RR、SpO2、PF）、**治疗类**（氧疗、通气、ICU、ECMO）、**诊断类**（肺炎、呼吸困难、呼吸衰竭、休克）。三类分开派生、分开报告；每组判据各自算基线、事件和"不干净"标记（D28）；分级本身（基线、最高级别、病程类型）按全部判据。

| 口径（variant） | 内容 | 角色 |
|---|---|---|
| `primary` | 治疗类 + 诊断类 | 主口径，跨院比较也以它为主（D21、D69）：生理类受测量密度影响最大（GD 有分钟级监护，GAM 只有病历里写的数） |
| `physiologic` | 生理类 | 敏感性 |
| `guideline` | 只用方案原文判据（去掉全部代理） | 敏感性；量代理判据贡献了多少事件 |
| `primary_img` | primary + 影像进展弱代理 | 敏感性 |

### 5.3 候选结局

| 编号 | 场景 | 定义 | 角色 |
|---|---|---|---|
| O3 | 门急诊早期进展 | 当次没有收住院、基线不超过中型；之后 14 天内住院或达到重型及以上。没能关联全院记录或转院的记"未知"，不记阴性 | 主结局；7 天窗做敏感性分析（D17） |
| D0 | 住院期间重症 | 住院期间任一时刻达到重型及以上 | 只做描述 |
| O1 | 住院中 → 重 | 基线不超过中型，之后首次达到重型及以上 | 次要；现有数据每院干净事件 <10 |
| O2 | 住院进展到危重 / 死亡 | 基线不超过重型，之后首次达到危重型或院内死亡 | 次要；同上 |

通用约定：只用状态为"有"的记录（"必要时""拟""拒绝""放弃""围术期"语境不计入）；只有本地 LLM 抽到、或与规则结论不一致的记录要复核判"是"后才进有效层；没有任何证据记"未见中型及以上证据"，**不等于轻型，也不等于阴性**（轻型判不出，不单列）。标记：`same_day`、`untimed_positive`（有时间未知的阳性证据）、`chronic_hypoxemia`（COPD）、围术期。

### 5.4 仍未定的

- 住院任务里，同一病程 14 天内再住院时发生的事件要不要算进索引住院的标签（D73 遗留，会改变标签定义）。
- 术后转入 ICU 是否排除：先看真实数据计数（D72）。
- 发热阈值腋温 ≥37.3℃、退热"不用退热药连续 24 小时正常"、不发热者单列（D13，倾向，待临床）；退热时间这个次要结局还没实现。
- COPD 者不用 SpO2 判重型（D14①，倾向）。
- 研究者在真实数据上要核对、只回报计数的项（对齐方案 §7）：如两院氧疗检出、ICU 科室名称清单、结局率的站点可区分性。

可行性证据（10-10 计数，候选分级）：住院患者发病到入院中位 7 天（门急诊中位 1 天）；约一半住院患者入院时不发热、病史也没记发热；"第 2 天以后首次达到重型"的干净事件每院 <10。

## 6 实验与结果

### 6.1 GAM → GD 外部验证 v1.0（09-29，可行性验证，未加奖惩函数）

- **训练**：GAM 161 人 / 163 次住院 / 10 事件；**测试**：GD 290 人 / 292 次住院 / 38 事件。
- **终点**：ICU、有创通气、院内死亡、ECMO 任一（这四项在 GAM 病历里最容易抽）。
- **索引**：GAM 取首次流感阳性；GD 没有入院日期，取首个体征日期。输入：t0 前 24 小时至预测时点的首个观测，15 个变量（体温、心率、呼吸、收缩压、舒张压、WBC、NEU、LYM、Hb、PLT、CRP、ALT、AST、CREA、BUN）+ 年龄、性别。

| 模型 | 做法 | GD AUROC（95% CI） | AUPRC | Brier | O/E |
|---|---|---|---|---|---|
| URB-65 | 尿素 >7、呼吸 ≥30、低血压、年龄 ≥65 各 1 分，GAM 上拟合一维 LR | 0.631 (0.535–0.723) | .192 | .113 | 1.72 |
| LR | 中位数插补 + 标准化 + L2 | 0.733 (0.627–0.826) | .370 | .101 | 1.54 |
| LightGBM | 浅树，内部交叉验证选树数 | 0.737 (0.651–0.817) | .351 | .108 | 1.92 |
| TabPFN v2 | 训练表作上下文，不微调 | 0.739 (0.653–0.821) | .359 | .103 | 1.40 |
| MIRA R0b | 冻结 MIRA 嵌入 → PCA16 → LR | 0.609 (0.493–0.721) | .264 | .117 | 2.81 |
| Qwen3-8B 零样本 | 中文提示，logit(是) − logit(否) → 一维 LR | 0.731 (0.640–0.817) | .314 | .106 | 1.18 |

解读与限制：GD 几乎没有时序（99.4% 序列只有一个点），时序模型不如 LR；38 个事件中 26 个在索引当天，真正前瞻的子集只有 263 次 / 9 事件；GD 住院期重症、E2、前瞻转重等多个终点版本不能拼接最高指标。这批结果不宜承担"时序模型提前预测流感转重"的主结论。

### 6.2 公开数据 week02（10-04 至 10-06，MIMIC-IV、eICU）

| 实验 | 结论 |
|---|---|
| P1 H-P1a（主假设） | 成立。Chronos-T5-small 上点误差类奖励（R-a 至 R-e）让 80% 区间覆盖率（cov80）从零样本 0.741 降到 0.091–0.131；R-f（单变量跨时点联合能量分 + 留一基线）cov80 = 0.773 [0.769, 0.777]。6 个分量 Holm 校正后都显著 |
| P1 H-P1b | 不成立。有界或相对奖励的 WQL 只好 0.3–1.1%，近零方差组比例反而更高 |
| P1 RL vs SFT | MIMIC 测试集最佳 RL（GTN-R）WQL 比 SFT 低 0.00027（约 0.4%，p = 0.001）；eICU eval 医院差 +0.00008，95% CI [−0.00037, +0.00106]，p = 0.78。三种后训练在 eICU 上都比零样本好约 4% |
| P1-E | Lag-Llama、Moirai-MoE 上"点误差奖励塌缩、R-f 不塌缩"同样成立 |
| P1 规模 | 约 90 次后训练运行；正式测试只有 Chronos-T5-small（GTN-R 两个种子）。MIMIC 测试 27,492 个预测单元 / 1,280 患者；eICU eval 21,926 单元 / 6,488 患者 |
| F1 零样本生命体征预测 | TimesFM 系列领先；Lag-Llama 在 eICU 上比 Naive 还差；Sundial 区间过窄（cov80 约 0.36），疑似调用问题；MIRA 见过 MIMIC 也没领先 |
| F2 冻结嵌入预测转重风险 | MIMIC 内部最好的嵌入与手工 LightGBM 持平；eICU 外部医院 12 个嵌入全部显著低于手工 LightGBM（−0.013 至 −0.054；手工 AUPRC 0.201、AUROC 0.715）。观测次数改成"有观测的小时数"后，LR 外部 AUROC 0.609 → 0.673，LightGBM 变化小 |
| F3 观测密度压力测试 | H-F3 不成立：稀疏到每变量 1 个值，TSFM 探针相对 LR 仍 +0.041 AUPRC；各模型 AUPRC 都降约 32–37%，相对 LR 的优势没有消失。推论：医院 v1.0 里复杂模型不如 LR，更可能来自小样本和跨中心偏移，不只是稀疏 |
| F4 | 零标签"预测轨迹 → 预警"几乎没有判别力（AUROC 0.55–0.59） |
| P2 风险头训练目标 | 加权、焦点、Brier 损失都不提高 AUPRC，只破坏校准（Platt 可修复） |
| AL4 无监督域适应 | 跨中心（MIMIC → eICU）10 种 UDA 中 7 种显著好于"仅源域 + 重校准"；跨年龄全部无效。骨干是弱 CNN，待在强基线上复核 |

### 6.3 六模型观测删减敏感性实验（mp_benchmark_v1，10-21 / 10-22，与合作同学分工）

- **问题**：同一批急诊患者、标签和原始生理记录下，观测被随机减少或连续移除时，不同缺失处理机制的模型的性能和患者级风险概率变化多大。只是"机制与观测策略敏感性存在关联"，不做因果主张。
- **设计**：MC-MED 冻结 benchmark（只读）；`decomp_60` 任务；六项生命体征，输入窗口 0–15 分钟；每个模型只训练一次（Original Train，按 Original Validation AUPRC 早停，阈值取验证集 F1 最大点后冻结）；四套测试集 original / drop20 / drop40 / continuous5min 用同一 checkpoint 打分；以 CSN 为单位 paired bootstrap 1,000 次。分工：合作同学 FF-LSTM、GRU-D、OPL-MT-MNAR；本人 BRITS、mTAND、Raindrop（超参数取论文默认，不调参）。

五个模型、5 个 seed（mean ± SD；Δ 依次为 drop20 / drop40 / continuous5min）：

| 模型 | Original AUPRC | Original AUROC | ΔAUPRC | Flip Rate |
|---|---|---|---|---|
| FF-LSTM | 0.275 ± 0.003 | 0.711 ± 0.005 | −0.006 / −0.016 / −0.005 | 3.7% / 6.4% / 4.4% |
| GRU-D | 0.298 ± 0.002 | 0.728 ± 0.002 | −0.020 / −0.036 / −0.009 | 4.6% / 7.3% / 5.0% |
| BRITS | 0.314 ± 0.003 | 0.734 ± 0.005 | −0.016 / −0.033 / −0.011 | 5.5% / 9.2% / 5.4% |
| mTAND | 0.273 ± 0.003 | 0.692 ± 0.002 | −0.010 / −0.024 / +0.004 | 3.4% / 6.2% / 2.2% |
| Raindrop | 0.269 ± 0.013 | 0.705 ± 0.014 | −0.008 / −0.024 / −0.001 | 5.0% / 9.7% / 6.6% |

观察（描述性）：随机删减呈剂量反应（drop40 下 15 个 run 的 ΔAUPRC CI 都不含 0）；continuous5min 下 AUPRC 与 AUROC 结论不同；群体指标不变不代表个体预测稳定（Raindrop continuous5min ΔAUPRC ≈ 0，Mean |Δp| 0.044）；删减推动概率的方向因模型而异（drop40 阳性预测率 BRITS +3.4、mTAND −1.8、Raindrop −7.3 个百分点）；训练 seed 带来的波动大于单个 run 的 bootstrap CI。

需要知道的实现事实：`pos_weight` ≈ 7.08 的加权 BCE 把概率整体推高，Brier（0.18–0.23）和 ECE（0.28–0.36）都差于一律预测患病率（Brier 0.106），校准类指标不能直接解读；Raindrop 在 PyPOTS / 官方 Raindrop_v2 的调用方式下观测传播层退化，变量间不传消息；mTAND 用判别式 mTAND-Enc，时间按 t/15 缩放；BRITS 是离线双向模型，不能说成在线预测。

待定（B 档，与合作同学一起）：类别加权口径（保持并标注，或登记新版本做单调再校准）；Raindrop seed 2028 未收敛是否统一放宽 epoch 重跑；是否先登记再做模型间配对比较；六模型汇总表等 OPL-MT-MNAR 结果。

## 7 flucase：多中心老年流感病例数据收集系统

- **定位**（D39）：医生导入本院导出的 Excel，系统认出格式、读成统一病例记录，先给医生看读到了什么和哪里有问题，确认后才进病例库；分级、复核、质控、导出是研究者在病例库之上的功能。
- **技术栈**：后端 FastAPI + SQLite（记录用 Parquet 按需读）；前端 Vue 3 + Element Plus。
- **导入**：已知格式精确导入，认不出的 Excel / CSV 走通用导入，确认后存成格式（D38）；格式族 + 格式配置是接入新中心的基础（D42）。内置格式：GD式 CRF、GD式原始导出（"病历系统多文件导出"格式族，一整套文件按表头认 13 类表、按 ENCT_ID / ENCT_UUID / 住院号挂接，D50）、GAM式住院、GAM式门诊、门急诊导出模板、统一格式 Excel。上传支持多文件、文件夹、zip / rar / 7z（D57）。导入累加（新增 / 更新建新版本 / 不变），可撤销、可放弃未确认的导入；医生可更正，原值保留（D43）。编号直接用病例ID，不化名（D37）。
- **数据处理口径**：GD 原始导出就诊编号用"住院号-入院日期"（D51）；有明确规则的数值笔误自动改并标"已修正"（如体温 300–430 ÷10），说不清的只记问题；SpO2 吸氧状态按医嘱推断并标"推断"（D55）；诊断编码范围、氧疗医嘱名称、ICU 科室名单写进格式配置由研究者审。两院共用一套文字规则词表（D68）。
- **角色**：医生（importer，导入本中心）、研究者（admin）、复核员（盲法复核、改判）、录入员（前瞻入组、随访）、观察者（viewer，只看聚合，D46）。登录失败只按账号锁：15 分钟内失败 5 次暂停 15 分钟（D47）。
- **研究者功能**：按规则集算候选分级（分级时间线、病程类型、候选结局，按口径分开）；复核条目 R1–R7——R1 决定结局的阳性事件没有时间；R2 字段冲突或规则与 LLM 不一致；R3 假设 / 计划 / 拒绝 / 围术期语境；R4 起病时间缺失、矛盾或晚于就诊；R5 SpO2 ≤93% 但吸氧状态未知；R6 不合理值 / 单位存疑；R7 自动接受条目中随机抽样。A 类（R1–R3）双人盲裁 + 共识，B 类单人 + 15% 抽样重复；复核员只看中性问题类别。质控（默认主分析人群：确诊且 ≥60 岁）、冻结快照、数据使用台账、std_v2 / std_v3 导出、规则集版本对比与"用此版本重算"、前瞻录入表单 v0.2、全字段标注与抽取评测。首次真实运行不开本地 LLM（D33）。
- **医生端**：使用说明页、术语表与悬停解释、导入四步（① 选文件 → ② 认格式 → ③ 看读到了什么 → ④ 确认导入）、导入回执与回执 Excel、问题清单、病例页体征与治疗图（体温、心率、呼吸、SpO2、血压共用时间轴，不显示分级以保持复核盲法）。
- **部署**：10-17 首次部署；10-23 发布含规则集 v0.3、统一文字规则、数据导出页、D73 的版本。服务内存上限 1.5 GB，导入一套 GD 原始导出按峰值 ≤1 GB 设计，同一时间只跑一个导入（D58）。改那台服务器只动 flucase 自己的账号、部署目录、systemd 服务、nginx 站点（8443）、sudoers 与 logrotate 配置，不碰同机另一系统的文件、服务、端口和数据库；改 nginx 前后都 `nginx -t`、只 reload。
- **测试与教程**：后端测试全部用虚构数据；10-16 全角色测试发现 26 个问题已全部修复；分角色测试教程（GD 医生、GAM 医生、新中心接入、研究者、复核员 / 录入员 / 观察者）在 `BaseModel/docs/flucase/`，由 `scripts/flucase_tutorials/build.sh` 生成。
- **顺序**（D45）：部署前开发准备 → 研究者第一轮测试 → 部署到专用服务器 → 医生测试（可用性测试、真实数据试用）。
- **接下来**：对齐方案阶段 1 其余项（GD 认转院、检查报告结论认肺炎、共用药品与流感检测对应表、来源类型与报告时间）；研究者在真实数据上核对对齐方案 §7 的计数；新中心接入；共享版（去标识）导出按统一数据规范 v1 草案（另一分支有公开医学时序数据集的规范对照讲解页，未合并）。

|---|---|
| GAM / GD | 广安门医院 / 广东省中医院 |

| 生理类 / 治疗类 / 诊断类 | 判据的三种类别 |
| 方案原文 / 代理 / 弱代理 | 判据依据（basis，D59） |
| same_day / untimed_positive | t0 当天只有日期的事件 / 有时间未知的阳性证据 |
| 不干净事件 | 带 same_day 或时间未知证据的事件，主分析另列 |
| R1–R7 | flucase 复核条目类型，见 §7 |
| 自动层 / 有效层 | 规则自动抽取的结果 / 复核后实际使用的结果 |
| std_v2 / std_v3 | flucase 的标准导出格式，见 §4 |
| A / B / C 档 | 服务器规范的决策分级。A 档必须由研究者裁决（临床定义、纳排、窗口、标签、终点、阈值、标签泄漏与有效性、模型路线、结论），先做完不依赖它的部分再带实测证据交回；B 档在定义已定后可直接执行（数据管线、特征、训练与评价代码），但不得改变标签、时点、纳排、切分、主指标、阈值、结论；C 档只做机械、可逐条核对的事（提取论文元数据、整理对比表与参考文献） |

| TSFM | 时序基础模型（Chronos、TimesFM、Moirai、MOMENT、MIRA 等） |
| SFT / RL / GTN-R | 监督微调 / 强化学习 / 一种保留真值邻域的时序 RL 后训练方法 |

| AUROC / AUPRC / Brier / O/E / ECE | 区分度 / 精确率-召回率曲线下面积 / 概率均方误差 / 观测与期望事件数之比 / 期望校准误差 |
| Δp / Flip Rate | 扰动前后同一患者的预测概率变化 / 冻结阈值下判定翻转的比例 |
| drop20 / drop40 / continuous5min | 随机删 20% / 40% 观测 / 连续移除 5 分钟观测 |
| URB-65 | CURB-65 去掉意识障碍（C）项：尿素 >7、呼吸 ≥30、低血压、年龄 ≥65 各 1 分 |
| landmark | 在固定时点做预测的样本单位，不等于患者数 |
