# MC-MED 与 MIMIC-IV-ED 时序模型子集诊断：本周计划（2026-11-02—11-08）

只含聚合量。编制日期 2026-11-02。第 3 节的 A 档事项由研究者在周一锁定；锁定前只做不依赖这些决定的部分（调研、虚构数据开发、只出计数的结构核查）。

## 1. 依据

11-02 组会结论（研究者转述）：

1. 调研现在常用的时序数据集：研究的是长时序还是短时序，用的什么数据集，有没有划分子集训练；
2. 把这些适配时序模型放在 MC-MED 和 MIMIC-IV-ED 上跑，看效果；
3. 把这两个数据集划分子集，用这些时序模型跑子集，看模型在哪个子集上表现差；
4. 对表现差的子集，分析是什么问题，给模型打补丁，让效果好一点；
5. 再找有没有合适的急诊数据集，先备着。

本计划取代 `plans/观测过程建模/观测策略后训练_下周详细计划_20261102-1108.md` 作为本周主线。那份计划在 MIMIC-IV/eICU 多医院上做 M0/M1b/M2 后训练，与组会定的方向不同；它的删观测算子保留，作为第 6 节的补丁候选之一。

## 3. 周一需研究者锁定的事项（A 档）

1. **MIMIC-IV-ED 任务口径。** MIMIC-IV-ED 没有床旁连续监护，生命体征大约一两个小时一条，照搬 MC-MED 的"前 15 min 输入 → 之后 60 min 恶化"不可行。
   - 建议：成人急诊就诊，以到院后 2 h 为预测时点；输入为 [到院, 2 h) 内的 triage 与 vitalsign（体温、心率、呼吸、SpO₂、收缩压、舒张压，需逐项核对与 MC-MED 六项生命体征是否同义）；结局为之后进 ICU 或院内死亡；2 h 前已离开急诊或结局已发生的排除。
   - 备选：向 Xie 等 2022 年的 MIMIC-IV-ED 公开基准靠拢（分诊时点；住院、危重结局、72 h 复诊），便于与文献比较。引用前核对原文。
   - 2 h 窗口是否可行，以周一只出计数的核查为准（第 5 节周一）。
2. **子集清单与"表现差"判据。** 建议见第 6 节。
3. **发现与确认分开。** 建议在验证集预测上找子集（每个 run 已有 `pred_val_original.csv`），测试集留到补丁完成后只评价一次。MC-MED 测试集已被多次查看，在同一测试集上既找子集又验补丁即为过拟合。若验证集上子集事件数不够，改为测试集一半发现、一半确认。
4. **校准。** 比较子集的 Brier 和校准之前，是否所有模型统一在 Original Validation 上再校准（即 v1.1），同时保留原始输出的结果。
5. **模型清单。** 建议 LR、LightGBM 作为强基线必须有；时序模型沿用 MC-MED 上那套；TimesFM、MIRA 等基础模型是否搬到 MIMIC-IV-ED，看调研结论再定。

## 6. 子集划分与判据

### 6.1 子集（看结果前登记）

建议每个子集在评价集中至少 30 个阳性，不足则合并或不报。字段以服务器实际列名为准，周一核对。

| 维度 | 建议切法 | 理由 |
|---|---|---|
| 年龄 | 18–64 / 65–79 / ≥80 | 项目主线是老年人 |
| 性别 | 男 / 女 | 常规公平性检查 |
| 分诊等级 | ESI 1–2 / 3 / 4–5 | 病情轻重 |
| 到达方式 | 救护车 / 其他 | 病情与监测强度 |
| 主诉或诊断类别 | 呼吸道或感染相关 / 其他 | 连到流感主线；急诊诊断离院时才有，只用于回顾性分组，不作输入 |
| 序列长短与密度 | 窗口内观测条数三分位；缺失通道数；有无 SpO₂ | 直接回答"长时序还是短时序" |
| 时间 | 年份（MC-MED 2020–2022 跨新冠）；夜间或白天到院 | 时间漂移、夜班记录习惯。**11-03 核查：MC-MED 日期随机平移、钟点也被打乱，两项都不能用；MIMIC-IV-ED 只有患者级的 anchor_year_group** |

### 6.2 "表现差"的判据

- 子集 AUROC 低于补集，CI 不含 0，且多数 seed 方向一致。AUPRC 随患病率变化，不同子集之间不直接比 AUPRC。
- 与 LightGBM、LR 对照，判断能不能补：
  - 所有模型（含树模型）都差：子集本身难（事件少、信息少或标签不准），回到数据和标签，不以模型补丁为主；
  - 树模型不差、时序模型差：时序模型自身的问题，是补丁对象；
  - 只校准差、排序不差：先试按子集再校准，成本最低。

### 6.3 补丁候选（下周再做）

- 稀疏或短序列子集：删观测或密度增强（原计划 M1b/M2 算子），或换时间编码。
- 老年等人群子集：重加权，或加入年龄、分诊信息。
- 基础模型在短窗口上差：换池化、加适配层或微调。

## 7. 急诊数据集检索

- 标准：急诊场景；逐人逐次就诊；生命体征与检验带时间戳；规模；≥65 岁覆盖；ICU、死亡、住院等结局；获取方式与周期；能否放到 L40。
- 检索范围：PhysioNet；Scientific Data 的数据描述论文；MC-MED 与 MIMIC-IV-ED 论文列出的同类数据集。
- 证据要求：只写官方页面或全文核实的内容；只看到摘要的标"基于摘要"；没找到写"未找到"。NHAMCS 一类全国抽样调查预计只有单次就诊的横断面记录，可作反例列出。
