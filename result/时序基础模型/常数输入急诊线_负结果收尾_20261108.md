## 0 结论

D159 的"解决"是：先尽量做到 (i)，再在这个基础上完成 (ii)。

- (i)：基础模型在常数输入上不退化。
- (ii)：转重风险排序变好。

| | 结果 | 依据 |
|---|---|---|
| (i) | **做到了**。零样本下有两种做法：加 8 格人群锚点；人群参考系 + 多变量 + 协变量。训练的分位数小模型也做到了 | 表 1 |
| (ii)，与 LOCF 或原零样本比 | **只做到一小部分**。常数就诊上 AUROC 最多比 LOCF 高约 0.01–0.04；越阈标签上，越阈概率读出比峰值读出高 0.05–0.13 | 表 1 |
| (ii)，与表格模型比 | **没有做到**。时序信息在 LightGBM 3b 之外只多 +0.002（非常数就诊）；常数就诊上为 0 | §2 |

**收尾结论**：在急诊到院 2 h 这个预测时点，常数输入退化可以修好，但修好以后风险排序并没有因此变好。

- 常数就诊上的风险信息在协变量和化验里，不在时间维度里。
- "先预测体征、再读风险"这条路的上限是 0.736。这个数是拿实际观测到的未来体征去读得到的，相当于预测完全准确；表格模型是 0.927。

方案 D 不做（D159）。

## 1 按 (i)、(ii) 打分

表 1 中的符号说明：

- **偏离**：常数通道上 max_t |预测中位数 − 末值| 的中位数。
- **向人群**：第 48 步比末值更接近人群中位数的比例，只算离人群中位数超过 0.5 个标准差的常数通道。
- **宽度**：q90 − q10 在 48 步上的均值，HR，取 eval 中位数，分常数与非常数就诊（本文补算）。

**(i) 的判断标准**（事后描述，不是事先判据）。三条都满足才算：

1. HR、MAP 的偏离 ≥ 1；
2. 向人群的比例 ≥ 75%；
3. 宽度之比（常数 / 非常数）在 0.25–4 之间。

后续的微调实验（方案 F1）会把这三条事先写进判据。

**表 1** AUROC 均为 D103 标签，峰值读出 / 越阈概率读出：

从表 1 可以读出四点：

1. **(i) 能做到，代价是非常数就诊变差。**
   - 锚点臂（D157）在常数就诊上比原零样本好 +0.007（0.002, 0.012）。
   - 但全体的峰值读出 AUROC 从 0.725 降到 0.704：锚点也改变了非常数序列的上下文。
2. **单变量的人群参考系不够。**
   - 它的中位数合理，但给出的分布宽到 HR 831 次/分，属于超出预训练分布。
   - 加上多变量和协变量后，分布才合理。
3. **(ii) 在常数就诊上最多提高约 0.04。**
   - 满足 (i) 的各臂里，常数就诊上最好的是训练的分位数小模型：0.694，比 LOCF 高 0.038；
   - 基础模型的两个臂只有 0.663–0.665，比 LOCF 高 0.007–0.009。
4. **越阈概率读出要配合合理的分布才有用。**
   - 分布合理的臂，越阈标签上越阈读出明显更好：锚点 0.689 对峰值读出 0.640；分位数小模型 0.737 对 0.606。
   - 原零样本在常数就诊上的分布是退化的，越阈读出反而更差：0.608 对峰值读出 0.656。

## 2 (ii) 的上限：为什么不能指望预测路线追上表格模型

| 证据 | 数值 | 来源 |
|---|---|---|
| 完美体征预测的上限（实际观测到的未来体征，峰值读出） | 全体 0.736，常数就诊 0.715；比 LOCF 高 0.058 / 0.060 | D158 §2.4 |
| 差距分解（常数就诊）：最好的预测路线 → 表格 | 0.689 → 0.887。只用水平的样条读出就有 0.704；加协变量 +0.139（最大的一块）；测量过程 −0.005；化验、主诉、既往史 +0.048 | D158 §2.1 |
| 门控混合（3b + 时序）− 静态专家 | 非常数就诊 +0.0023（0.0014, 0.0032）；常数就诊 −0.0000 | D158 §4.2 |
| 个人既往体征基线（3b 上） | 常数且有既往 −0.0077（−0.0166, 0.0005） | D158 §4.2 |
| 多变量 / 门控融合（补回水平后） | 常数就诊 +0.013（普通多变量）、+0.003（门控，不显著） | D157 §0 |
| 治疗混杂假设 | 不支持：常数 HR > 110 的就诊里，事件组只有 44% 回到阈值内，非事件组 92% | D158 §2.4 |

退化的原因是逐序列归一化：常数通道被压成全 0，模型看不到水平。把水平还给模型，退化就修好了。

但在这个时点，风险排序靠的主要是"谁来的、怎么来的、化验如何"，不是"体征接下来怎么走"。体征的时间信息只有 2 h，69% 的就诊三项体征都是常数，能提供的信息本来就很少。

## 3 能留下来用的东西

1. **零样本的默认做法**：常数输入时前加 8 格人群锚点，可以避免分布退化。代价是非常数序列的风险排序变差，所以只应在常数通道上用。按通道条件使用的效果，本线没有检验。
2. **读出**：分布合理时，用越阈概率读出代替中位数峰值读出（D158 §3.3）。
3. **评价方法**（拟写进文章，方向 6）：
   - 按"三项都常数 / 部分常数 / 都不常数"分层报告；
   - 用三个量衡量钉住程度：偏离、向人群移动的比例、分布宽度之比；
   - 用合成常数输入做合理性检查，并且要同时看分布宽度，不能只看中位数；
   - 用实际观测到的未来体征估计预测路线的上限；
   - 从 LOCF 到表格模型逐级做差距分解。
4. **代码**：`W/basemodel/experiments/const_ctx_feas/`（D157）、`W/basemodel/experiments/const_ctx_sol/`（D158）。参考系补丁 `zs_ref.install_ref_norm`、越阈读出 `common.cdf_from_quantiles` 都可以复用。

## 5 局限

- 训练集内部切分，没有多重比较校正，结论都是探索性的。
- 只有 MIMIC-IV-ED 急诊到院 2 h 一个时点、只有 Chronos-2 一个基础模型做了修复实验，不能直接外推到住院场景、更晚的时点或其他基础模型。
- 表 1 的 (i) 标准是事后定的，只用于描述。
- 完美预测的上限是描述性的：事件组未来测得更频繁，未来观测本身带有选择。
