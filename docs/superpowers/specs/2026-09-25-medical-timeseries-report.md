# 医学时序调研 HTML 报告设计

以 2026-09-23 的后训练调研与第二轮模型、数据集核对为主证据，为项目决策者制作单文件、可离线浏览的中文报告。历史首轮材料仅作背景，不把未核验的流感 RL 奖励当成已证实配方。

页面包含总览、研究图谱、患者时间轴、模型与数据对照、六类奖励机制、治疗 RL 边界、迁移矩阵、实验路线、评估、证据与来源。图表用内嵌 SVG/CSS，并有文本解释；证据标注 S 编号与本地来源。页面兼容移动端、键盘、减弱动态效果及打印。

视觉系统：海军蓝 `#132C3A`、乳白 `#F5F4EF`、正文墨色 `#243640`、青绿 `#147C79`、警示朱红 `#B34B39`、细线灰 `#D5DEDC`。宋体类中文标题与系统无衬线正文形成学术出版物气质。一个宽幅任务路径图作为视觉核心，其余是有层级的阅读版式，不用装饰性图表。
