## 0 一句话

"常数输入问题"其实是三个问题叠在一起：
1. 模型结构让输出只能等于末值；
2. 读出方式丢掉风险信息；
3. 这类就诊本身就没有时间信息。

前两个可以修。第三个不能靠时序模型修，只能三选一：换一种处理方式（按就诊状态分开处理），引入窗口外的新信息（个人历史基线），或者换到有时间信号的任务（住院、更晚的预测时点）。

## 1 问题到底是什么：三层

### 1.1 第一层：位置-尺度等变性，让常数输出只能等于末值

设预测器 F 把上下文 x 映射为预测。若 F 对正的仿射变换等变，即 F(a·x + b) = a·F(x) + b（a > 0），并且连续，那么对常数上下文 c·1 有：

c·1 = lim_{a→0} (a·x₀ + c·1)，所以 F(c·1) = lim (a·F(x₀) + c·1) = c·1。

也就是说，**任何等变的预测器，在常数输入上都只能输出 LOCF**。逐序列归一化（RevIN、InstanceNorm）就是为了实现这种等变。Chronos-2 用 max(std, 1e-5) 作尺度，于是输出 = 末值 + 1e-5 × 网络输出。

推论（可行性实验已全部证实，偏差都是 0.000）：
- 逐通道归一化的多变量模型，每个通道各自等变。常数通道被钉住，与其他通道无关。
- 静态协变量也被各自归一化成常数，所以不带信息。
- 跨病人分组（group attention）同理。
- 在不改归一化的前提下微调权重，改变不了常数通道的输出。

等变性是基础模型**故意**的设计：各领域的单位任意，水平没有含义。但生命体征的水平是有含义的：HR 130 不论历史如何都偏高，体征会向人群水平回落。这是通用时序模型的归纳偏置与临床语义之间的根本错配。

**要修就必须打破等变性**，办法只有四种：
1. 给尺度设下限；
2. 把水平作为输入还给模型；
3. 用固定的参考系代替逐序列统计；
4. 让上下文不再是常数，例如加锚点或历史。

### 1.2 第二层：读出方式与风险不对齐

可行性实验里，补回水平的小模型预测误差降了 17%–20%，但风险 AUROC 反而下降：D103 标签 −0.021，越阈标签 −0.04 到 −0.07。原因有两个。

1. **中位数轨迹的峰值不是越阈概率。** 对越阈事件 E = {某时刻 t ≤ H，y_t 越过阈值 θ}，最优分数是 P(E | 信息)。它取决于"离阈值多远"相对于"未来波动多大"。
   - 中位数预测向人群回归，压缩了病人之间的差别；
   - 它也不含波动信息。三个通道回归的速度不同，取峰值后的最大值还会改变各通道的相对权重。
2. **治疗混杂（假设，未检验）。** 异常体征会被处理（吸氧、补液），之后回到正常。把治疗后的体征预测得越准，越会给最重的病人预测"会恢复正常"。而 D103 结局反映的是病情本身。这时预测观测到的体征，本身就是风险的错误替代目标。

### 1.3 第三层：信息量上限

任何"先预测、再读出"的风险分 r = g(F(x, s)) 都是输入 (x, s) 的函数。所以它的 AUROC 不可能超过同一输入上的最优分类器。

在常数就诊上，(x, s) = (各通道的水平, 协变量)。可行性实验中：
- 同输入的逻辑回归 0.834，LightGBM 3b 0.889；
- "预测 → 阈值"最好只有 0.689。

另一方面，常数序列归一化后，对所有病人都是同一个向量，所以基础模型的嵌入在这批就诊上不含任何信息。这与 ③ 的发现一致：嵌入的增益可以由上下文长度解释。

由此可得，**在占 69% 的常数就诊上，不论怎样设计，时序基础模型都不可能超过表格模型**，除非有窗口外的新时间信息进来。

### 1.4 不可能有效的做法（不必再试）

| 做法 | 原因 | 证据 |
|---|---|---|
| 零样本多变量、协变量、跨病人分组 | 等变性（§1.1） | 可行性实验：与 LOCF 的差都是 0.000 |
| 不改归一化的微调 | 同上 | 推论 |
| 常数就诊上的嵌入探针 | 嵌入是常数（§1.3） | ③（D150） |
| 急诊窗口延长到 4 h | 4 h 时仍有 52% 的就诊只有 ≤1 个生命体征时刻 | D142、D145 |
| 门控、聚类等通道融合 | 常数就诊里 99% 的通道全是常数，没有形状可融合 | 可行性实验 §4 |

## 2 解决方案

| 方案 | 修哪一层 | 零样本？ | 预期 | 成本 |
|---|---|---|---|---|
| **A 按状态分开处理的混合模型**（推荐主线） | 绕开第三层 | 否 | 常数就诊等于表格模型；非常数就诊上检验时序模型的增量 | 低 |
| **B 人群参考系 + 越阈概率读出** | 第一、二层 | 是 | 零样本下最好的机会；上限是"只用水平"的表格模型 | 低 |
| **C 个人历史基线作上下文** | 第三层（引入新信息） | 两者皆可 | 唯一可能让时序模型在常数就诊上真正有用的办法 | 中；A 档 |
| **D 水平感知的微调 + 分布式读出** | 第一、二层 | 否 | 视 A 的结果再定 | 高 |
| **E 换到有时间信号的任务** | 第三层（换场景） | — | 住院流感任务可能本来就没有这个问题 | 计数由研究者在医院数据上做；A 档 |

### 方案 A：按状态分开处理的混合模型（推荐主线）

**思路**：把你提出的"学习什么时候保持个性、什么时候融合"，从"通道之间"提升到"信息来源之间"。

- **静态专家 E_S**：只用表格信息，包括分诊体征水平、年龄、性别、ESI、到达方式、主诉、化验、既往史（3b）。模型用 LightGBM、TabPFN v2，或小样本轮已确认的 ens_bag。表格基础模型（TabPFN）本身就是这一状态下的"基础模型"。
- **动态专家 E_D**：E_S 的输入，再加时序模型给出的信息：
  - 上下文形状特征；
  - 方案 B 的零样本越阈概率；
  - 冻结嵌入。
- **门控**：门值 g 由测量过程决定，包括每个通道的观测次数、极差、标准差、距上次观测的时间、是否常数。

  p = σ((1 − g)·logit_S + g·logit_D)；也可以用带交互项的堆叠 LR 实现。

  常数就诊上 E_D 与 E_S 的信息相同，g 的取值不影响结果。门控真正起作用的地方是非常数就诊。

**它回答的问题**：在有时间信号的那 31% 就诊上，时序模型比表格模型多带来多少？这是"时序基础模型在急诊有没有用"的真正答案。常数输入问题在这里不是被修好，而是被正确地绕开：那部分交给适合它的模型。

**可检验的假设**：
- H_A1：非常数就诊上，混合模型 − E_S 的 AUROC 差，95% CI 下限 > 0。
- H_A2：常数就诊上，混合模型不比 E_S 差（差的 CI 下限 > −0.005）。

**风险**：③ 已发现嵌入在 3b 上的增益为零，但当时没有按常数 / 非常数分层。非常数就诊上很可能也接近零。如果是这样，结论就很干净：在急诊 2 h 窗口上，时序基础模型不提供表格模型之外的信息。这本身可以写进负结果。

### 方案 B：人群参考系归一化 + 越阈概率读出（零样本）

**思路**：用固定的人群参考系代替逐序列统计，打破等变性；再用分位数算越阈概率，代替中位数峰值。

1. 每个通道用人群参考 (μ_ref, σ_ref) 做 z 变换，取 fit 部分的中位数与标准差，也可以按年龄、ESI 分层。HR 130 就变成 z ≈ +2.5 的常数。
2. Chronos-2 源码 `chronos2/model.py` 中，上下文在第 408 行做 InstanceNorm，分位数预测在第 762 行反变换；InstanceNorm 本身接受外部传入的 loc_scale（第 454、532 行对协变量和未来目标就是这样用的）。在第 408 行改为传入 loc = 0、scale = 1，等于恒等变换，由我们在外面做 z 变换和反变换。
3. 预训练时，模型见到的上下文经过逐序列归一化后均值总是 0。它对"均值不为 0 的常数"的先验，很可能是回到 0，也就是回到人群水平。这正是零样本下缺的"向人群回落"。这一点是待验证的假设。
4. 读出：由分位数网格插值得到 p_{v,t} = P(y_{v,t} 越过 θ_v)，风险取 1 − Π_v (1 − max_t p_{v,t})。原零样本臂和锚点臂也同样改用这种读出，作为对照。

**可检验的假设**：
- H_B1：常数通道不再被钉住，并且预测向人群水平回落。合理性检查：输入恰好等于人群中位数时，预测应接近平的。
- H_B2：越阈标签上，越阈概率读出的 AUROC 高于中位数峰值读出。
- H_B3：D103 标签上，常数就诊高于 LOCF，全体不低于原零样本 `z_ci`。这次把非劣对照也定为原零样本，补上上一轮判据的疏漏。

**上限**：它只用了水平，不用协变量，所以上限约等于"只用 5 个分诊水平的 LR"（阶段 0 会算出这个数）。

**风险**：均值不为 0 的输入超出了预训练分布，模型可能表现异常。合理性检查不过就停。

### 方案 C：个人历史基线作为上下文（把常数变成有信息的序列）

**思路**：常数就诊的问题是"窗口内没有时间信息"。但很多病人有既往就诊，那些生命体征都在当前到院之前，不构成泄漏。
- 同样是 HR 110，对平时 70 的人是警报，对平时 105（如房颤）的人不是。
- "相对个人基线的偏离"是窗口内拿不到、时序模型又最擅长的信息。
- 对老年人尤其重要：慢性病让固定阈值经常误判。

MIMIC-IV-ED 训练集 150,635 名患者共 309,776 次就诊，平均每人约 2 次，所以有既往就诊的比例应当不小（阶段 0 计数）。

**两种做法**：
1. **表格特征**：每个通道的个人基线（既往中位数、四分位距）、当前值相对基线的偏离、距上次就诊的时间、既往就诊次数。
2. **时序模型**：把"既往就诊的体征 + 本次分诊"拼成不规则序列（间隔从几天到几年）。用 MIRA 原生的时间戳输入（CT-RoPE、Neural ODE）。我们以前只给过它规则网格。

**可检验的假设**：
- H_C1：在有既往就诊的常数就诊上，加入基线特征后，AUROC 比"水平 + 协变量"（以及 3b）高，CI 下限 > 0。
- H_C2（H_C1 成立后再做）：MIRA 在不规则历史上的零样本预测或嵌入，在 H_C1 的基础上还有增量。

**A 档**：这会新增输入（模型变量）和数据来源（既往就诊），需要研究者决定。医院侧（GAM / GD）有没有既往门诊、住院体征，也需要研究者只出计数。

### 方案 D：水平感知的基础模型微调 + 分布式读出（重，视结果再做）

在 Chronos-2 上：
- 改 InstanceNorm，给尺度设下限，或用方案 B 的参考系；
- 把 loc / scale 作为额外 token 输入，即 Lag-Llama / NuTime 的做法；
- 协变量不做归一化，直接输入；
- 用分位数损失做 LoRA 微调；
- 读越阈概率，也可以加一个结局头做多任务（时间到事件，参考 ICareFM；排序项，参考 CalibRank）。

小模型实验已经预示：只修第一层，预测会变好，风险不会；要配合第二层（分布式读出）和协变量。并且按 §1.3，在常数就诊上它仍不会超过表格模型。所以 D 的价值主要在非常数就诊，以及作为一个"临床预训练预测器"给别的任务用。只有方案 A 显示时序模型在非常数就诊上有增量，才值得做。

### 方案 E：换到有时间信号的任务（A 档）

常数输入是"急诊到院后 2 h"这个预测时点的属性。项目真正的目标是老年人流感住院转重（GAM → GD）。护理记录每 4–8 h 一次、跨好几天，上下文可能本来就不是常数。可选做法：
- **动态 landmark**：每来一次新测量就更新一次预测；
- **推迟预测时点**：到至少有 k 次测量后再预测。

两者都会改动索引时点和窗口，属于 A 档。第一步只需研究者在医院数据上出计数：候选预测时点前生命体征时刻数的分布，以及常数上下文的比例。

## 4 风险与局限

- 方案 B 的输入超出预训练分布，结果可能不稳定，有合理性检查兜底。
- 治疗混杂只能做描述性检验（0d），不能确证。
- 训练集内部评价不是独立外部验证；D111 下验证集和测试集都不再使用。是否在别处验证，属于 A 档。
- 方案 C 依赖既往就诊。没有既往的病人（首诊）仍然只有表格信息，这部分的上限不变。

## 5 需要研究者决定的事项

1. **"解决"指什么**（A 档：主要指标）：
   - (i) 让基础模型在常数输入上不再退化，属于技术目标，B、D 已能做到；
   - (ii) 提高转重风险的排序，属于临床目标。按 §1.3，在常数就诊上只能靠新信息（C）或换场景（E）。

   两者的主要指标不同。
2. **是否批准阶段 0–2**（探索性，只用训练集内部切分）。
3. **是否把既往就诊的体征作为新输入**（A 档：模型变量；方案 C）。
4. **是否在医院数据上做方案 E 的计数**（研究者执行，只回报计数）。
