# MIMIC-IV-ED 四组读出与排序分解执行方案（2026-11-08，D160）

研究者授权先锁定并运行四组读出，重点评价 D−C、D−B，再依据结果决定急诊路线是否收尾。本轮属于探索性分析，沿用 D103 到院 2 h 的 ICU／死亡 12 h 标签、D157 患者级 fit／eval 切分和三项体征均有上下文的队列。全部真实病例输入与逐就诊输出留在服务器，报告仅含聚合量。

## 四组读出

| 臂 | 输入 |
|---|---|
| A | 五个体征各自的实测时刻数、非空 15 分钟格数、距末次实测的分钟数、是否测过、是否仅测一次、是否复测但所有实测值相同，另加 HR／MAP／SpO₂ 三项上下文均常数的标志 |
| B | A 加五个体征的末次值及 D157 的 13 个协变量编码，包括年龄、性别、ESI、到达方式 |
| C | B 加 D159 锚点零样本 `base_anc8` 的越阈风险分 |
| D | B 加 D159 锚点微调 `ft_anc8` 的越阈风险分 |

风险分直接复用 `common.exceed_risk`，由三通道各自未来 48 步的最大边际越阈概率按 `1−∏(1−p)` 汇总。该值作为模型特征，不解释为 ICU／死亡的校准概率。临床体征阈值、插值与尾部外推规则沿用 D158。

四臂均采用样条 LogisticRegression，5 knots、degree 3、常数外推、标准化、C=1、lbfgs、max_iter=5000、tol=1e-5，不调参、不重加权。二元特征直接传入。C、D 额外加入风险分样条与常数标志的交互，采用相同自由度。读出的样条结点和标准化只在读出拟合集上拟合。

RR、体温确实可能从未测量，末值按 fit-tr 的通道人群中位数显式填入，并保留观测标志。过程特征的无观测情况显式编码为时刻数 0、距末次观测 120 分钟、观测标志 0。这些都是变量缺失的约定。HR／MAP／SpO₂ 按既有纳入条件均有上下文。

## 患者隔离与预测特征

D159 仅保存 eval 预测。其 fit-tr 为 82,803 次就诊，fit-va 为 9,520 次，eval 为 45,041 次／2,296 个事件。本轮用 fit-tr 拟合读出，并保留整个原 eval 作评价。

在 fit-tr 按 MRN 的固定 salted SHA256 分五折。每折重新从原 Chronos-2 权重开始，用其余四折的未来体征训练 `ft_anc8`，fit-va 只作预测损失早停。该折患者同时不得出现在训练、早停、eval 的患者中。五个 OOF 模型均沿用 D159 的学习率 1e-5、2,000 步、batch 256、seed 2026、8 格锚点、五个体征单变量训练和最佳验证损失选检查点。固定锚点沿用 D159，用原 fit 部分的上下文计算，不使用结局或未来数值。这样保持与既有 eval 预测同一参考系；折外患者上下文参与这项已冻结的无监督锚点估计，需在报告中披露。

各折只保存该折患者的零样本和微调风险分。拼接后每名 fit-tr 患者的预测均由不使用该患者训练或早停的模型产生。fit-va 不参与读出拟合。eval 直接复用 D159 原始 `f1_preds.npz`，不重新选择预测检查点。

本轮从 W 内已有 `models_cache/chronos-2` 加载原始权重，SHA256 与 D159 相同。Chronos 的纯 Python 源码使用 W 内已安装版本的冻结副本。锁定前对 eval 中固定前 64 次就诊仅核对预测复现，最大中位数差 6.485e-5、最大边际越阈概率差 6.735e-6，均通过预先指定的技术容差 0.01 和 1e-4，没有计算性能指标。源码副本和权重均纳入锁定清单。

OOF 模型拟合了约 80% 的 fit-tr，原 eval 模型拟合完整 fit-tr，二者预测分布存在训练规模差异。该限制事先登记，本轮不据 eval 改读出或补调参。

观测过程读取 D103 已有的 [0,120) 分钟观测表，用原 `derive_map` 构造 MAP。实际时刻数按不同时间计数，空格填充不会增加观测数。重建 8 格上下文并断言与 D157 数组相同，验证时间边界、CSN 对齐和标签取值。所有拟合／早停／评价患者集合两两隔离。

## 评价与 AUROC 分解

两项主要比较为全体 D−C、D−B。报告 AUROC 配对差和患者聚类 bootstrap 95% 区间，B=500、seed=2026；两项主要比较的 bootstrap 双侧 p 值一起做 Holm。其余分层、贡献和辅助比较作描述性结果。保持既有 bootstrap p 值实现，最小可报告 p 为 1/500。

每臂报告全体、三项都常数、其余就诊的 AUROC，以及描述性 Brier。辅助比较为 C−B、B−A 和未经监督读出的 `raw_D−raw_C`，最后一项核对 D159 的约 −0.079 变化。

设 C 为常数层、N 为非常数层，全体 AUROC 等于四类正负配对的条件排序概率乘以该类配对权重之和，配对依次为 C事件×C非事件、C事件×N非事件、N事件×C非事件、N事件×N非事件。每项权重为该层事件数乘该层非事件数除以全体事件数乘全体非事件数，并列计半分。

对每项主要和辅助比较，报告四项各自对全体 ΔAUROC 的贡献，以及两项跨层贡献之和。每次 bootstrap 按患者重新抽样，同时重算权重与排序概率，配对保持一致。每次重抽样的四项贡献之和必须等于全体 AUROC 差。层内 AUROC 差与其加权贡献分别报告。

不事后设定临床最小有意义差值或报警阈值。读出模型在相同输入下的增量方向、区间和来源作为本轮判断依据，临床价值与急诊线是否收尾由研究者看结果后决定。由于原 eval 已多次用于发现问题，本轮所有区间均为探索性区间；不打开 D103 外层验证／测试或 D156 已封存确认集。
