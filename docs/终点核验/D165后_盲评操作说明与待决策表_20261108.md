# 两院呼吸恶化终点的盲评操作说明与待决策表

2026-11-08。对应执行方案 v2 第五、六节。本文件、空白核验表和字段字典可先准备；真实试点在 M2 返回、研究者锁定院区、候选终点和抽样设计后启动。

## 数据管理员保管钥匙，评阅者独立看原始证据

数据管理员运行 `prepare` 和 `sample`，保管 `sampling_population.csv`、`review_design.json` 和 `stratum_key.csv`。评阅者 A、B 各领取随机清单及本人的空表，只看到随机编号与就诊查阅编号。算法标签、抽样层、另一名评阅者的答案和任何模型分数均不进入临床任务。评阅在医院病历系统或原始文书中完成，flucase 分级视图会显示判据，不能用于盲评。

试点每院20份，10个事件、10个无事件，全部独立双评。全量核验的实际配额在试点后定；事件、生理类独有事件和未知层全取，无事件层按研究者登记的配额随机抽样，四分之一双评。患者跨抽样层时工具报错，先登记联合聚类方案再运行。

医院记录、清单、钥匙和填写结果只留在本机 `data/`。质量备注与基线证据可含病历内容，汇总程序只取受控字段，不把自由文本交回。

## 以 label_start 为预测时点，分开记录起病与书写时间

住院核验的预测时点是 `prediction_instances.label_start = baseline_end`。原始 `t0` 是入院或流感锚点；院内获得流感等情形按当前实例定义取原始锚点，不能一律用入院加24小时自行重建。管理员提供每份实例的预测时点和7天核验窗，临床只据此查证，不看算法首命中时间。支持恰在预测时点生效计入基线；预测后窗为左开右闭。

日期、小时和分钟是不同精度。原文只有日期就填 `day`，没有可定位时间就填 `unknown` 并留空时间。补写文书同时保留书写依据和临床估计起病依据；不能把日期补成08:00，也不能把首次记载直接当成首次发生。护理12小时、病历24小时的模糊带目前是方案建议情景，正式采用需研究者登记。

## 先填事实，再判断新发恶化

| 核验内容 | 填写规则 |
|---|---|
| 预测时点支持 | 查当时实际使用装置、慢性家庭支持和执行记录，填写 `baseline_level` 及 `baseline_basis`。无记录不足以证明L0；未知填unknown。GD按医嘱推断的L0需核验执行与实际状态 |
| 7天最高支持 | L0无氧、L1低流量、L2高流量/无创、L3有创/ECMO、L4死亡。`maximum_level_7d` 记录实际达到的最高级别，不用计划升级代替 |
| 支持是否执行 | 基线和升级分别填 `baseline_execution`、`actual_execution`。只有医嘱选order_only；执行依据缺失选unknown。未发生相关支持选not_applicable |
| 两组时间 | `first_upgrade_time` 写首次实际支持升级；`first_deterioration_time` 写首次有临床意义的呼吸恶化。诊断类恶化可以早于或晚于支持升级，不强行相等 |
| 高流量 | 对照装置、流量、执行或明确文书判 `hfnc_confirmed`，名称含“高流量”但无法确认时选unknown |
| 呼吸记录 | 有数满60秒、监护仪或明确测量过程才选measured；有估计或模板证据才选estimated_or_template；只看到18/20等整齐数值时选unknown |
| 新发判定 | `new_deterioration=yes` 指预测后新发且有临床意义的呼吸恶化，`onset_class=new`；预测前已有选no/pre_existing；确认无事件选no/no_event；证据无法区分选unknown/unknown |
| 死亡与受限 | 分别填yes/no/unknown；支持没有升级不能自动推为无恶化。死亡纳入复合终点及治疗受限的主/敏感性处理由A4锁定 |
| 用时与原因 | 每次评阅记录分钟数，裁定也单独记用时；reason填受控代码。其他细节写quality_notes，只留本地 |

支持不变、首次生理测量异常、诊断补写等情形，要按证据判断临床新发。旧算法是否判阳性不参与此判断。`new_deterioration` 为复合终点参照，不直接把临床判定写回导出标签；揭盲后确认的抽取错误由研究者在flucase复核层逐条记录，再生成新版本。

## 三个虚构例子用于统一填写方式

例一：虚构患者甲在预测时点有明确空气记录，预测后30小时实际启用HFNC，执行单与临床恶化时间一致。基线L0、最高L2，两组时间按原证据精度填写，执行yes、高流量yes，新发yes/new。是否把该层作为正式转重切点仍按A2/A7登记。

例二：虚构患者乙在预测前已执行低流量，预测后续开同级别医嘱，之后首次血气异常。基线L1、最高L1；没有实际升级就不填升级时间。首次血气异常不能单凭“首次”证明新发，查早先病情和后续证据后填临床参照，无法区分则unknown。这个例子不要求评阅者猜算法会怎么判。

例三：虚构患者丙在预测后6小时的护理文字提到正在吸氧，记录没有实际开始时间，也找不到基线支持证据。基线unknown；写明书写时间只作为证据，不把6小时当升级时刻。临床也无法定位起病时，两组精度与新发类别均保留unknown。

## 分歧先裁定，再生成聚合报告

A、B先各自完成，随后第三名临床人员只对分歧作裁定。裁定追加 `reviewer=consensus` 行，保留A/B原始行。单评病例只使用该次独立判断；双评分歧未裁定、漏填或权重不守恒时汇总直接报错。每个参照判断的不确定性保留为unknown，报告给出加权比例边界。

空白文件可在无导出时生成：

```bash
flucase/backend/.venv/bin/python scripts/endpoint_audit/review_tools.py template \
  --out-dir docs/终点核验/endpoint_audit_空表_20261108
```

M2后先按 `prepare --help` 填写已锁定的endpoint、pilot/full、随机种子及分院密度切点，再修改生成设计中的实际配额。运行 `sample` 后，填写文件都留在同一 `data/` 工作目录。汇总可直接读多个文件：

```bash
flucase/backend/.venv/bin/python scripts/endpoint_audit/review_tools.py summarise \
  --keys data/<核验目录>/stratum_key.csv \
  --reviews data/<核验目录>/filled_A.csv data/<核验目录>/filled_B.csv data/<核验目录>/consensus.csv \
  --seed <已登记种子> --n-boot <已登记重复数> \
  --out tmp/终点盲评聚合报告_<日期>.md
```

没有分歧时省略consensus文件。试点未覆盖完整抽样层时，不能把试点准确度和发生率外推到全队列；工具在报告中标记估计范围。事件层全取时，推广区间与本数据集抽样误差的含义不同，报告需保留这一说明。
