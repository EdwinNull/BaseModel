# 强化学习/后训练奖惩机制

仅保留奖励、惩罚、偏好、约束或离线评估可在论文中定位的条目。当前主任务是个体级老年流感转重预测，因此本目录的论文主要服务于“预测模型之后的治疗/资源决策层”，不直接替代转重风险模型的监督或生存损失。每个子目录均含独立精读文档和 SVG 方法/数据流图。

| 优先级 | 条目 | 阅读目的 |
|---|---|---|
| P1 | `08_medR` | 后续治疗决策的稳态、观测可信度和动作成本奖励 |
| P1 | `02_Potential_Reward_Shaping`、`07_DR_OPE` | 势函数理论与离线价值估计条件；不用于风险标签损失 |
| P1 | `10_CQL`、`11_CPO` | 后续资源/治疗策略的保守价值与显式安全约束 |
| P2 | `09_GNN_Sepsis_Offline_RL` | 近 L40 工程开销、WIS 局限与状态表示 |
| P2 | `04–06` | 通用 RLHF/DPO/宪法式对齐，只用于文本解释层 |

## 对转重预测的影响

| 内容 | 可迁移到转重预测的部分 | 不应直接迁移的部分 |
|---|---|---|
| medR 三驱动奖励 | 观测新鲜度/可信度、风险状态的可审计分解、成本意识 | 生存势函数、补液/升压药成本不能直接当分类或生存损失 |
| 势函数塑形 | 将临床状态变化拆成可解释的中间目标 | 没有动作和状态转移时，不能伪装成 MDP 奖励 |
| CQL/CPO | 后续抗病毒、床位或监护资源决策的保守性与安全约束 | 不能替代 AUROC、AUPRC、Brier 和校准训练目标 |
| DR-OPE/WIS | 当项目进入治疗决策阶段时评估离线策略 | 不能用 WIS 证明转重预测准确或临床因果效益 |
| GNN-Sepsis | 不规则状态表示和双 L40 附近工程预算 | 脓毒症动作策略结果不能直接外推到流感转重 |

当前建议：先完成 `t0`、转重终点、预测窗口和校准评估；只有确定模型输出要驱动抗病毒、监护升级或床位分配等序贯行动，才建立独立 CMDP/RL 层。
